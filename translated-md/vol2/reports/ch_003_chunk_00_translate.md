## 难点句式

- 原文："Cet ouvrage est le 400e publié / dans la collection *À tous les vents* / par la Bibliothèque électronique du Québec." → 处理方式：源文以三次换行拆开同一句，法文语序为「本书 + 第 400 部 + 在丛书中 + 由某机构出版」。中文按自然语序重组为「本书是魁北克电子图书馆在《随风》丛书中出版的第 400 部作品」，把施动机构提前，避免「由……出版」的后置造成拖沓。信息项（本书、第 400 部、丛书、出版机构）四项齐备，无增删。
- 原文："La Bibliothèque électronique du Québec / est la propriété exclusive de / Jean-Yves Dupuis." → 处理方式：合并为「魁北克电子图书馆为让-伊夫·杜皮伊独家所有」。用「为……所有」而非「是……的独家财产」，前者更合书目页的书面语体；propriété exclusive 依裁决作「独家所有」。

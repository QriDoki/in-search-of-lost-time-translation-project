| Swann | 斯万 | 核心人物姓氏（Charles Swann，夏尔·斯万）。首次出现于第 0 章（书名及题献页）。贯穿全书的重要角色，巴黎上流社会艺术品鉴赏家。 需要称谓时用斯万先生；不擅加源文未出现的名字。 禁用译法: 史万 原文别名: M. Swann |
| Mme Swann | 斯万夫人 | 即奥黛特；本章她在布洛涅树林散步，路人低语其旧名 Odette de Crécy。叙述者只称斯万夫人，不点破。 |
| Gilberte | 希尔贝特 | 斯万与奥黛特之女；本章香榭丽舍游戏的中心人物，叙述者少年之恋的对象。全名 Gilberte Swann→希尔贝特·斯万。禁用译法沿用全书。 |
| Christmas | Christmas | 斯万母女用英文 Christmas 代替 Noël，以示时髦；译文保留英文原词，不译「圣诞节」。 |
| salon | 沙龙；客厅 | 第003章；前者指社交圈，后者指房间，按语境判断。 |
| Noël | 圣诞节 | 第003章；年末节日。 |
| valet de pied | 男仆 | 穿号衣的随车男仆（valet de pied）；与 groom／tigre（跟车小厮）不同。 |
| Bois | 布洛涅树林 | le Bois＝Bois de Boulogne，巴黎西郊树林，上流社会散步、炫示之地；不译「森林」。本章有金合欢道、玛格丽特王后道、大湖、射鸽场。首现第1章。 |
| Charvet | 夏尔韦 | 巴黎高级衬衫与领带店；叙述者赴斯万家午餐前整理其领带。 |
| Combray | 贡布雷 | 叙述者童年度假小镇、全书核心场景（原型伊利耶 Illiers）。译林版（上游指示）。首现第1章。 |
| Joconde | 《蒙娜丽莎》 | 达·芬奇《蒙娜丽莎》（la Joconde）；叙述者说它挂在斯万家也不会比一件睡袍更让他欢喜。 |
| Klingsor | 克林索尔 | 瓦格纳《帕西法尔》中的魔法师；斯万夫人家的候客厅被比作其实验室。 |
| M. Swann | 斯万先生 | 即夏尔·斯万；叙述者父母与他有旧交、后不相往来。需要称谓时作「斯万先生」，不擅加名字。 |
| matinée | 日间聚会 | 下午的社交聚会或日场演出；本章两义并用（贝尔玛的「日场」／斯万夫人的日间聚会），按语境分别作「日场」「日间聚会」，二者不混。 |
| nom | 名字 | 本章主题词（noms de pays／le nom）：地名之名承载欲望、想象与记忆，并反过来塑造它所命名的城市。译「名字」，不作「名称」「名词」。普通用法仍按上下文作「名字／名」。 [theme] |
| orchidée | 兰花 | 斯万家候客厅与花篮中的兰花；与卡特兰同为奥黛特所爱。 |

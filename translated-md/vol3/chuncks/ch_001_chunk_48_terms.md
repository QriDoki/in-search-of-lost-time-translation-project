| Bergotte | 贝戈特 | 作家，叙述者的文学偶像；本章（vol3 第 1 章）首次实际登场，在斯万家谈论贝尔玛与《费德尔》，并评点叙述者的习作。其谈吐与文体不同，译时保留这一落差。 |
| Gilberte | 希尔贝特 | 斯万与奥黛特之女；本章香榭丽舍游戏的中心人物，叙述者少年之恋的对象。全名 Gilberte Swann→希尔贝特·斯万。禁用译法沿用全书。 |
| maman | 妈妈 | 叙述者的母亲；睡前吻为本章情感核心。ma mère 依语境译母亲/妈妈。首现第1章。 |
| Mme Swann | 斯万夫人 | 即奥黛特；本章她在布洛涅树林散步，路人低语其旧名 Odette de Crécy。叙述者只称斯万夫人，不点破。 |
| Norpois | 诺尔普瓦 | 德·诺尔普瓦侯爵（marquis de Norpois），前驻外使节、驻埃及财政监督，法兰西道德与政治科学院院士；说话用旧式外交辞令。带爵位时作「诺尔普瓦侯爵」。禁用译法: 诺尔普瓦兹、诺普瓦。 |
| Swann | 斯万 | 核心人物姓氏（Charles Swann，夏尔·斯万）。首次出现于第 0 章（书名及题献页）。贯穿全书的重要角色，巴黎上流社会艺术品鉴赏家。 需要称谓时用斯万先生；不擅加源文未出现的名字。 禁用译法: 史万 原文别名: M. Swann |
| Louis XIV | 路易十四 | le grand Roi→大王（指路易十四） |
| Monseigneur | 主教大人 | 对王室成员的尊称；本章指巴黎伯爵，作「殿下」。宗教语境（如主教）才作「主教大人」，按语境判断。 |
| ennuyeux | 讨厌家伙 | 第003章；圈内排斥标签，不是叙述者的客观判断。 |
| grand-père | 外祖父 | 叙述者的外祖父（阿梅代），斯万老父挚友，爱读报。全书统一译「外祖父」（第1章译文已用）。首现第1章。 |
| hôtel | 公馆 | 贵族宅邸语境作「公馆」（un hôtel de la rue de…）；旅馆语境作「酒店」（如 Grand-Hôtel）；maître d'hôtel 作「膳食总管」。按语境判断，不一律译「旅馆」。首现第1章。 |
| salon | 沙龙；客厅 | 第003章；前者指社交圈，后者指房间，按语境判断。 |

## 阅读与使用方法

1. **行号**：`L数字` 是中文 Markdown 原文件的物理行号，可直接在编辑器跳转定位。问题摘录与该行文本逐字匹配（包括原有 Markdown 标记）；建议译法是**局部替换候选**，若涉及跨句衔接，须在完整段落中再读一遍。
2. **等级**：A＝实质意义偏差／添减事实；B＝读者难理解的歧义、双关、指代、典故；C＝欧化句法、生硬搭配、语体不自然；D＝可选处理、保留特殊修辞或加注。A级判断也可能因校勘底本、上下文而需要再次确认，不等于学界定论。
3. **不可机械替换**：译文中有意错拼的仆人书信、贵族的粗俗语言、陌生化比喻和不合常规的心理分析，不能一律“润顺”。被标记为“保留／注释”的条目不表示该词本身有错。
4. **覆盖边界**：这是对全篇进行的**系统化语言筛查与重点参校**，不是有审校员逐字盖章的“零遗漏校样”；尤其不把无标记的句子谎称为已经证明毫无错误。配套的逐句定位表列出所有切分句段，方便后续逐条复核。

## 优先改动的A级问题

- **L7**｜原：`年末最后一场舞会`；问题：语境明确是夏末，原文“l'année”不等于“年末”；建议：**这一年最后一场舞会**。
- **L13**｜原：`下巴上涂着黑乎乎的肥皂沫`；问题：原文只说“menton noir”发黑的下巴，未提黑色肥皂沫；建议：**胡茬尚未刮净、下巴发黑的模样**。
- **L13**｜原：`年轻的主妇`；问题：原文“jeune ménagère”是善于料理家务的年轻女子，并不能据此认定已婚；建议：**一个会料理家务的年轻姑娘**。
- **L21**｜原：`阿尔贝蒂娜便要我继续开到圣克卢去`；问题：叙述者和她乘车，原文“demanda de poursuivre”仅要求继续前往，并非由“我”驾车；建议：**阿尔贝蒂娜便提议继续乘车前往圣克卢**。
- **L51**｜原：`极度尖锐的种姓式附庸风雅`；问题：“snobisme de caste”侧重门第歧视与势利，不能只译为追求风雅；建议：**一种极端的门第势利心理**。
- **L117**｜原：`福音式附庸风雅`；问题：法语“snobisme évangélique”讽刺的是以福音话语装点门第势利，非文艺意义的附庸风雅；建议：**披着福音外衣的势利心理**。
- **L181**｜原：`中心化倾向的“团体”`；问题：法语“corps tant soit peu centralisé”，中文“中心化”易引入现代组织／计算机术语；建议：**任何多少有些集权或等级组织的团体**。
- **L237**｜原：`附庸风雅之事与利益之事`；问题：此处“snobisme”是社交地位势利，而非文学艺术的附庸风雅；建议：**追逐名流地位与计较现实利益这两种事情**。
- **L455**｜原：`附庸风雅的人`；问题：多处“snob”主要是攀附上流社会的势利眼，并非追求艺术雅趣；建议：**一心攀附名流的人／势利眼**。
- **L561**｜原：`附庸风雅`；问题：仍属门第与沙龙势利的“snobisme”，不宜让人误解为追求文艺趣味；建议：**势利／攀附上流社会**。
- **L611**｜原：`很附庸风雅`；问题：人物讨论“snob”，说的是攀附名流的势利心理，不是文学艺术趣味；建议：**很势利／一心巴结上流社会**。
- **L613**｜原：`他还没被接纳，这份附庸风雅也无从施展`；问题：原文“snobisme”与被贵族承认有因果，附庸风雅失焦；建议：**他还没真正混进圈子，想攀附也无从攀起**。
- **L953**｜原：`留下信纸`；问题：法语“gardant le contenu”指莫莱夫人将信纸自留，拿信封当名片；现译会被读成留下信纸给公爵夫人；建议：**她把信纸留在自己手里，只将写着姓名的信封折起一角当作名片**。

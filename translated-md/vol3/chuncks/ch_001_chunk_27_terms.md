| Swann | 斯万 | 核心人物姓氏（Charles Swann，夏尔·斯万）。首次出现于第 0 章（书名及题献页）。贯穿全书的重要角色，巴黎上流社会艺术品鉴赏家。 需要称谓时用斯万先生；不擅加源文未出现的名字。 禁用译法: 史万 原文别名: M. Swann |
| Bontemps | 博纳唐 | 博纳唐夫人（Mme Bontemps）为公共工程部部长办公厅主任之妻、阿尔贝蒂娜的姑母，斯万家的常客；译名用「博纳唐」，禁用「邦唐」「邦当」。 |
| Albertine | 阿尔贝蒂娜 | 人名，统一作「阿尔贝蒂娜」。本章（vol3 第 1 章）仅被提及：她是博纳唐夫人的侄女，叙述者从希尔贝特与斯万口中听到其名，尚未认识、未见面。不得写成本章在场人物。禁用译法: 艾伯丁、阿尔贝汀 |
| Gilberte | 希尔贝特 | 斯万与奥黛特之女；本章香榭丽舍游戏的中心人物，叙述者少年之恋的对象。全名 Gilberte Swann→希尔贝特·斯万。禁用译法沿用全书。 |
| chef de cabinet | 办公室主任 | 部长办公室主任；希尔贝特误用此职，斯万纠正为 directeur du cabinet（办公厅主任）。 |
| Mme Swann | 斯万夫人 | 即奥黛特；本章她在布洛涅树林散步，路人低语其旧名 Odette de Crécy。叙述者只称斯万夫人，不点破。 |
| Odette | 奥黛特 | 与德·克雷西夫人、斯万夫人是同一人；黛奥特为转录中的疑误写法，不采纳。本章为背景人物。 禁用译法: 黛奥特 |
| directeur du cabinet | 办公厅主任 | 部长办公厅主任（directeur du cabinet），位在部长之下而总揽实务；与 chef de cabinet（办公室主任）不同，斯万特意纠正希尔贝特。 |
| Légion d'honneur | 荣誉军团 | 法国国家勋位；grand cordon→大绶带。首现第1章。 |

| Théodose | 狄奥多西 | 「狄奥多西国王」，普鲁斯特虚构的访法外国君主（时评热点）；音译，不加现实对应，不译「狄奥多修」。 |
| Travaux publics | 公共工程部 | ministère des Travaux publics；博纳唐先生任其部长办公厅主任。 |
| Verdurin | 维尔迪兰 | 复数指维尔迪兰夫妇或维尔迪兰一家，依句法。 禁用译法: 韦尔迪兰、维乐迪兰 原文别名: les Verdurin |
| grand-père | 外祖父 | 叙述者的外祖父（阿梅代），斯万老父挚友，爱读报。全书统一译「外祖父」（第1章译文已用）。首现第1章。 |
| hôtel | 公馆 | 贵族宅邸语境作「公馆」（un hôtel de la rue de…）；旅馆语境作「酒店」（如 Grand-Hôtel）；maître d'hôtel 作「膳食总管」。按语境判断，不一律译「旅馆」。首现第1章。 |
| papa | 爸爸 | 儿语称谓；mon père 依语境译父亲/爸爸。首现第1章。 |

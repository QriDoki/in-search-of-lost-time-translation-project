| Charlus | 夏吕斯 | 〔称谓〕裸形 Charlus 作「夏吕斯」。三种形式严格随源文：`M. de Charlus`→「夏吕斯先生」、`baron de Charlus`／`le baron`（含 `du baron`）→「夏吕斯男爵」、裸形→「夏吕斯」。**不得互换，禁用「夏吕斯男爵先生」**。本章 131 处 M. de Charlus、38 处 le baron、1 处 baron de Charlus |
| M. de Charlus | 夏吕斯先生 | 〔称谓〕本章 131 处。战时彻底转向亲德与失败主义；身体沉重、夜间出入朱皮安旅店；自称 « Je suis prince »（「我是亲王」）。维尔迪兰夫人诬其为普鲁士间谍、预言其死，**均属人物之言，不得写成叙述事实** |
| le baron | 夏吕斯男爵 | 〔称谓〕同 `baron de Charlus`；法语叙述中以 « le baron » 代指，属变体而非新人物 |
| Jupien | 朱皮安 | 〔人物〕裁缝，后谋得部里职位。本章：受夏吕斯之托经管旅店（`factotum`），为男客与青年牵线；叙述者在此撞见夏吕斯受鞭打。禁用「朱皮耶」「儒皮安」「朱比安」 |
| Françoise | 弗朗索瓦丝 | 〔人物〕女仆。本章：为「可怜的俄国人」抱不平；把 Boche 念成 « Bbboches »；怀疑「我们也不比他们好」；侄儿在贝里欧巴克阵亡。禁用「弗朗索瓦斯」 |
| Bloch | 布洛克 | 〔人物〕先以「近视」为免役宣言，被判合格后立刻改口主战；与圣卢街头争吵，骂军官「镀金的公子哥」 |
| Mme Swann | 斯万夫人 | 〔称谓〕奥黛特的旧称；本章「斯万夫人说『我设法染上了那讨厌的流感』」为旧语的回响 |
| duc de Guermantes | 盖尔芒特公爵 | 〔称谓〕与 `M. de Guermantes` 同译 |
| Swann | 斯万 | 〔人物〕已故；夏吕斯说他若用巴尔扎克书信里的粗话会痛苦至死 |

| Maurice | 莫里斯 | 〔人物〕受雇鞭打夏吕斯的青年；后文的「工人」 |
| le jeune homme de vingt-deux ans | 二十二岁的年轻人 | 〔人物〕因「才二十二岁、只当了六个月兵」而相信自己不会死；后文大谈「吃软饭」 |
| perme | 休假 | 〔战争〕permission 的军人口语缩略；« un soir de perme »。可加引号示意俚语 |

| Croix de guerre | 战争十字勋章 | 〔战争〕法国 1915 年设立；本章指圣卢遗失在朱皮安旅店的那一枚、莫雷尔战后所得的那一枚 |
| Boche | 德国佬 | 〔战争〕法国对德军的贬称；« les Boches »。**禁用「博什」「德国人」**（后者是中性 Allemand）。弗朗索瓦丝的 « Bbboches » 保留其迟疑语气 |

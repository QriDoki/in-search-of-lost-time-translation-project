## 一、正文逐段校勘

### 第一组：睡眠、记忆、夏吕斯与汽车旅行（中译 L2–L60）

**标题 / ZH L2 · B · #001**  
原句锚点：“横渡大西洋号”的各个车站  
**建议**：题名可保留此译，但建议注明它是海滨支线小火车的戏称，并非远洋轮船的站点。  
**理由**：标题中的船名意象有意夸大慢车的声势，注释应避免使读者误以为有一条真实的跨大西洋路线。

**P01 / ZH L4 · B · #002**  
原句锚点：那个眼神不大正派的侍应生  
**建议**：可改为“那个眼神鬼祟的跑堂小伙计”。  
**理由**：louche 不只指品行不端，写目光宜传达鬼祟、可疑，不能擅断其道德。

**P01 / ZH L4 · B · #003**  
原句锚点：他和家里另外几个更走运的孩子的母亲  
**建议**：建议重组为“他母亲——也是家中另外几个比他走运的孩子的母亲——”。  
**理由**：插入语修饰关系易令读者误解为两位母亲。

**P01 / ZH L4 · B · #004**  
原句锚点：他姐姐却什么好的都舍得享用  
**建议**：“他姐姐如今却样样讲究，什么都不肯委屈自己”。  
**理由**：ne se refuse rien 不是舍得消费的意愿，而是对自己有求必应。

**P01 / ZH L4 · B · #005**  
原句锚点：在衣柜或五斗柜里拉上一泡  
**建议**：“在衣柜、五斗柜里大小便一通”是否必要，须核定 se soulager 的不定指范围；若不明确，不宜把它限定为小便。  
**理由**：法文委婉动词有意留下不体面的想象空间；中文“拉上一泡”口语模糊且可能误指定性。

**P01 / ZH L4 · B · #006**  
原句锚点：总得有人是苦命人，好让我现在有了钱，能稍微恶心恶心他们  
**建议**：可作“世上总得留些穷苦人，好让我如今有了钱，可以稍稍欺负欺负他们”。  
**理由**：emmerder 是羞辱、使人受罪的粗口；“恶心恶心”偏重让人厌恶，可能削弱阶级虐待之意。

**P02 / ZH L6 · C · #007**  
原句锚点：仿佛从未发生、一笔勾销  
**建议**：“索性认作从未发生”即可；或保留“一笔勾销”，但不必并置。  
**理由**：两种近义表达叠加，压低哲学命题的清晰度。

**P03 / ZH L8 · B · #008**  
原句锚点：入夜时的天光  
**建议**：“黄昏将尽时的日光”。  
**理由**：法文 comme le jour quand le soir tombe 强调白昼衰弱，不是夜晚的天光。

**P03 / ZH L8 · B · #009**  
原句锚点：睡眠就像我们另外拥有的一套住宅  
**建议**：“睡眠仿佛是我们另有的一处住所”。  
**理由**：另外拥有的一套住宅是现代房产语感；原文是感知空间的比喻。

**P03 / ZH L8 · B · #010**  
原句锚点：住在里面的那个族类  
**建议**：“居住其间的族群”。  
**理由**：“那个族类”指代不明，压弱对梦境人群的拟人。

**P03 / ZH L8 · B · #011**  
原句锚点：有时又长得多：反过来，觉得只合了一会儿眼  
**建议**：宜改“有时反倒慢得多：以为只打了个盹，却已睡过整整一天”。  
**理由**：原句容易把‘睡得久’和‘主观时间流得慢’混为一谈；应标明主观与钟表时间对照。

**P04 / ZH L10 · B · #012**  
原句锚点：跳过途中的驿站  
**建议**：“一站站飞掠而过”亦可。  
**理由**：brûler les étapes 既是跳过阶段的习语，又与车驾意象呼应；“驿站”具体化可选，但宜保持疾驰感。

**P04 / ZH L10 · B · #013**  
原句锚点：头脑被倒空了，倒掉的是那个在此之前一直构成他生活的过去  
**建议**：“头脑已被清空，先前构成生命的全部往事仿佛一扫而空”。  
**理由**：第二个“倒掉”与前句机械重复，且意象显得笨重。

**P04 / ZH L10 · B · #014**  
原句锚点：睡眠中的那些念头被一件遗忘的斗篷卷走  
**建议**：“梦中的思绪被遗忘的厚篷遮蔽”。  
**理由**：chape d'oubli 在此偏重覆盖与隔绝，而非卷走；避免把‘无法及时返回’译成‘被带走’。

**P04 / ZH L10 · B · #015**  
原句锚点：于是，从我们自以为穿越过的那场黑色风暴里  
**建议**：删去重复的“于是……里……从中”：可作“我们仿佛刚穿过一场漆黑的风暴……醒来时仍横卧着”。  
**理由**：空间起点连用形成不必要的回环。

**P04 / ZH L10 · B · #016**  
原句锚点：在我们以为自己是在做与睡觉全然不同的事的时候去捕捉睡眠  
**建议**：“要趁自以为在做别的事时，让睡眠忽然攫住我们”。  
**理由**：原句累赘，且 prendre le sommeil 的主动/被动悖论应尽量保留。

**P05 / ZH L12 · B · #017**  
原句锚点：一层麻絮，妨碍了睡眠者听见记忆彼此间的低语  
**建议**：可保留“麻絮”并加注：étoupe 是隔音/填塞用的粗纤维；译为“一层填塞耳目的麻絮”可读性更好。  
**理由**：该具体材质与意识隔绝有内在联系。

**P05 / ZH L12 · B · #018**  
原句锚点：外祖母；从前即便她病入膏肓，也会过来  
**建议**：建议复核法文时间关系，改成“再不会像从前那样由外祖母应铃，而来的是……”，别把“病入膏肓的外祖母”写成确曾来应铃的独立事实。  
**理由**：此处把梦中的往昔、外祖母将死的讯息和醒后的预感叠合，应保持时间层次。

**P05 / ZH L12 · C · #019**  
原句锚点：一个无动于衷的贴身男仆  
**建议**：“一个与此事毫不相干的贴身男仆”。  
**理由**：indifférent 可指不相干的旁人，不必判定男仆冷酷。

**P06 / ZH L14 · B · #020**  
原句锚点：这仿佛白白损失了一份好处  
**建议**：“仿佛一笔财富就这么白白丢了”。  
**理由**：bien perdu 指失去可供享用的资源，现译“好处”稍平。

**P07 / ZH L16 · C · #021**  
原句锚点：我说过两个时间；也许只有一个  
**建议**：可加一条解释性旁注，说明此处不是‘醒时一小时等于梦中一小时’，而是追问深层睡眠是否根本不属于时间范畴。  
**理由**：避免把时间哲学的假设误读为科学断言。

**P08 / ZH L18 · B · #022**  
原句锚点：由一及彼地推论  
**建议**：“由此推及药物睡眠时”或“把两种睡眠联想在一起”。  
**理由**：汉语“由一及彼地推论”书面生硬，且指代模糊。

**P08 / ZH L18 · C · #023**  
原句锚点：同事——对不起，是同仁  
**建议**：建议补注 confrère 与 collègue 的称谓差别及说话人纠正称呼时的卖弄。  
**理由**：这一停顿属于人物口吻，而非冗余。

**P09 / ZH L20 · B · #024**  
原句锚点：我的亲身经验所得，却恰好相反  
**建议**：“我的切身经验却恰恰说明了相反的情形”。  
**理由**：名词“所得”与“经验”搭配僵硬。

**P10 / ZH L22 · A? · #025**  
原句锚点：波德莱尔某句让我颇感疲倦的诗  
**建议**：须重点核对原文：‘让我颇感疲倦’究竟修饰引文还是叙述者记诵之劳，不宜轻率定为作者对波德莱尔的评价。  
**理由**：现译读来像叙述者厌烦这句名诗；建议对照法文上下句消除歧义。

**P10 / ZH L22 · B · #026**  
原句锚点：成了个疯子  
**建议**：如原文保留 fou，应考虑“仿佛成了疯子”以标明自我惊异，而不是医学诊断。  
**理由**：描述注意/感知丧失的修辞不可读作真正患病。

**P10 / ZH L22 · B · #027**  
原句锚点：我们拥有自己的全部记忆，所缺的只是把它们回忆起来的能力  
**建议**：前后两次出现类似论断，建议将第二次处理为带追问的反复，保留同一措辞以显出辩论转折。  
**理由**：重复是叙述者与柏格森命题角力的关键，不能随手换成不同的同义词。

**P11 / ZH L24 · B · #028**  
原句锚点：那么知识反过来，是否也有梦的那种不真实呢  
**建议**：“那么反过来，我们自以为确知的事，难道也像梦一样不真实吗？”  
**理由**：“知识反过来”主谓衔接不自然。

**P12 / ZH L26 · B · #029**  
原句锚点：睡眠很少这样把一些不随它一同死去的记忆抛进醒着的生活  
**建议**：“睡眠很少把那些不随它消散的记忆，像这样抛到清醒的生活里”。  
**理由**：限制关系错位，尤其“这样把一些……”造成多余停顿。

**P13 / ZH L28 · B · #030**  
原句锚点：单凭这一点，我就觉得自己歇得透透的  
**建议**：“单凭这些荒诞的梦，我便确信自己睡得十分深沉”。  
**理由**：歇得透透的口吻偏现代口语，可作为叙述者自欺的轻快语调，但须全篇一致。

**P14 / ZH L30 · B · #031**  
原句锚点：那位客人不是别人，正是康布雷梅尔家一位表亲的男仆  
**建议**：可改“与他共餐的，竟是康布雷梅尔家一位表亲的男仆”。  
**理由**：原句将‘客人’误导成来拜访叙述者的人。

**P14 / ZH L30 · B · #032**  
原句锚点：他们中间开出一条路来  
**建议**：“从他们中间穿出一条道来”。  
**理由**：主语是夏吕斯，现译像是把路作为物体‘开出’。

**理由**：科学化‘性征’突然破坏引诗与情色反讽之间的语域；如原文明确生理成熟则可保留更精准用词。

**P15 / ZH L32 · B · #034**

**建议**：“他本希望对方更有男子气概”。

**P15 / ZH L32 · B · #036**

**P17 / ZH L36 · B · #041**

## 二、增补注解建议（建议采用“术语｜简注｜解释目的”的结构）

注解不必把小说改造成历史辞典。以下主要补充**妨碍中文读者理解情节、典故和反讽**的注释；已提示“待核”的材料不得在未查考前写成定论。优先将解释放在第一次出现处，人物习语、同类植物品种与重复词源不必反复加注。

**N001 · 中译 L2 · 可直接说明** — **« Transatlantique »**：字面是“横渡大西洋的船”，在章题中用作海滨小铁路的戏称，形成豪华航海和缓慢地方列车的反差；不应注成实际大西洋客轮。

**N002 · 中译 L4 · 可直接说明** — **chasseur / liftier**：前者为酒店跑腿侍者，后者为电梯员，职责不同；“开电梯的”“侍应生”全章应统一，以免读者误以为人物前后换岗。

**N003 · 中译 L4 · 可直接说明** — **carrosse / voiture**：乘用马车与后来新式汽车在本章具有不同时代感，建议译注第一次出现时区分；车夫和汽车司机也不应混称。

**N004 · 中译 L4 · 文本解释** — **印度王子**：酒店仆役家庭借贵族/王室情人的财富上升、又带羞辱穷人的言辞，具有强烈阶级讽刺；“另一路”暗指其弟弟受到的不同形式供养。

**N005 · 中译 L8–L17 · 主题释义** — **睡眠的第二寓所**：睡眠被写作另一套住所，拥有门铃、访客、男女变形和独立的时间秩序；可在首次出现处合注一次，之后不必每种奇异景象都重复解释。

**N006 · 中译 L10 · 主题释义** — **太阳车驾与陨石**：古典太阳神车驾意象和现代“着陆”词汇混用；陨石既是唤醒的外来刺激，也在下文“铃声残留”处回响。

**N007 · 中译 L12 · 可直接说明** — **麻絮 étoupe**：粗麻纤维可用于填塞、隔音，作者借此解释醒后无法听见梦中意识活动的隔绝状态。

**N008 · 中译 L16–L22 · 需核原始言论** — **柏格森 Henri Bergson**：法国哲学家，关注持续、记忆、意识等议题。本章引述并非可直接视作柏格森的确证观点，叙述者明确说话语经挪威哲学家、布特鲁转述。

**N009 · 中译 L18 · 史实待补来源** — **埃米尔·布特鲁 Émile Boutroux**：法国哲学家；所谓“同事/同仁”的自我纠正，有学术圈称谓与身份讲究的滑稽。

**N010 · 中译 L18 · 可直接说明** — **佛罗那 Véronal**：早期巴比妥类催眠药物的商标名称。这里只需要简注时代用途与记忆效应的文学讨论，不应把小说描述直接作为现行用药建议。

**N011 · 中译 L22 · 可直接说明** — **普罗提诺与波菲利**：新柏拉图主义哲学家普罗提诺及其学生波菲利；作者拿高深哲学的仍可讨论，与日常事务的记忆受损作对照。

**N012 · 中译 L22 · 主题释义** — **出生以前的记忆**：从未被唤回的过去推到出生之前，再推到别人的身体或另一颗星球，是哲学思辨/设想，不是作者声称证明轮回。

**N013 · 中译 L22 · 典出待核** — **波德莱尔的 tympanon**：需追查《恶之花》具体诗篇和句子，单注“手鼓”无法说明引句为何被拿来与忘记俗务对比。

**N014 · 中译 L28 · 主题释义** — **梦中夏吕斯年逾一百、殴打母亲**：夸张而荒唐的梦不是给人物增加传记经历，而是叙述者以梦的悖常来推断自己睡得很沉。

**N015 · 中译 L30 · 可直接说明** — **利未人 lévites**：《圣经》中利未支派与祭司服务有关；作者把酒店年轻侍者比作圣殿从祭人员，是圣俗对位的讽刺。

**N016 · 中译 L30 · 出处待核** — **若莎贝特 / 《阿达莉》**：拉辛悲剧《阿达莉》中的人物；夏吕斯截引并拒绝继续念出招呼女儿们的台词，令熟读古典戏剧的姿态变成择偶偏好的遮掩。请核该引文具体幕场。

**N017 · 中译 L36 · 可直接说明** — **欧律克勒亚 Euryclée**：《奥德赛》中识破奥德修斯身份的老乳母；比较重点是老仆先于客人看穿一个人的真实阶层身份。

**N018 · 中译 L40 · 主题释义** — **伊特鲁里亚式红发**：这里把侍应生的相貌放进古代雕塑/人种美学的视觉类型中；不宜将“更古老的血统”当严肃人类学结论。

**N019 · 中译 L40 · 可直接说明** — **孔特雷克塞维尔 Contrexéville**：法国矿泉水产地；文中的饮用习惯带保健、年龄与酗饮后调养的社会讽刺。

**N020 · 中译 L40 · 可直接说明** — **彼得三次不认耶稣**：《新约》福音书中彼得三次不认主；夏吕斯借用此语形容男仆拒绝赴约，表明他把失意自比宗教受难。

**N021 · 中译 L40 · 可直接说明** — **诸圣相通**：基督教信经中的“诸圣相通”观念，被夏吕斯用于解释亡友仿佛通过相似者介入现世，具有自我戏剧化色彩。

**N022 · 中译 L42 · 主题释义** — **柏拉图式关系**：原文用作可能不涉及肉体行为的亲密关系，不能据此断言夏吕斯与莫雷尔关系完全如此。

**N023 · 中译 L44 · 可直接说明** — **俄刻阿尼得斯 Oceanides**：希腊神话中俄刻阿诺斯的女儿们，常与水域宁芙相关；在此是鸟声和水气的神话化称呼，应说明为比喻。

**N024 · 中译 L44–L47 · 主题释义** — **汽车重写距离**：“距离=空间/时间”意指交通速度改变了地点的可达性与心中的地理尺度，属于艺术知觉论，不是严格物理量定义。

**N025 · 中译 L44 · 可直接说明** — **七里靴**：欧洲童话中的神奇长靴，穿上后一步可跨七里；在文中是汽车使原本相隔不同日子的景点同日可见。

**N026 · 中译 L46 · 可直接说明** — **哈德良的别墅**：罗马皇帝哈德良在蒂沃利附近的别墅群，以对各地建筑与风景的模拟著名，呼应拉斯佩利埃花园缩纳全海岸“景”的设计。

**N027 · 中译 L46 · 主题释义** — **乡间沙龙与巴黎豪宅**：巴黎私人花园稀缺，乡下显赫来宾稀缺；作者故意交叉比较两种稀缺资源，讽刺社交价值由环境决定。

**N028 · 中译 L46 · 可直接说明** — **博蒙与《包法利夫人》《帕尔马修道院》**：主角设想自己在小说之外遇见包法利夫人和桑塞维里娜，意在揭示艺术场景赋予人物的封闭独特性；后者为司汤达小说人物。

**N029 · 中译 L48 · 文本交叉** — **虚报里程**：司机与莫雷尔通过虚增汽车公里数分利，后来又以更低数字向公司申报；建议一条注释串联两种欺骗，否则读者难分收付款的两端。

**N030 · 中译 L48 · 品种待核** — **玫瑰品种名称**：以罗斯柴尔德男爵夫人、涅尔元帅夫人为名的花卉品种，突显夏吕斯对绚丽贵族名称的矛盾爱憎；具体园艺品种应查种植史。

**N031 · 中译 L50 · 史实核对** — **肖邦和斯塔马蒂**：肖邦是波兰裔法国活动时期作曲家，Camille Stamaty 是十九世纪巴黎钢琴家/教师；此处男爵追忆未听到肖邦本人演奏的可能性。

**N032 · 中译 L52 · 可直接说明** — **贝多芬第十五弦乐四重奏**：可注明 Beethoven String Quartet No. 15 in A minor, Op.132；作者把为弦乐所写的作品改编成钢琴，与其音色美学争论相关。

**N033 · 中译 L52 · 可直接说明** — **皮媞亚 Pythie**：德尔斐阿波罗神谕的女祭司；用她形容演奏家像受神灵附体般弹奏，带挖苦而非单纯赞叹。

**N034 · 中译 L52 · 可直接说明** — **灵媒 médiumnimique**：十九世纪末至二十世纪初的通灵/灵媒文化背景；必须结合夏吕斯对莫雷尔演奏“神启”的夸张做讽刺解释。

**N035 · 中译 L52 · 品种待核** — **好基督徒梨**：Bon Chrétien 是欧洲梨品种名；最好和阿夫朗什的善良路易丝、科米斯的多耶内等成串解释为品种而不是宗教信徒。

**N036 · 中译 L52 · 出处待核** — **《埃斯卡巴尼亚斯伯爵夫人》**：莫里哀的喜剧人物/剧作名称与水果摆阔之间形成文化卖弄；原文是否准确引自该剧具体台词，须查法文戏剧版本。

**N037 · 中译 L54 · 主题释义** — **追逐幽灵**：fantômes 是欲望所投射的对象：希尔贝特、盖尔芒特公爵夫人、阿尔贝蒂娜轮流成为幻象；与作品中非自愿记忆的复现有关，但不等同。

**N038 · 中译 L56 · 主题释义** — **马尔库维尔教堂的修复**：埃尔斯蒂尔反感修复的石料，叙述者却从落日光线看到了另一种画面价值；这是艺术之“客观遗物”与“瞬时知觉”的紧张。

**N039 · 中译 L56 · 可直接说明** — **卡尔瓦多斯酒与苹果酒**：Normandie 地区出产苹果白兰地 Calvados 与苹果酒 cidre；若需加注只解释饮品类型与产区，不必引入现代商品广告。

**N040 · 中译 L56 · 词源待核** — **圣马尔斯勒韦蒂**：地名后缀 le Vêtu 字面“穿衣的”，情节明确安排布里肖后续释词源；建议此处先标双关，后文再给出处。

**N041 · 中译 L58 · 主题释义** — **萨尼埃特**：老友怕惹人厌却越发惹人不耐烦，是社交误会的典型；他在叙述者眼中应得到更多怜悯，不宜注成单纯怪人。

**N042 · 中译 L62 · 文本解释** — **百日咳**：开电梯者向客人咳嗽，叙述者为回避传染而说的礼貌话和内心话冲突；这是服务礼仪与身体风险的戏剧性反差。

**N043 · 中译 L62 · 可直接说明** — **圣西门《回忆录》**：Saint-Simon 是法国宫廷回忆录作者，对贵族座次、尊号等级特别敏感；拿来比拟母亲对仆人称呼的介意。

**N044 · 中译 L62 · 主题释义** — **飞机初见**：叙述者把早期飞机写成希腊半神显形，显示新技术未消灭神话感，反而改变了它的呈现方式。

**N045 · 中译 L64–L68 · 情节脉络** — **豪斯勒兄弟**：哥哥被支走，弟弟被诬饮酒并遭伙计殴打；应明确同谋如何利用时间差构陷，及司机由此获得职位。

**N046 · 中译 L68 · 出处待核** — **丰塔纳与夏多布里昂**：莫雷尔反复引用“工作吧，成名吧”，借名人话装饰自己；引语的传承与出典需要原文/历史文献双重核查。

**N047 · 中译 L72 · 可直接说明** — **希腊火**：历史上指可燃性强且极具传奇色彩的拜占庭武器燃烧剂，此处比喻夕阳被室内镜玻璃反射为燃烧的海景。

**N048 · 中译 L72 · 制度待核** — **首席院长 premier président**：法国法院特定审判机构首长的头衔，不是大学“院长”，也不必自动等同今天某一种法院职衔；建议注法国司法制度的历史称谓。

**N049 · 中译 L74 · 主题释义** — **无功利心的文化**：culture désintéressée 指不以直接收益衡量的文学、艺术与通识修养，与谋生公文工作对照；不是要求人完全无私。

**N050 · 中译 L76 · 拉丁文待校** — **“In prœliis non semper”**：男爵藏书票拉丁文座右铭，与“Non sine labore”并列，可分别给字面释义，解释贵族藏书/箴言的表演功能。

**N051 · 中译 L76 · 可直接说明** — **罗马家神 Penates**：家庭守护神，不属基督教；戈达尔夫人怕冒犯自己误认的犹太信徒，结果改用另一个异教术语，构成讽刺。

**N052 · 中译 L80 · 语源待核** — **funiculeur**：与 funiculaire（缆车）相关的滑稽造词；不确定其中性暗示的具体词源时应如实写“人物以生造词戏谑男爵”，而非强行落实为单一现代中文粗话。

**N053 · 中译 L80 · 主题释义** — **“这两位小姐”**：小圈子戏称男爵与莫雷尔，注释应说明说话人通过女性化进行性取向嘲笑，而不暗示两人的性别身份改变。

**N054 · 中译 L82 · 可直接说明** — **德雷福斯事件**：1890年代法国军事冤案及其造成的政治阵营分裂，卷入贵族沙龙与知识分子；人物被叫作“德雷福斯派”含强烈社会立场。

**N055 · 中译 L88 · 主题释义** — **“两座亭子”**：一座是人相信他人在背后如何看待自己的想象，一座是他人实际的议论；文学视觉化地呈现我们对自身社会形象的盲点。

**N056 · 中译 L90 · 可直接说明** — **雨果《奥林匹欧的悲哀》**：雨果的 Tristesse d’Olympio 含爱情记忆与失落；斯万挪用到巴尔扎克男性关系，形成带讥谑的跨作品隐喻。

**N057 · 中译 L90 · 书目待核** — **《交际花盛衰记》的分卷标题**：核法国书目中的《幸福的以斯帖》等分卷原题并列在注释中，建议提供原文而非只留不可检索的自由译名。

**N058 · 中译 L90 · 文本解释** — **拉伯雷的索邦式造词**：布里肖故作古奥、堆叠 Sorbonne 词根，嘲笑学院学究，同时暴露其自身掉书袋倾向。

**N059 · 中译 L90 · 可直接说明** — **苏格拉底与“认识你自己”**：γνωθι σεαυτόν 通行正字为 γνῶθι σεαυτόν，是德尔斐箴言，戈达尔误当苏格拉底原创；原文故意拼错时应保留并注。

**N060 · 中译 L90 · 文本解释** — **夏多布里昂牛排**：同名的文豪 Chateaubriand 与法式牛排 chateaubriand 被戈达尔拼接成笑话，“配苹果”涉及食物与人名的俗套联想。

**N061 · 中译 L90 · 可直接说明** — **卡迪尼昂亲王妃的秘密**：Balzac《卡迪尼昂亲王妃的秘密》描写女主人公担心恋人知道过去坏名声，夏吕斯借她反观自身被发现的惶恐。

**N062 · 中译 L102–L106 · 出典待核** — **贵族拉丁格言**：Atavis et armis、Tantus ab uno splendor、Mort m’est vie，以及法语 Condescendre n’est pas descendre，都被男爵用来表演祖先与勇武；拉丁词形/出处各自需要独立核校。

**N063 · 中译 L104 · 可直接说明** — **决斗“证人” témoins**：旧式决斗双方的副手或调停见证人，并非审判中的目击证人；它解释为什么男爵能用一套正式程序制造、又化解决斗。

**N064 · 中译 L104 · 饮品待核** — **马扎格兰与格洛里亚**：法国旧式咖啡/酒精饮料名称，男爵以老派餐饮掌故维持礼貌，而戈达尔误将其触碰当情欲攻势。

**N065 · 中译 L104 · 出典可查** — **奥维德拉丁句**：“Os homini sublime dedit caelumque tueri …” 出自奥维德《变形记》第一卷开头关于人类仰望天空的句群；戈达尔乱用来摆学问。

**N066 · 中译 L106 · 可直接说明** — **拉斐尔与多俾亚**：《多俾亚传》中天使拉斐尔护送多俾亚的故事，夏吕斯将自己与所爱的小提琴手比作精神父子/受护者。

**N067 · 中译 L110 · 文本解释** — **“宫殿大饭店”**：建筑门面与妓院性质错位，听不懂的贵客热情邀请两位体面女士来此，构成蒙昧自信的闹剧。

**N068 · 中译 L112 · 情节脉络** — **亲王与莫雷尔的秘密交易**：莫雷尔接受盖尔芒特亲王金钱，男爵却只知有神秘约会；妓院窥探时各方信息并不对称，不应以全知视角补写当时人物不知的事。

**N069 · 中译 L114 · 主题释义** — **泰坦群像**：神话中的泰坦巨人用于比喻爱情在心灵山峰上雕出暴怒、嫉妒、好奇等一群巨大力量。

**N070 · 中译 L120 · 可直接说明** — **verjus**：未熟葡萄榨成的酸汁/青葡萄，既是伯爵戒指的纹章图案又与姓氏谐音；不可只释为“葡萄很酸”。

**N071 · 中译 L122 · 主题释义** — **餐厅经理切小火鸡**：法式高级餐厅的桌边分切礼仪，被经理自夸成宗教祭祀、甚至另立纪年；一战停战的后见之明在旁白中插入。

**N072 · 中译 L126 · 可直接说明** — **《佩利亚斯与梅丽桑德》**：德彪西歌剧，1902年首演；外省绅士说“没什么意思”，与现代主义音乐的历史评价形成反差。

**N073 · 中译 L128 · 可直接说明** — **圣伯夫**：法国文学评论家，受普鲁斯特强烈批评；此处在侯爵太夫人倒序形容词的写信癖好里出现，用于比较文体趣味。

**N074 · 中译 L128 · 主题释义** — **“年轻夫妇”**：对已经不年轻的康布雷梅尔夫妇使用固化称呼，揭示社交圈对时间、婚姻身份与客套套语的滞后。

**N075 · 中译 L128 · 主题释义** — **贵族姓氏与污言**：夏吕斯故意把康布雷梅尔等姓氏和排泄词并列，这是人物粗俗偏见兼阶级表演；应在注释中明确并非可靠家族史。

**N076 · 中译 L130–L132 · 语源待核** — **地名词源学**：港口 fleur、诺曼语 budh、古诺尔斯语 holm/thorp、词根 pen 等均属布里肖的口头讲学，部分可能为民间词源；应注“布里肖的解释”，必要时另附现代地名学依据。

**N077 · 中译 L132 · 可直接说明** — **圣西尔 Saint-Cyr**：法国军事学校的关联，使唐西埃尔的军人和地名拉丁化玩笑呼应；所称 Dominus Cyriacus 的推导不应无校核写为正式词源。

**N078 · 中译 L134 · 可直接说明** — **布洛克引用赫利俄斯和许普诺斯**：赫利俄斯为太阳神、许普诺斯为睡眠神；布洛克以仿史诗的希腊神名描述闲谈，显得自负而造作。

**N079 · 中译 L134 · 神谱待核** — **克罗尼翁之女**：“克罗尼翁”通常指宙斯（克洛诺斯之子）；所谓羞耻女神及其亲缘应就原文查神谱，别凭字面造一位神。

**N080 · 中译 L136 · 重要语境** — **亵渎圣体的传说**：中世纪欧洲反犹宣传常有诬称犹太人亵渎圣体的指控，小说中男爵重述此类故事，必须注其歧视性、传言性质，不可作为事实。

**N081 · 中译 L136 · 可直接说明** — **奥尔良与波旁王朝继承权**：夏吕斯的“篡位”言论来自贵族正统派立场；所称“亨利五世”并非法国实际统治中的在位国王。

**N082 · 中译 L136 · 出处待核** — **《基督的童年》《圣周五之魅》**：伯辽兹清唱剧及带受难题材的音乐，与男爵对犹太人想象结合；第二作品对应哪位作曲家、准确中文名应查原文题名。

**N083 · 中译 L136 · 主题释义** — **从地名到地址簿**：同一条铁路的站名从早年的诗意、古族词源想象，变成随时可见友人的地图；末尾“结婚是发疯”伴随地理祛魅与情感冷却。


### 补遗：此前仅作结构性注释的三段（中译 L100、L132、L134）

**ZH L100 · 补校 #01**  
原句锚点：仍像面对一个上流社会的人那样，继续发作他的怒气  
**建议**：“他对莫雷尔发怒时，仍沿用对上流社会人士的那一套派头——或真或假，却大半已经不灵”。  
**理由**：“继续发作他的怒气”有病症发作的语感，且后半句省略主语。

**ZH L100 · 补校 #02**  
原句锚点：不肯为此打扰我表妹  
**建议**：若坚持“表妹”须在本章注释：这是叙述者在外人面前为阿尔贝蒂娜使用的称呼，不是直系亲缘事实。  
**理由**：避免把两人的暧昧关系当真表兄妹。

**ZH L100 · 补校 #03**  
原句锚点：那种在重大关头懂得担起那份崇高的人  
**建议**：“那种在紧要关头懂得作出崇高牺牲的人”可选。  
**理由**：“担起那份崇高”名词搭配不自然。

**ZH L100 · 补校 #04**  
原句锚点：我个人欠她一份情，而且我愿意欠着  
**建议**：可保留，但注此处夏吕斯把私人情绪困境夸大成道德债务，故意显得庄重。  
**理由**：人物自我戏剧化。

**ZH L100 · 补校 #05**  
原句锚点：他的快活全没了，脸也绷了起来  
**建议**：可作“他顿时没了笑意，沉下脸来”。  
**理由**：口语的“快活全没了”略不稳，但可作为莫雷尔态度骤变。

**ZH L100 · 补校 #06**  
原句锚点：Je suis au baron  
**建议**：注男爵藏书票本义“本书属男爵”，莫雷尔有意当作“我这个人属于男爵”的标记而拒收。  
**理由**：这是人身依附恐惧/文字双关的明确信号。

**ZH L100 · 补校 #07**  
原句锚点：Exspectata non eludet  
**建议**：可核拉丁文语法和原家徽，再译为“所盼望的终不会使人失望”，若原有旧译固定形式则附校记。  
**理由**：“所期待者”是人还是事关涉男爵的寄托。

**ZH L100 · 补校 #08**  
原句锚点：Sustentant lilia turres  
**建议**：须核拉丁语主谓格、原徽铭含义；在正文注释中指出男爵故意颠倒百合与塔楼的象征关系。  
**理由**：这不是普通的无主语名言，而是爱恋中的自我投射。

**ZH L100 · 补校 #09**  
原句锚点：Non mortale quod opto  
**建议**：“我所企求的并非凡间必死之物”，可注明这源于神话/拉丁诗文的典故（出处待查）。  
**理由**：“我所求者非必死之物”现代汉语难以理解。

**ZH L132 · 补校 #10**  
原句锚点：这几头四足动物等得不耐烦了  
**建议**：保留“这几头四足动物”，注明布洛克卖弄古典的讽刺腔，不宜改成纯粹“大马”。  
**理由**：口语与荷马式庄重混合的滑稽。

**ZH L132 · 补校 #11**  
原句锚点：把全部的礼貌都留给他  
**建议**：“反而会把全部心思都放在应酬布洛克上”。  
**理由**：原说法更像礼貌实体能被留下，反事实的因果不够清楚。

**ZH L132 · 补校 #12**  
原句锚点：一种神圣的羞耻，克罗尼翁之女  
**建议**：布洛克故作神谱语的引语与后面叙述者列举政治家、批评家、院士不助人的“羞耻”构成反讽。  
**理由**：不应只作古希腊人名说明。

**ZH L132 · 补校 #13**  
原句锚点：你在其中端坐的那座隐秘神庙  
**建议**：“他唯恐你安坐的那座隐秘神庙遭无知读者和记者闯入”或保留长句并消除主谓悬浮。  
**理由**：原文隐喻的叙述层次极深，易把批评家的借口写成好意。

**ZH L132 · 补校 #14**  
原句锚点：那些被恭恭敬敬摆到他坟头的花圈  
**建议**：保留。此段结尾是对借‘尊重’之名压制死者名誉的尖刻批评，与布洛克的沉默形成递进。  
**理由**：不宜为了精简长句删去最后一环。

**ZH L134 · 补校 #15**  
原句锚点：后来又坦白自己在博纳唐夫人面前诋毁过我  
**建议**：法文 m'avait déconsidéré chez Mme Bontemps，直指他令我在博纳唐夫人家名誉受损；可改“后来又承认曾在博纳唐夫人面前贬损我”。  
**理由**：“诋毁”可能带明知虚假恶意的额外判断，“贬损”相对稳妥。

**ZH L134 · 补校 #16**  
原句锚点：这个年轻的犹太人给夏吕斯先生留下的，却绝非坏印象  
**建议**：“但这位年轻犹太人给夏吕斯先生留下的印象，绝不是惹人厌烦”。  
**理由**：后文男爵深感吸引，原句“绝非坏印象”语气不足；亦应保持叙述者的修辞反差。

### 原文核对后的两项说明

- **ZH L46 “电车司机”**：法文对应词是 **wattman**，意为有轨电车的驾驶者；尽管本章这一场出游乘的是汽车，维尔迪兰夫人所引的话确实用了这个词。因此先前标为 A? 的“译错车辆”怀疑**不能成立**，应保留该称谓并可加注其中与乘车情境的反差。
- **ZH L52 “被他强暴过的姑娘”**：原文确有 **une jeune fille violée**，不能据中文措辞断言是词义误译。真正需要在语义上讲清的是：这发生在莫雷尔**尚在炫耀的想象情节**中，而不是已经发生、由叙述者查证的事件。

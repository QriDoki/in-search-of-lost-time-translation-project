| Albertine | 阿尔贝蒂娜 | 人名，统一作「阿尔贝蒂娜」。vol3 仅被提及为博纳唐夫人的侄女；vol4 仍只被提及；vol5 第 001 章正式登场——埃尔斯蒂尔画室介绍相识，与安德蕾、吉赛尔、罗丝蒙德等结成少女小团体，叙述者的爱情由此开始。禁用译法: 艾伯丁、阿尔贝汀 |
| Elstir | 埃尔斯蒂尔 | 虚构画家，叙述者在巴尔贝克结识（vol5 第 001 章正式登场：海滨大酒店初遇、画室长谈、《卡尔克蒂港》、为奥黛特所作的《萨克里邦小姐》小像）；其观看方式深刻影响叙述者的视觉，普鲁斯特以惠斯勒、透纳、莫奈等为部分原型，不得坐实为任何真实画家。禁用译法: 埃尔斯提尔、埃尔斯蒂。 |
| grand'mère | 外祖母 | 叙述者的外祖母（巴蒂尔德）；爱雨中散步、重品味轻等级。全书统一译「外祖母」（第1章译文已用；book_context_001 中「外婆」为笔误）。首现第1章。 |
| Odette | 奥黛特 | 与德·克雷西夫人、斯万夫人是同一人；黛奥特为转录中的疑误写法，不采纳。本章为背景人物。 禁用译法: 黛奥特 |
| Carquethuit | 卡尔克蒂 | 巴尔贝克附近的海港小村；埃尔斯蒂尔刚完成的《卡尔克蒂港》是本章论绘画隐喻的核心作品。虚构地名，按音译。首现 vol5 第 001 章。 |
| Combray | 贡布雷 | 叙述者童年度假小镇、全书核心场景（原型伊利耶 Illiers）。译林版（上游指示）。首现第1章。 |
| Miss Sacripant | 萨克里邦小姐 | 奥黛特年轻时在一出杂耍剧中扮演的角色名，也是埃尔斯蒂尔早期小画像上的题字（1872 年 10 月）。叙述者由这幅画认出奥黛特。此名是艺名，不译作「萨克里庞」。首现 vol5 第 001 章。 |
| Mme Swann | 斯万夫人 | 即奥黛特；本章她在布洛涅树林散步，路人低语其旧名 Odette de Crécy。叙述者只称斯万夫人，不点破。 |
| Odette de Crécy | 奥黛特·德·克雷西 | 与奥黛特同一人。 |
| Swann | 斯万 | 核心人物姓氏（Charles Swann，夏尔·斯万）。首次出现于第 0 章（书名及题献页）。贯穿全书的重要角色，巴黎上流社会艺术品鉴赏家。 需要称谓时用斯万先生；不擅加源文未出现的名字。 禁用译法: 史万 原文别名: M. Swann |
| Véronèse | 韦罗内塞 | 意大利文艺复兴威尼斯画派画家；与曼特尼亚并举，形容某些天空的「几乎巴黎式的现代感」。首现 vol4 第 1 章。 |
| croyance | 信仰 | 本章关键概念：我们赋予人或物以统一与存在的力量；信仰消失后仍对旧物有拜物式依恋。不坐实为宗教信仰。 |
| ne varietur | 定本 | 拉丁语公证用语「不得更改」（ne varietur）；原文戏称斯万所珍视的奥黛特照片为「定本」。首现 vol5 第 001 章。 |

# vol4-1 P187 逐句审校

- 法语原文行号 `raw-md/vol4/chapters/001.md:377`
- dev 底稿行号 `polish/dev/chapters/polished-vol4-1.md:377`

本段为维尔巴里西斯侯爵夫人的对话：上段末她拉着外祖母的手请其落座（« asseyez-vous, tenez, mettez-vous là »），本段随即拦阻别坐这把扶手椅，下段由这把椅子引出普拉兰公爵夫人赠椅的轶事（« un fauteuil du genre de celui-ci »）。已核对 worktree 实际第 377 行与对照材料快照一致，法中对应无误。

1. **Oh !**。对应「哦！」。惊叹词独立成单元，「哦！」语气轻缓，与侯爵夫人客气拦阻的口吻相合，无信息损失。保留。
2. **si cela vous est égal, pas dans ce fauteuil !**。对应「要是您不介意，别坐这把扶手椅！」。「si cela vous est égal」是「若您不介意/对您都一样」的客套条件句，译「要是您不介意」准确且合中文礼貌语；« pas dans ce fauteuil » 为省略动词的否定祈使（「别在这把扶手椅里」），dev 补出「别坐」，由上文请坐语境支撑，属必要显化而非增译；指示词 ce 译「这把」无误。保留。
3. **Il est trop petit pour deux, mais trop grand pour moi seule, j'y serais mal.**。对应「两个人坐显得太挤，我独自坐又显得太空，我坐着不舒服。」。分三层核对：其一 « Il est trop petit pour deux »（椅子两个人坐太小），dev 以「两个人坐显得太挤」转写，「太小」与「太挤」信息等值，「显得」略作缓和，与客套口吻一致，不构成实质增译；其二 « mais trop grand pour moi seule »（可我一人坐又太大），dev 以「我独自坐又显得太空」承接，「太大」化作「太空」（空余太多），是中文描述座椅过大的自然说法，「挤/空」对举保住原文 petit/grand 的反差，「又」传达 mais 的转折；moi seule 为阴性，说话者为侯爵夫人，中文「我」无性别冲突；其三 « j'y serais mal »（我坐在里面会不舒服），条件式表假设，y 指椅中，dev「我坐着不舒服」以「坐着」落实 y，mal 译「不舒服」准确（être mal dans un fauteuil 即坐得不舒服），假设语气由上文虚拟框架自然带出，中文不必另加「会」。全句「两个人坐……我独自坐……」排比流畅，无欧化纠缠；「显得太空」在语境中只能解作「过于空荡」，不致误读。保留。

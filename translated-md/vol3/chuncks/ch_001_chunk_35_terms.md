| Gilberte | 希尔贝特 | 斯万与奥黛特之女；本章香榭丽舍游戏的中心人物，叙述者少年之恋的对象。全名 Gilberte Swann→希尔贝特·斯万。禁用译法沿用全书。 |
| Swann | 斯万 | 核心人物姓氏（Charles Swann，夏尔·斯万）。首次出现于第 0 章（书名及题献页）。贯穿全书的重要角色，巴黎上流社会艺术品鉴赏家。 需要称谓时用斯万先生；不擅加源文未出现的名字。 禁用译法: 史万 原文别名: M. Swann |
| Mme Swann | 斯万夫人 | 即奥黛特；本章她在布洛涅树林散步，路人低语其旧名 Odette de Crécy。叙述者只称斯万夫人，不点破。 |
| papa | 爸爸 | 儿语称谓；mon père 依语境译父亲/爸爸。首现第1章。 |
| Odette | 奥黛特 | 与德·克雷西夫人、斯万夫人是同一人；黛奥特为转录中的疑误写法，不采纳。本章为背景人物。 禁用译法: 黛奥特 |
| Champs-Élysées | 香榭丽舍 | 本章主场景之一：叙述者与希尔贝特在此玩抢垒、打羽毛球；斯万夫妇住所亦在近旁街区。 |
| Forcheville | 福什维尔 | 与 comte de Forcheville 同人（福什维尔伯爵）；裸形用于叙述与熟人称呼（M. de Forcheville→福什维尔先生）。斯万在维尔迪兰家失宠的对照人物，粗俗的势利者，萨尼埃特的妹夫。禁用：福尔什维尔、福歇维尔。首现第1章。 |
| Mlle Vinteuil | 凡德伊小姐 | 其无名女友（son amie）不立名、不点破 |
| Méséglise | 梅塞格利丝 | 预收：le côté de Méséglise→梅塞格利丝那边（斯万家那边的散步路线，贡布雷II）。 |
| barres | 抢垒游戏 | jeu de barres，儿童分两队互相攻守的跑动游戏；译「抢垒」，不作「跳房子」「夺旗」。原文 faire une partie de barres→玩一局抢垒。 |
| hôtel | 公馆 | 贵族宅邸语境作「公馆」（un hôtel de la rue de…）；旅馆语境作「酒店」（如 Grand-Hôtel）；maître d'hôtel 作「膳食总管」。按语境判断，不一律译「旅馆」。首现第1章。 |
| salon | 沙龙；客厅 | 第003章；前者指社交圈，后者指房间，按语境判断。 |

| Bergotte | 贝戈特 | 作家，叙述者的文学偶像；本章（vol3 第 1 章）首次实际登场，在斯万家谈论贝尔玛与《费德尔》，并评点叙述者的习作。其谈吐与文体不同，译时保留这一落差。 |
| Saint-Loup | 圣卢 | 罗贝尔·德·圣卢（Robert de Saint-Loup-en-Bray），马桑特伯爵夫人之子、夏吕斯男爵的外甥，叙述者在巴尔贝克的挚友。单称 Saint-Loup 作「圣卢」，全名 Saint-Loup-en-Bray 作「圣卢昂布雷」。禁用译法: 圣卢普、圣鲁。 |
| Académie | 法兰西学院 | 第003章；“il est de l’Académie”指法兰西学院院士身份。 |
| Meschorès | 梅绍雷斯 | 布洛克家宴上老布洛克嘟囔的姓氏；原文随即说明 Meschorès 在《圣经》里指「神的仆人」，此姓是家族标榜门第的话头。首现 vol5 第 001 章。 |
| Cercle des Ganaches | 老糊涂俱乐部 | 布洛克之父吹嘘的俱乐部（Cercle des Ganaches）；ganache 意为「老糊涂、蠢货」，名字本身带讥讽，译文照字面保留讥讽，不加注。首现 vol5 第 001 章。 |
| Schlemihl | 施莱米尔 | 沙米索小说中卖掉影子的人，犹太德语里转指「笨拙倒霉的人」；尼西姆·贝尔纳以此讥贝尔戈。首现 vol5 第 001 章。 |
| duc d'Aumale | 奥马勒公爵 | 奥尔良家族亲王；戈达尔大夫新学来的笑话里提到「去和奥马勒公爵说几句话」，其实只是去上厕所。首现第1章。 |
| sir Rufus Israël | 鲁弗斯·伊斯拉埃尔爵士 | 犹太金融家，与伊斯拉埃尔家族同姓；布洛克之父常把他挂在嘴边，「老糊涂俱乐部」的传闻也涉及他。译名与 Israels 条一致。首现 vol5 第 001 章。 |

| Chamisso | 沙米索 | 德国作家阿德尔伯特·冯·沙米索，《彼得·施莱米尔奇遇记》作者。首现 vol5 第 001 章。 |
| Chronique mondaine | 社交专栏 | 报纸的社交新闻栏（Chronique mondaine）；不作「世界专栏」。首现 vol5 第 001 章。 |
| Compagnie | 车马行 | 原文 la Compagnie 指巴黎出租马车的公司（Compagnie des voitures）；布洛克租其双马敞篷维多利亚车招摇过市。译「车马行」，不加「公司」。首现 vol5 第 001 章。 |
| Darius | 大流士 | 波斯帝国君主大流士一世；原文说某人的脸「像是从大流士的宫殿搬来」。首现 vol5 第 001 章。 |
| Gramont-Caderousse | 格拉蒙-卡德鲁斯 | 十九世纪巴黎著名的花花公子，名字在布洛克家被当作「时髦」的标尺。首现 vol5 第 001 章。 |
| Jockey | 赛马俱乐部 | 「un monsieur du Jockey」即赛马俱乐部的成员；不作「骑师」。 |
| Khorsabad | 霍尔萨巴德 | 亚述古城，以带翼人首牛身像（taureau androcéphale）著称；叙述者以此形容尼西姆·贝尔纳的胡须。首现 vol5 第 001 章。 |
| Radical | 《激进报》 | 巴黎报纸 Le Radical（激进派机关报），其社交专栏把布洛克之父称作「巴黎人熟悉的面孔」。首现 vol5 第 001 章。 |
| Salomon | 萨洛蒙 | 布洛克家在闲谈中提到的「萨洛蒙舅舅」，以讲究衣着著称；与尼西姆·贝尔纳不是同一人，勿合并。首现 vol5 第 001 章。 |
| Sargon | 萨尔贡 | 亚述国王萨尔贡二世（Sargon II），霍尔萨巴德宫殿的建造者；原文以「萨尔贡王的环状胡须」形容尼西姆·贝尔纳。首现 vol5 第 001 章。 |
| Suse | 苏萨 | 波斯古都（Suse），与「大流士的宫殿」连用；不作「苏撒」「苏萨城」。首现 vol5 第 001 章。 |
| Villiers | 维利耶 | 维利耶·德·利尔-亚当（Villiers de l'Isle-Adam），象征主义作家；尼西姆·贝尔纳谈贝尔戈时提到的「大人物」之一。首现 vol5 第 001 章。 |
| grand-oncle | 外叔外祖父 | 童年恐惧记忆中拉发卷的叔公；或与「阿道夫外叔外祖父」为同一人，本章未指名，勿加名字。首现第1章。 |
| grand-père | 外祖父 | 叙述者的外祖父（阿梅代），斯万老父挚友，爱读报。全书统一译「外祖父」（第1章译文已用）。首现第1章。 |
| maître d'hôtel | 领班 | 大酒店餐厅领班（艾梅的职务）；不作「旅馆主人」。首现 vol4 第 1 章。 |
| rue Royale | 皇家街 | 巴黎八区街道，连接协和广场与玛德莱娜教堂；韦伯咖啡馆在此。 |
| victoria | 维多利亚式敞篷马车 | 19 世纪的轻便四轮敞篷马车（voiture victoria），因英国维多利亚女王时代流行而得名；指车，不是人名或地名，禁译为「维多利亚」。源文 n'avait à sa disposition que sa victoria→只有他那辆维多利亚式敞篷马车可用。首现第1章。 |

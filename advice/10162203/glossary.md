## 术语表审查：确实还有更深层的僵化风险

我检查了仓库的翻译工作流，以及累积到 `translated-md/vol15/glossary.json` 的 5,079 条术语。

目前发现的问题比“太太”更广泛：一些普通词、抽象概念甚至多义词，被赋予了固定译法和禁用译法；而这些限制并不总能跨语境成立。

更关键的是，翻译规则本身有一处冲突：

- [术语维护规则](https://github.com/QriDoki/in-search-of-lost-time-translation-project/blob/main/.ai/skills/translate-multi-md/layer1_glossary-maintainer.md?utm_source=chatgpt.com) 要求“同一术语在全书中必须使用同一中文翻译”。
- 同一文件又明确承认，hôtel、maître d’hôtel、baignoire 等多义词必须按语境译成不同的中文。
- [译者规则](https://github.com/QriDoki/in-search-of-lost-time-translation-project/blob/main/.ai/skills/translate-multi-md/layer2_translator.md?utm_source=chatgpt.com) 要求严格参考术语表，并把备注中的文化判断作为硬约束。

这意味着：尽管规则已经意识到一词多义，“统一译名”的要求仍可能压倒对具体句子的理解。历史翻译报告里也出现过译者发现 `zh` 字段不合适、主动按上下文纠正的情况。

## 一、优先级最高的 10 个条目

这些是我认为最值得优先修订的地方。要注意，术语表有风险，不等于现有正文一定译错了；有些正文反而已经正确地摆脱了错误约束。

| 法语词            | 当前术语表         | 发现的问题与建议                                                                                                                       |
| -------------- | ------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| intelligence   | 智力；禁用“理智”“智慧” | 已证实与正文冲突。 `vol15-1` 原文 l'intelligence fournit les prétextes pour l'éluder，现译“理智却替逃避职责寻找借口”，很自然。术语表却禁止“理智”。应允许“理智／智力／理解力／聪明才智”。 |
| temps          | 时间；禁用“时机”“时候” | 硬性限制过度。 原文既有哲学意义的“时间”，也有 il était temps de commencer（该开始了）、le temps qu'il faisait（天气）。不能跨词义禁用“时候”。                             |
| viatique       | 临终圣体          | `zh` 与 `note` 直接矛盾。 备注要求在阿尔贝蒂娜的比喻中译“临行圣体”。死亡语境可作“临终圣体”，一般比喻还可能需要“精神上的慰藉／行路的食粮”。                                                |
| nef            | 中殿            | 教堂建筑中是“中殿”，但瓦格纳《特里斯坦》描写伊索尔德归来的场景中是“船”。`vol11-1` 已正确译“航船”，备注也已记录，单值字段仍有误导性。                                                     |
| lift           | 电梯            | 在酒店语境中既指电梯，也可借指操作电梯的人员。`vol5` 的翻译报告已经明确要求增补“电梯员”的人物义项，但累积术语表仍只列机器义。                                                            |
| cure           | 疗法            | 另有宗教语境的“本堂区／神职任所”之义。`cure de Criquetot` 已在历史报告中正确处理，必须保留这种分流。                                                                  |
| correspondance | 换乘票           | 除交通意义外，还可表示“呼应、对应、通信”，在普鲁斯特的美学描写中尤其重要。不能统一为交通术语。                                                                               |
| entremetteuse  | 淫媒            | 带性交易色彩时可用；泛指为人撮合、牵线时不能无条件使用“淫媒”。现有备注已指出这个区别。                                                                                   |
| loge           | 楼座包厢          | 在剧院是包厢，在公寓可指门房的小屋、门房职位。备注已经分义，应该显式拆成不同义项。                                                                                      |
| grue           | 烟花女子；鹤        | 依语境还可能涉及动物、妓女或其他本义，尤其必须保留骂人时的粗俗程度，不能把词形当作身份识别依据。                                                                               |

其中最明确的实证是 intelligence：

原文（vol15-1）

l’instinct dicte le devoir et l’intelligence fournit les prétextes pour l’éluder.

现有开发稿

“因为本能指明应尽的职责，理智却替逃避职责寻找借口。”

术语表约束

`intelligence → 智力；禁用“理智”“智慧”`

这里的“理智”与“本能”构成对照，比机械使用“智力”更符合中文表达。不能因为正文违反术语表，就判定正文有错。

## 二、另外一组：文学概念词过度锁定

这一组风险更隐蔽，因为译出来往往不是明显的错词，而是中文抽象、重复、生硬，或者语气发生偏移。

| 词            | 现行约束            | 我建议的处理                                            |
| ------------ | --------------- | ------------------------------------------------- |
| impression   | 印象；禁用“感受”“感觉”   | 论艺术认识论时优先“印象”，其他场景允许“感受、印象、观感”，但注意与 sensation 的区别 |
| bonheur      | 幸福；禁用“快乐”       | 依据句意可作“幸福、快乐、幸事、好运”，不能因与 joie 有区别就禁止重叠            |
| vérité       | 真理；禁用“真实”       | 允许“真理、真相、事实、真实之处”；哲学论证时保持概念一致                     |
| amour        | 爱情；禁用“恋爱”       | 分辨爱情、爱、爱意、喜爱、恋情，不宜将所有情感关系归入同一种“爱情”                |
| esprit       | 机智              | 沙龙应答中可作“机智”，也可能指“精神、心智、头脑、才智”；现有备注已经承认多义          |
| monde        | 社交界             | 特定上流社会语境正确；一般表达也可能是“世界、世人、人们”                     |
| habitude     | 习惯              | 作为全书反复出现的重要概念，需要稳定性，但具体句子仍可能需要“惯性、习以为常、熟悉”        |
| souvenir     | 回忆              | 应区别回忆这一活动、留下的记忆、往日印象及具体的纪念物                       |
| réminiscence | 旧感复现；禁用“回忆”“追忆” | 核心美学概念可以优先统一，但普通文学语境未必需要每次使用这一较生硬的术语              |
| moi          | 自我；禁止作名词时译“我”   | 哲学意义的“自我”应保留；人物语气及句法要求“我自己”“我这个人”时应允许变化           |

这里必须特别谨慎：普鲁斯特经常有意区分 sensation、impression、souvenir、mémoire 等词，完全自由的同义替换也会损失哲学层次。

所以我不主张取消这些概念的统一性，而是把规则改成：

概念需要统一，具体中文措辞不一定需要逐字统一。

## 三、还有两类结构性风险

人物关系称谓也需要从术语约束中部分解放。比如 `grand'mère → 外祖母`、`ma tante → 姑妈`，术语表往往附带“叙述者的外祖母”“莱奥妮姑妈”等身份说明。但一旦引语出自另一个人物，相同的法语称谓可能指不同的人，也可能因亲属关系不同而需要另一个中文称呼。

社会身份和职业则需要按场景分流。例如 `chasseur → 侍应生` 在酒店门口可能更自然地译作“门童／跑腿侍者”；`gouvernante → 女管家` 不能扩展到所有家庭教师或女监护人的语境；`maître d’hôtel` 已经正确地区分了酒店领班和私人府邸的膳食总管。这些不适合当作全书无条件的单值替换规则。

## 四、应该从哪里修复？

问题实际上分布在三个层级。

第一级：`glossary.json`

将一词多义的条目从单一 `zh` 拆为按语境定义的多个义项，或者标注主译法仅在特定范围有效。优先修复 `viatique`、`lift`、`intelligence` 等已发现明确问题的条目。

第二级：章节术语清单与 Chunk 术语表

术语维护者应先判断某个法语词在本章、本段中采用哪个义项，再把该义项交给翻译者，而不是把历史上所有的释义和禁用条件直接复制过去。

第三级：翻译与校对规则

将“同一术语全书必须使用同一中文翻译”调整为“同一专名、同一概念义项原则上统一；同形异义、语域变化和修辞要求允许按上下文调整”。

建议将条目分为以下三个等级：

| 级别    | 适用对象                | 约束方式              |
| ----- | ------------------- | ----------------- |
| 严格统一  | 人名、地名、作品名、明确专有称号    | 同一对象保持固定译名        |
| 按义项统一 | 宗教、社会制度、建筑、音乐、哲学概念  | 先判断词义，再选该义项的推荐译法  |
| 上下文优先 | 普通名词、形容词、抽象词、人物临时称谓 | 只提供建议译法，不设跨语境硬性禁令 |

### 最终判断

这次发现的风险不全是术语表维护者没有意识到一词多义。恰恰相反，很多备注已经做了正确的语境分析，但最终数据结构和下游执行指令没有充分表达这种分析。

因此，继续逐个修改“太太”“女士”“智力”等正文词语，可以改善当前版本，却无法根除问题。

更值得优先修订的是 [术语表维护者规则](https://github.com/QriDoki/in-search-of-lost-time-translation-project/blob/main/.ai/skills/translate-multi-md/layer1_glossary-maintainer.md?utm_source=chatgpt.com)、[翻译者规则](https://github.com/QriDoki/in-search-of-lost-time-translation-project/blob/main/.ai/skills/translate-multi-md/layer2_translator.md?utm_source=chatgpt.com)，再对已有术语按上述三级分类重整。

本轮仅进行了只读审查，没有改动仓库文件。

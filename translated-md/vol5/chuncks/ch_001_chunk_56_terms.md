| Albertine | 阿尔贝蒂娜 | 人名，统一作「阿尔贝蒂娜」。vol3 仅被提及为博纳唐夫人的侄女；vol4 仍只被提及；vol5 第 001 章正式登场——埃尔斯蒂尔画室介绍相识，与安德蕾、吉赛尔、罗丝蒙德等结成少女小团体，叙述者的爱情由此开始。禁用译法: 艾伯丁、阿尔贝汀 |
| Andrée | 安德蕾 | 少女小团体的核心成员之一，阿尔贝蒂娜最亲密的女伴；棕色皮肤、眼睛极亮，第一天跳过老银行家，性格沉稳、乐善好施（富家女），叙述者一度假装追求她以接近阿尔贝蒂娜。首现 vol5 第 001 章。禁用译法: 安德雷、安德里 |
| croyance | 信仰 | 本章关键概念：我们赋予人或物以统一与存在的力量；信仰消失后仍对旧物有拜物式依恋。不坐实为宗教信仰。 |
| Rosemonde | 罗丝蒙德 | 少女小团体成员，爱开玩笑、带北方口音，与吉赛尔、安德蕾同住。首现 vol5 第 001 章。禁用译法: 罗斯蒙德、罗萨蒙德 |
| Bakst | 巴克斯特 | 俄罗斯舞台美术家莱昂·巴克斯特（Léon Bakst），俄国芭蕾舞团布景与服装设计者；原文以之形容舞台道具在灯光下的魔力。首现 vol5 第 001 章。 |
| Elstir | 埃尔斯蒂尔 | 虚构画家，叙述者在巴尔贝克结识（vol5 第 001 章正式登场：海滨大酒店初遇、画室长谈、《卡尔克蒂港》、为奥黛特所作的《萨克里邦小姐》小像）；其观看方式深刻影响叙述者的视觉，普鲁斯特以惠斯勒、透纳、莫奈等为部分原型，不得坐实为任何真实画家。禁用译法: 埃尔斯提尔、埃尔斯蒂。 |
| Leucothoé | 琉科托厄 | 希腊神话中的海仙女；维吉尔诗中人物，原文以之形容隔在少女与叙述者之间那层「不透明而柔和的」雾气。首现 vol5 第 001 章。 |
| Virgile | 维吉尔 | 罗马诗人。首现第1章。 |

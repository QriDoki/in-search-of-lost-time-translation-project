## 检查范围

1. **错译**：语义相反、否定/肯定颠倒、主体与客体错位、人物张冠李戴、因果与逻辑关系偏差、时态与体貌误读、明显漏译或增译（含整句、分句、限定语、修饰语）。
2. **语句不通顺**：句子结构残缺或杂糅、长句意群断裂、修饰语挂错对象、指代不明导致歧义。
3. **不符合现代中文使用习惯 / 令读者迷惑**：生硬直译造成的费解搭配、虚词滥用、西式长定语堆叠、代词链条过长、无必要的欧化被动。

## 判断原则

- **保守**：只有能由法文原句及上下文确证的，才记为「明确问题」。可接受的其他译法、风格偏好、轻重差异归入「可选润色」或直接不提。
- **保留原作**：普鲁斯特的长句、修辞、反讽、人物口吻（弗朗索瓦丝、女仆、门房等下层人物的话语特征）、多义与含混，不得为求通顺而删减或缩句。中文不通顺必须修，但不得改变信息量与语气。
- **注释标记**：`⊂…⊃≼…≽` 是既有译注，属于正文的一部分。审校时忽略标记本身造成的视觉割裂，**不得删除或改写注释内容**；若因正文改动导致注释定位词失效，须在报告中标明并给出注释内定位词的最小同步修改建议。
- **专名与文化事实**：不确定的译名、典故不擅自改，标「待核」。
- **不得编辑**原文与译文文件；只写自己的报告与 JSON。

### 2. `pNNN.json`（可机械应用的替换）

```json
{
  "id": NNN,
  "edits": [
    {
      "old": "<从现译中逐字复制的片段，必须在该段译文中唯一出现>",
      "new": "<替换后的中文>",
      "reason": "<一句话理由>",
      "type": "错译|漏译|增译|指代|逻辑|语句不通顺|中文习惯"
    }
  ],
  "optional": [
    {"old": "…", "new": "…", "reason": "…"}
  ]
}
```

- `edits` 只放**确定要改**的项；`optional` 放可选润色，主审决定是否采纳。
- `old` 必须与译文**逐字一致**（含中文标点、注释标记原样），且在**本段内**唯一；尽量取足够长的上下文以保证唯一性。
- 替换片段不得跨段；不得把注释标记 `⊂…⊃≼…≽` 包进 `old` 后在 `new` 中丢弃或改写注释内容。
- 无修改时写 `{"id": NNN, "edits": [], "optional": []}`。
- JSON 必须可被 `json.load` 解析，UTF-8，不转义中文。

| matinée | 午后聚会 | 第003章 4 处均指亲王妃家的白天招待会；章题与正文统一「午后聚会」。与 goûter（下午茶会，规模更小）区分。禁用「早晨」「日场」（日场义见 vol11 条）。 |
| M. de Charlus | 夏吕斯先生 | 源文 12 处。严格随源文形式：M. de Charlus→「夏吕斯先生」；le baron／du baron（17 处）→「夏吕斯男爵」；裸形 Charlus→「夏吕斯」。禁用「夏吕斯男爵先生」。本章他已中风初愈：白发白须、言语含混、动作失调，而智力完好。 |
| princesse de Guermantes | 盖尔芒特亲王妃 | 本章午后聚会的女主人，与亲王同住 avenue du Bois 新宅。princesse de X 一律「X 亲王妃」；禁用「公主」「亲王夫人」。与公爵夫人严格区分。 |
| prince de Guermantes | 盖尔芒特亲王 | 公爵的堂弟吉尔贝；已迁出旧府、在 avenue du Bois 新建府邸，聚会即在其家举行。禁用「亲王殿下」（源文无 Monseigneur）、「盖尔芒特亲王先生」。 |
| Jupien | 朱皮安 | 裁缝兼旅店经管人。本章他寸步不离照料病后的夏吕斯，扶他下车、替他通报来人，像看护孩子；并向叙述者讲述夏吕斯失明期间仍设法寻人、以及疗养院里的丑事。禁用「朱皮耶」「儒皮安」「朱比安」。 |
| Françoise | 弗朗索瓦丝 | 本章出现在回忆里：当年与她同去香榭丽舍、在皇家街角看照片摊。禁用「弗朗索瓦斯」。 |
| maman | 妈妈 | 叙述者的母亲。本章她去萨士拉夫人家赴小茶会，叙述者因此得以毫无顾虑地去亲王妃家。叙事中可作「母亲」，随句法。 |
| Albertine | 阿尔贝蒂娜 | 本章只在回忆中：经过某条街时想起「听说她曾与安德蕾去过」那里的某所房子。禁用「艾伯丁」「阿尔贝汀」。 |
| Andrée | 安德蕾 | 与阿尔贝蒂娜同去某所房子的旧闻。禁用「安德雷」「安德里」。 |
| Gilberte | 希尔贝特 | 本章回忆：在坦松维尔与她每日散步、深夜才回房吃饭，正是在那时认定自己无文学天赋。禁用「吉尔贝特」。 |
| Mme Sazerat | 萨士拉夫人 | 贡布雷居民。本章叙述者的母亲去她家赴「小茶会」。**禁用「萨泽拉」**（旧译）；姓 Sazerat 一律「萨士拉」。 |
| Américaine | 美国女人 | 本章 2 处：亲王新宅里那些美国女人的晚会（与他无干的新富社交）；「最末等的美国女人」。非特指某位人物，不得代拟姓名。禁用「美国女子」「美洲女人」。 |
| Guermantes | 盖尔芒特 | 家族名与地名。本章：请帖上这个名字重新唤起贡布雷的空气、鸟街与彩窗的旧魔力，随后又因亲王迁居而失效。le côté de Guermantes（散步路线）作「盖尔芒特家那边」；les Guermantes 作「盖尔芒特一家」。 |
| Champs-Élysées | 香榭丽舍 | 巴黎林荫大道。本章：去亲王妃家途中，马车经过通往香榭丽舍的街道，他忆起当年与弗朗索瓦丝同去。此处是巴黎地名，非神话「极乐世界」。 |
| rue Royale | 皇家街 | 巴黎八区街道。本章：街角原有弗朗索瓦丝喜爱的露天照片摊，马车到此「自己转弯」。禁用「皇家大道」。 |
| avenue du Bois | 布洛涅树林大道 | 巴黎西侧通往布洛涅树林的大道（今福煦大街），普鲁斯特时代通称 avenue du Bois。译「布洛涅树林大道」，与既有「布洛涅树林」同一命名体系。禁用「树林大街」「布瓦大道」「布洛涅大街」。本章：亲王在此新建府邸，旧日魔力随之消失。 |
| ancien hôtel du prince de Guermantes | 盖尔芒特亲王的旧府 | 亲王迁居前的巴黎府邸。与公爵夫妇的「盖尔芒特府」（叙述者一家租住其侧翼）不是一处，与「盖尔芒特亲王妃府」亦分列。hôtel 作「府」，不作「旅馆」。首次出现可作「亲王原先的府邸」。 |
| hôtel de l'avenue du Bois | 布洛涅树林大道上的府邸 | 亲王新建的府邸；`le magnifique [hôtel] qu'il s'était fait construire avenue du Bois` 与 `l'hôtel de l'avenue du Bois` 同指。hôtel 作「府邸」，不作「旅馆」「酒店」。 |
| hôtel | 府／府邸（贵族宅邸）；酒店（旅馆） | 本章贵族宅邸语境一律「府／府邸」。不作「旅馆」。 |
| Paris | 巴黎 | 本章「回巴黎」「久离巴黎」，照常作「巴黎」。 |
| Phèdre | 《费德尔》 | 拉辛悲剧，贝尔玛名段。本章：午饭后赶去看街头海报。作品名加书名号。禁用「费德儿」「菲德尔」。 |
| roi Lear | 李尔王 | 莎士比亚悲剧主人公。指人不加书名号；禁用「李尔国王」。 |
| affiche | 海报 | 《费德尔》《黑多米诺》的街头海报。作「海报」，不作「告示」「招贴画」。 |
| Potel et Chabot | 波泰勒与沙博 | 巴黎著名承办宴席的商家（traiteur）。本章：亲王新宅里临时派来的仆役出自此家，叙述者自嘲无法假装他们是革命前的旧仆之后。禁用「波泰尔」「沙波」。 |
| Bernheim jeune | 伯恩海姆-热纳画廊 | 巴黎画商 Bernheim-Jeune 兄弟的画廊，专营当代绘画。本章：他把上月刚在此买下的画称作「祖先肖像」。jeune 是店名的一部分，不作「年轻的伯恩海姆」。禁用「伯恩海姆画廊」。 |
| Révolution | 大革命 | 本章 `bien avant la Révolution` 作「早在革命之前」，指 1789 年法国大革命，不作「改革」「变革」。 |
| gens du monde | 上流社会的人 | 本章 `C'est un des torts des gens du monde de ne pas comprendre que…` 作「上流社会的人有一桩毛病：不明白……」。 |
| apoplexie | 中风 | `attaque d'apoplexie` 作「一次中风」；与 attaque（「中风发作」）合译时避免「中风发作发作」。不作「脑溢血」（apoplexie 不限于出血）。 |
| attaque | 中风发作 | 本章指夏吕斯那次中风。 |
| petit thé | 小茶会 | 萨士拉夫人家的小型茶会。与 goûter（下午茶会）近义而更简。不作「小茶」「茶叶」。 |

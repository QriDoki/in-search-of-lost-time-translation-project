# Chunk 29 校对报告 (第 002 章)

## 术语审查
- 盖尔芒特亲王妃 / 盖尔芒特公爵夫人 / 盖尔芒特公爵 / 夏吕斯先生 / 叙尔吉侯爵夫人 / 帕拉梅德 / 巴赞 / 梅梅 / 奥丽阿娜：均按 chunk 术语表落笔，未作改动。同段内先说「盖尔芒特公爵」、后文简称「公爵」，亲王妃与公爵夫人严格分开，未混称。
- 末句「玛丽」按 L2 提示处理为公爵夫人本名（Marie de Guermantes），未加注、未误作第三人；译文作「你们让玛丽和我站了半个钟头了」，读者可自然理解为自称。
- `le vieux père Courveau` → 「老库尔沃老师」；`Hervey de Saint-Denis` → 「赫维·德·圣但尼」；`dictionnaire chinois` → 「一部中国辞典」。三处均无术语表条目，按 L2 报告沿用，建议上游统一「库尔沃老师」「赫维·德·圣但尼」为章内定译。

## 初译稿典型错误
- **关键遗漏**：「看这两兄弟这么亲热，真叫人高兴。」之后脱漏亲王妃回答公爵夫人的一整句——「啊，这个嘛，我不觉得这样的兄弟能找出几个来。我会请您跟他一道来的，」她向我许诺，——即公爵夫人对叙述者的邀约，以及亲王妃「qu'est-ce qu'ils peuvent avoir à se dire」的直接引语引子。已补回，未改变段落数。
- **法语原词残留 / 游戏失效**：初稿把库尔沃老师的问答保留为 `trou…… trou……` / `blé` / `blanc`，中文读者接不上，且违反正文不加外语词的体例。改为「烦……烦……」＋「人」「乱」：老师吐半字，学生补尾成「烦人」「烦乱」。终稿让两问的补字交叉（问「为什么叫人烦」补「乱」，问「为什么烦乱」补「人」），正好对应原文第二答 `blanc` 并非第一答 `blé` 的「接错了字」的笑点——孩子把两个尾字对调，老师照样夸他「您会考取的」。语义上 `troublant / troublé` 的对照由「烦人／烦乱」承担，不需加注。若下游认为交叉读来费解，可改回同序（烦人→人、烦乱→乱），但会失去原笑话的错位感，故此处保留交叉。
- **俗语落地**：`piqua ce qu'on appelle un soleil` 初稿作「猛地涨红了脸——用俗话来说，是“出了个太阳”」，中文读者会误以为「出了个太阳」是中文俗语。终稿改为「公爵的脸就猛地红到了耳根——按俗话说的，是“出了个太阳”」：先用具体的中文说法交代事实，再以「按俗话说的」把法语的比喻作为引述保留，既留住了原文的自嘲口吻和那个突兀的意象，又不让中文读者把它当成地道说法。
- `quelque liaison « spéciale »` 处「特殊」加引号保留，与前文「特殊的口味」呼应；未改成「那种事」之类明说，反讽层次完整。

## 对后续章节的建议
- 本章公爵失言—补救—再失言的线索依赖「口味」「特殊的」两处措辞的重复，后续段落若再现 `goûts`、`spécial`，建议固定译「口味」「特殊的」，不要换成「趣味」「特别的」，否则呼应会断。
- 叙述者在本段的自我更正（「还是回过头来说说……」）是普鲁斯特常用的叙述姿态，宜保留「还是回过头来」这类口语化的回撤语，不要改成「回到……」。

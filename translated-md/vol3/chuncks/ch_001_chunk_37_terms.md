| Swann | 斯万 | 核心人物姓氏（Charles Swann，夏尔·斯万）。首次出现于第 0 章（书名及题献页）。贯穿全书的重要角色，巴黎上流社会艺术品鉴赏家。 需要称谓时用斯万先生；不擅加源文未出现的名字。 禁用译法: 史万 原文别名: M. Swann |
| Mme Swann | 斯万夫人 | 即奥黛特；本章她在布洛涅树林散步，路人低语其旧名 Odette de Crécy。叙述者只称斯万夫人，不点破。 |
| Bloch | 布洛克 | 我年长的同学，引介贝戈特；爱用矫揉语体（mon très cher maître） |
| nom | 名字 | 本章主题词（noms de pays／le nom）：地名之名承载欲望、想象与记忆，并反过来塑造它所命名的城市。译「名字」，不作「名称」「名词」。普通用法仍按上下文作「名字／名」。 [theme] |
| Bontemps | 博纳唐 | 博纳唐夫人（Mme Bontemps）为公共工程部部长办公厅主任之妻、阿尔贝蒂娜的姑母，斯万家的常客；译名用「博纳唐」，禁用「邦唐」「邦当」。 |
| Jardin d'Acclimatation | 驯化园 | 巴黎布洛涅树林内的动物园与游乐园（Jardin d'Acclimatation），当时有「黑人」「僧伽罗人」展演；不作「驯化花园」。 |
| princesse Mathilde | 玛蒂尔德公主 | 拿破仑一世的侄女、第二帝国沙龙女主人；此处是正统派家庭不愿与之同席的人物。她是王室公主，故用「公主」。首现第1章。 |
| Altesse Impériale | 皇族殿下 | 对皇室成员的尊称（Son Altesse Impériale）；玛蒂尔德公主为拿破仑一世侄女，故称。 |
| Bois | 布洛涅树林 | le Bois＝Bois de Boulogne，巴黎西郊树林，上流社会散步、炫示之地；不译「森林」。本章有金合欢道、玛格丽特王后道、大湖、射鸽场。首现第1章。 |
| Compiègne | 贡比涅 | 有森林与城堡的王城，斯万想去而未得。首现第1章。 |
| Cynghalais | 僧伽罗人 | 原文 Cynghalais 即锡兰（今斯里兰卡）僧伽罗人；普鲁斯特把他们与非洲黑人混作一谈，译文保留这一误置，不加按语。 |
| Dumas | 小仲马 | 此处指小仲马（Alexandre Dumas fils），新剧《弗朗西荣》；不指《三个火枪手》作者大仲马。首现第1章。 |
| Gilberte | 希尔贝特 | 斯万与奥黛特之女；本章香榭丽舍游戏的中心人物，叙述者少年之恋的对象。全名 Gilberte Swann→希尔贝特·斯万。禁用译法沿用全书。 |
| III | 第三卷 | 书名页上总书名下方的罗马数字卷次，首见于 vol3 第 0 章。指《追忆似水年华》第三卷，译文作「第三卷」，不加书名号；不要直留「III」。vol2 第 0 章的同位条目为「II」→第二卷。 |

# 翻译方法：厘清动作主体与条件关系

翻译多层假设、反复出现“离开／留下”等动作的长句时，不宜只按原文顺序逐词接续，应先理清逻辑，再尽量保留原文的修辞。

1. **标明主体与方向**：逐一确认“谁离开谁／哪里”“谁留下”，避免中文代词造成主客倒置。
2. **还原条件链**：分清假设、假设成立后的结果，以及人物眼下的真实处境。
3. **保留关键对照**：原文若以一组反义动词收束，应尽量在译文中重现；必要时少量补足中文语境，但不改变因果。
4. **用上下文复核**：检查补出的地点、时间与动作顺序是否有依据，避免为求通顺而增加原文没有的事实。

## 例子：《斯万之恋》（续）

**法语原文**（[raw-md/vol2/chapters/001.md](../raw-md/vol2/chapters/001.md)）：

> Sans doute Swann était certain que s'il avait vécu maintenant loin d'Odette, elle aurait fini par lui devenir indifférente, de sorte qu'il aurait été content qu'elle quittât Paris pour toujours ; il aurait eu le courage de rester ; mais il n'avait pas celui de partir.

**原译**：

> 无疑，斯万确信，假如他现在远离奥黛特生活，她最终会对他变得无所谓，那样的话，她若从此永远离开巴黎，他也会高兴；他会有勇气留下；但他没有勇气走。

**修订**（[开发稿](../polish/dev/chapters/polished-vol2-1.md)）：

> 斯万固然确信，倘若自己现在能远离奥黛特生活，终有一天便不会再在乎她；那时，奥黛特即使永远离开巴黎，他也会为此高兴，有勇气留下来；可他没有勇气自己先走。

**拆解**：假设斯万主动远离奥黛特 → 经过时间，他不再爱她 → 即便奥黛特永远离开巴黎，他也敢留下；**现实却是他不敢主动离开**。

原文以 *rester / partir*（留下／离开）对照收束。“不再在乎她”明确感情变化发生在斯万身上；“自己先走”补明行动主体及条件链的起点，是有上下文依据的释义性增补，并非法语逐字对应。

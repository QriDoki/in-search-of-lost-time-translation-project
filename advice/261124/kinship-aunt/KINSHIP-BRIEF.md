## 中文亲属称谓定义（判据）
- **姑母/姑妈** = 父亲的姐妹（paternal aunt）。
- **舅母** = 母亲的兄弟（舅父）之妻。
- **姨母/姨妈** = 母亲的姐妹。
- **伯母/叔母** = 父亲的兄弟之妻。
- **随夫称呼**：妻子对丈夫的亲属，从丈夫的称谓（如丈夫称舅母，妻亦称舅母）。
- 法语 `tante` 泛指姑/姨/舅母/伯叔母，须按具体谱系定中文；`belle-sœur` 为嫂/弟媳/姑/姨等姻亲。

## 已核实的谱系（铁律，附证据）
1. **马桑特夫人（Mme de Marsantes）是盖尔芒特公爵与夏吕斯的亲姐妹**。证据：「兄弟姐妹…像盖尔芒特公爵与马桑特子爵夫人那样」「马桑特夫人…站在嫂子一边，反对自己的亲兄弟」。
2. **圣卢（Robert de Saint-Loup）是马桑特夫人之子**。故：
   - 盖尔芒特公爵、夏吕斯 = 圣卢的**舅父**（母亲的兄弟）。全书已用「舅父/舅舅」（「你的舅父夏吕斯」「罗贝尔从父亲的趣味过渡到舅父的趣味」）。
   - **盖尔芒特公爵夫人奥丽阿娜（Oriane，公爵之妻）= 圣卢的舅母**，不是姑母，更不是表姐。
3. **维尔巴里西斯侯爵夫人（Mme de Villeparisis）= 公爵与夏吕斯的姑母**（父亲的姐妹；公爵亲口「那是他的姑母」）。她又是博塞让夫人、汉诺威亲王妃的姐妹。对公爵夫人（随夫）与圣卢（姑外祖母辈）而言，家族通称「维尔巴里西斯姑母」。**凡指维尔巴里西斯的「姑母」均正确，保留。**
4. **博纳唐夫人（Mme Bontemps）= 阿尔贝蒂娜的姑母**（「她姑母」「带着侄女阿尔贝蒂娜」）。**凡指博纳唐夫人的「姑母」均正确，保留。**
5. **夏吕斯的其他姑母**：希迈姑母、科黛莉亚姑母（卡斯特拉纳元帅夫人）、博塞让夫人（艾费尔德夫人）等，是公爵/夏吕斯父系姑母，**「姑母」正确，保留**。
6. **叙述者的莱奥妮姑妈（tante Léonie）**= 叙述者父亲的姐妹，「姑妈」正确，保留。

## 核心校订规则
- **当「姑母」实指盖尔芒特公爵夫人奥丽阿娜，且是作为圣卢的姑母被称呼时 → 改为「舅母」**（她是圣卢舅父公爵之妻）。这是本次主要误标。
- **当「姑母」实指公爵夫人，且是作为希尔贝特（Gilberte，后为圣卢夫人）的姑母被称呼时 → 改为「舅母」**（希尔贝特随夫圣卢称呼）。注意：若同章他处已作「舅母」，应统一。
- **当「姑母」指维尔巴里西斯、博纳唐夫人、夏吕斯的父系姑母、叙述者姑妈等 → 保留**。
- **暧昧处**（「我姑母」「他的姑母」「某位姑母」等）：必须先确定**说话人是谁**、**指的是哪位姑母**。读足上下文并对照法文 `tante` 所指人物：
  - 指维尔巴里西斯 → 保留「姑母」；
  - 指公爵夫人（作为圣卢/希尔贝特长辈）→ 改「舅母」；
  - 指其他父系姑母 → 保留；
  - 实在无法确证 → 标 UNCERTAIN，给出法文依据与两种可能，不强行改。
- **社交泛称**：若「姑妈/姑母」是社交口吻的亲昵泛称（非实指父系姑母，原文有注说明），保留，不改。
- **俚语/语言注释**：如「姑母之妻」（法语俚语 femme d'une Tante，tante 暗指男同性恋）属语言说明，**不动**。
- **译注内容**：`⊂…⊃≼…≽` 注释内容不得改写；若正文改词导致注释内定位词失效，仅做最小同步（改所引数字），并在报告标明。

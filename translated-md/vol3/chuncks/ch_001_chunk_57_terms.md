| Mme Cottard | 戈达尔夫人 | 大夫的妻子；不可合并为维尔迪兰夫人。 禁用译法: 科塔尔夫人 |
| Patronne | 老板娘 | 圈子对维尔迪兰夫人的固定称呼（「老板娘」），大写；不是旅馆老板娘。首现第1章。 |
| Mme Swann | 斯万夫人 | 即奥黛特；本章她在布洛涅树林散步，路人低语其旧名 Odette de Crécy。叙述者只称斯万夫人，不点破。 |
| Mme Verdurin | 维尔迪兰夫人 | 与其丈夫分开建角色；不把她的判断直接当作叙述事实。 禁用译法: 韦尔迪兰夫人、维乐迪兰夫人 原文别名: Madame Verdurin |
| salon | 沙龙；客厅 | 第003章；前者指社交圈，后者指房间，按语境判断。 |
| Bontemps | 博纳唐 | 博纳唐夫人（Mme Bontemps）为公共工程部部长办公厅主任之妻、阿尔贝蒂娜的姑母，斯万家的常客；译名用「博纳唐」，禁用「邦唐」「邦当」。 |
| chrysanthème | 菊花 | 奥黛特冬日沙龙里的主要花卉；本章末段叙述者追想斯万夫人客厅里「十一月暮色中菊花的橙红火光」，是旧日优雅的标记。首现第1章。 |
| petit clan | 小宗派 | 第003章；与信条、教会、正统等宗教比喻相连。 |
| Mme de Crécy | 德·克雷西夫人 | 不是另一个角色；按源文称呼保留。 原文别名: Madame de Crécy |
| Swann | 斯万 | 核心人物姓氏（Charles Swann，夏尔·斯万）。首次出现于第 0 章（书名及题献页）。贯穿全书的重要角色，巴黎上流社会艺术品鉴赏家。 需要称谓时用斯万先生；不擅加源文未出现的名字。 禁用译法: 史万 原文别名: M. Swann |
| Verdurin | 维尔迪兰 | 复数指维尔迪兰夫妇或维尔迪兰一家，依句法。 禁用译法: 韦尔迪兰、维乐迪兰 原文别名: les Verdurin |
| petit groupe | 小集团 | 第003章；与 petit noyau 交替使用的圈子称呼，修辞上有变化。 |

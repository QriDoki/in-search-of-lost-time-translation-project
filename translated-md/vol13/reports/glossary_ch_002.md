## 已有术语审查（本章重点复核）

- `Mme de Guermantes` / `duchesse de Guermantes` → 盖尔芒特公爵夫人：全章高频（66 次 Guermantes）。叙述中首次提及用全称「盖尔芒特公爵夫人」，同段可简称「公爵夫人」，**禁「盖尔芒特夫人」**。
- `princesse de Guermantes` → 盖尔芒特亲王妃；与公爵夫人严格区分（本章 P21 提到「她的表亲盖尔芒特亲王妃」）。
- `princesse de Parme` → 帕尔马亲王妃；本章 P61、P67 两次，均为「亲王妃」，非「公主」。
- `M. de Bréauté` → 布雷奥泰伯爵（vol13 第 001 章已定），本章 P33、P41、P42 出现；维勒迪厄沙龙里另有「布雷奥泰侯爵」的旧译，本章不得混用。
- `prince des Laumes` → 洛姆亲王；P33 公爵自述婚前封号，须与「盖尔芒特公爵」同人、不加注。
- `Mémé` → 梅梅（夏吕斯在家族内的昵称），P33 公爵夫人语；不作「奶奶」。
- `prince d'Agrigente` → 阿格里真托亲王；绰号「格里格里」。
- `comtesse Molé` → 莫莱伯爵夫人；`Mme de Marsantes` → 马桑特伯爵夫人。
- `Lady Rufus Israël` → 鲁弗斯·伊斯拉埃尔夫人；P34–P35 出现，Gilberte 否认认识她。注意：姓氏 Israël 音译「伊斯拉埃尔」，与族称「以色列人」（Israélites）区分。
- `figaro` 相关：`Figaro` → 《费加罗报》；原文斜体保留，中文用《》。全章 13 次，务必统一。
- `Elstir` → 埃尔斯蒂尔；`Vinteuil` → 凡德伊；`Sonate de Vinteuil` → 凡德伊奏鸣曲；`petite phrase` → 小乐句（本章 P5 出现，与奏鸣曲动机相关）。
- `Tansonville` → 坦松维尔；`Rivebelle` → 里夫贝尔；`Montjouvain` → 蒙舒凡（禁用「蒙茹万」）；`Buttes-Chaumont` → 肖蒙山丘；`Petit Trianon` → 小特里亚农。
- `Balbec` / `Hôtel de Balbec` → 巴尔贝克 / 海滨大酒店（本卷统一）。
- `seringa` → 山梅花（P63 关键道具：安德蕾叙述中「山梅花枝」的夜晚）；禁用「紫丁香」。
- `maison de passe` → 妓院；`cocotte` → 交际花；`vice` → 恶习（叙述者沿用时代委婉语，不译「变态」）。
- `snobisme` → 附庸风雅（本章主题词之一，P35、P38、P40–P41 反复出现；名词 `snob` 可作「附庸风雅的人」）。
- `gens du monde` → 上流社会的人；`le monde` → 社交界。
- `grand seigneur` → 大贵人；`self-government` → 自行其是（见新增条）。
- `faubourg Saint-Germain` → 圣日耳曼区（P27 转喻义：贵族社交圈）。
- `affaire Dreyfus` → 德雷福斯事件；P19 论反犹运动与犹太人在社交界的渗透。

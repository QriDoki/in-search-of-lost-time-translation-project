| Albertine | 阿尔贝蒂娜 | 人名，统一作「阿尔贝蒂娜」。vol3 仅被提及为博纳唐夫人的侄女；vol4 仍只被提及；vol5 第 001 章正式登场——埃尔斯蒂尔画室介绍相识，与安德蕾、吉赛尔、罗丝蒙德等结成少女小团体，叙述者的爱情由此开始。禁用译法: 艾伯丁、阿尔贝汀 |
| Andrée | 安德蕾 | 少女小团体的核心成员之一，阿尔贝蒂娜最亲密的女伴；棕色皮肤、眼睛极亮，第一天跳过老银行家，性格沉稳、乐善好施（富家女），叙述者一度假装追求她以接近阿尔贝蒂娜。首现 vol5 第 001 章。禁用译法: 安德雷、安德里 |
| Gisèle | 吉赛尔 | 少女小团体成员，有一头长发，因家中缘故提前离开巴尔贝克；众人传阅她写的作文（索福克勒斯致拉辛、塞维涅致拉法耶特夫人两题）。首现 vol5 第 001 章。禁用译法: 吉塞尔 |
| Sophocle | 索福克勒斯 | 古希腊三大悲剧诗人之一；本章是吉赛尔作文题的假设收信人（「索福克勒斯致拉辛」）。首现 vol5 第 001 章。 |
| Racine | 拉辛 | 拉辛（Jean Racine），法国古典主义悲剧诗人；夏吕斯称「拉辛的一出悲剧比雨果先生的全部剧作更有真实」。作品名加书名号：《安德洛玛克》《费德尔》。首现第1章。 |
| Athalie | 《阿塔莉》 | 拉辛悲剧《阿塔莉》；本章吉赛尔作文题引之（「索福克勒斯致拉辛，安慰他《阿塔莉》失败」）。作剧名加书名号。 |
| Merlet | 梅尔莱 | 文学批评家；安德蕾列举「圣伯夫与梅尔莱的判断」时提及。首现 vol5 第 001 章。 |
| Sainte-Beuve | 圣伯夫 | 圣伯夫，法国批评家；诺尔普瓦引其与洛梅尼的掌故，普鲁斯特全书对其方法持批判态度。 |
| Aman | 《阿曼》 | 蒙克雷蒂安（Montchrestien）的悲剧；与《犹太女人》并举。首现 vol5 第 001 章。 |
| Balbec | 巴尔贝克 | 诺曼底海滨胜地（原型卡堡）。前三卷只在想象与谈论中出现；vol4 第 1 章叙述者与外祖母真正抵达，住海滨大酒店，教堂在内陆的巴尔贝克镇。首现第1章。 |

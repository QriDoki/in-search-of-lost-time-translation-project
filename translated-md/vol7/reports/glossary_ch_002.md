## 已有术语审查

- `grand'mère → 外祖母`、`grand-père → 外祖父`、`maman → 妈妈`：与第 001 章一致，本章沿用；禁用「外婆」「姥姥」。
- `Cottard → 戈达尔`、`Mme Cottard → 戈达尔夫人`：本章戈达尔以「将军定策」的形象出现，译名不变；禁用「科塔尔」。
- `Sazerat → 萨士拉夫人`：本章只来信一封，沿用旧译。
- `Sévigné → 塞维涅`：本章母亲引外祖母语「塞维涅也未必说得更好」，沿用。
- `avenue Gabriel → 加布里埃尔大道`、`Champs-Élysées → 香榭丽舍`、`Concorde → 协和广场`、`Combray → 贡布雷`、`Balbec → 巴尔贝克`、`Doncières → 唐西埃尔`：地名一致。
- `Legrandin → 勒格朗丹`、`Bloch → 布洛克`、`Jupien → 朱皮安`、`Saint-Loup → 圣卢`、`Rachel → 拉谢尔`、`Bergotte → 贝戈特`、`Françoise → 弗朗索瓦丝`：人物一致。
- `fiacre → 出租马车`、`valet de chambre → 贴身男仆`、`femme de chambre → 贴身女仆`、`valet de pied → 男仆`、`croque-mort → 殡葬工`：社会词一致。
- `étoile → 台柱`（既有条目，指女演员）：本章 `étoile de l'Opéra` 专设新条作「歌剧院明星」，与之并立，不冲突。

# vol3-1 P156 逐句审校

- 法语原文行号 `raw-md/vol3/chapters/001.md:313`
- dev 底稿行号 `polish/dev/chapters/polished-vol3-1.md:314`

法文基线 `raw-md/vol3/chapters/001.md:313`，中文基线 `polish/dev/chapters/polished-vol3-1.md:314`。全段是母亲在街上碰见斯万夫人之后的一句打趣，承接上文“特龙贝尔家既然已经归顺”和“邻近的部落”。

1. **« J’ai aperçu Mme Swann sur son pied de guerre »** 对应“我瞧见斯万夫人一副出征的架势”。`apercevoir` 是一眼看见，“瞧见”符合当面说话的口吻。`sur son pied de guerre` 化用 `sur le pied de guerre`，写她呈现出准备作战的状态。“一副出征的架势”保留原意和母亲的戏谑，可原样保留。[《法语宝库》guerre 词条](https://www.cnrtl.fr/definition/guerre)
2. **« elle devait partir pour quelque offensive fructueuse »** 对应“她想必是要……去发动一场收获颇丰的攻势了”。`elle` 指斯万夫人，`devait` 是母亲根据所见作出的推测，“想必”准确。`quelque` 表示想象中的某一次行动，现译“一场”足以传达。`fructueuse` 说的是料想中的成果。改作“她想必是要……去发动一场攻势，少不了要有些斩获”，让“斩获”接住军事比喻，并保持母亲把预期战果说得煞有介事的口气。[《法语宝库》fructueux 词条](https://www.cnrtl.fr/definition/fructueux)
3. **« chez les Masséchutos, les Cynghalais ou les Trombert »** 对应“到马萨诸塞人、僧伽罗人或者特龙贝尔家那里”。`chez` 的“到……那儿”应保留，上门做客的意思和军事口吻同时存在。`Cynghalais` 是“僧伽罗人”，本章后文也用这个词指驯化园里的僧伽罗人。`les Trombert` 是“特龙贝尔家”，保留“或者”及三者并列。单独看 `Masséchutos`，词形与 Massachusetts 有相似处，但英译注第 190 条也谨慎判断它似为普鲁斯特戏造的名字。现译沿用项目词表“马萨诸塞人”，容易使读者把它认成正式地名的居民称呼。建议音译“马塞舒托人”，保住这个疑似戏造的群体名。原译注正文按约定逐字保留并移接新锚点，其中“殖民地名称”只是一个有待核实的解释。[普鲁斯特原文及上下文](https://www.tha.de/~harsch/gallica/Chronologie/20siecle/Proust/pro_t211.html) [英译注第 190 条](https://thephilosopher.net/prust/wp-content/uploads/sites/369/2025/04/In-Search-of-Lost-Time-Vol-2-Within-a-Budding-Grove-A-lombre-des-jeunes-filles-en-fleurs-Marcel-Proust.pdf)

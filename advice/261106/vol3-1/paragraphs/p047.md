# vol3-1 P047 逐句审校

- 法语原文行号 `raw-md/vol3/chapters/001.md:95`
- dev 底稿行号 `polish/dev/chapters/polished-vol3-1.md:96`

法文基线 `raw-md/vol3/chapters/001.md:95`。译文基线 `polish/dev/chapters/polished-vol3-1.md:96`。

全段为母亲对德·诺尔普瓦先生说的一句话。下文他转向父亲，表示自己也很想同他一道去旅行，印证这里的人物指代和同行关系。

1. **「Et mon mari m'a dit, Monsieur」**。现译「我丈夫跟我说，先生」。转述关系和称呼都准确。句首 `Et` 把话从德国皇帝的电报转到私人的旅行计划，可用轻轻一转的「对了」接话，并把「先生」移到句首话头处。
2. **「que vous l'entraîneriez peut-être un de ces étés en Espagne」**。现译「您也许将来某个夏天会约他一道去西班牙」。`vous` 是诺尔普瓦，`l’` 指丈夫，`entraîneriez` 是转述中相对于 `m’a dit` 的将来，另有 `peut-être` 明说事情未定。`un de ces étés` 指接下来几个夏天里不确定的某一个，现译时间意思基本准确，但「也许将来某个夏天会」略拗口。`entraîner quelqu’un` 在此强调由诺尔普瓦带动丈夫同行，「约」把动作偏向发出邀约，可译「您也许会在今后某个夏天带他一道去西班牙」。
3. **「j'en suis ravie pour lui」**。现译「我为他高兴」。`en` 指前面这件可能成行的事，`pour lui` 指母亲替丈夫高兴，两处关系都对。`ravie` 的喜悦比平直的「高兴」更强，改为「我真替他高兴」，并另断一句，让母亲的反应自然落下。

## dev 稿处理

已应用以下修订。

——对了，先生，我丈夫跟我说，您也许会在今后某个夏天带他一道去西班牙。我真替他高兴。

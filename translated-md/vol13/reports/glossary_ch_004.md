## 二、已有术语审查（本章语境复核，均无需修改）

- `Saint-Loup` / `Robert de Saint-Loup` / `marquis de Saint-Loup`：本章为全章主角，三种称谓分别用于叙述、亲密称呼、报纸爵称，互不混用；不用「圣卢普」「圣鲁」。
- `Gilberte` / `Mme de Saint-Loup` / `marquise de Saint-Loup`：同一人三阶段称谓；叙述者始终称「希尔贝特」，叙述其封号时用后二者。
- `Cambremer` 族：本章同时出现 marquis de Cambremer（小康布雷梅尔）、Mme de Cambremer-Legrandin（其母、勒格朗丹之姐）、marquise de Cambremer（太夫人）。严格按既有条区分，禁用「康布尔梅」。
- `Jupien` / `la nièce de Jupien`：本章外甥女成为奥洛龙小姐；叙述边界内不点破她与夏吕斯的真正关系。
- `Charlus` / `M. de Charlus`：夏吕斯男爵；本章写他收养养女、替她择婚，以及他对圣卢的「父子之情」。
- `Rachel` / `Charlie` / `Morel`：拉谢尔（女演员）、夏利（莫雷尔的昵称）；**不得混为一人**，本章正是靠两人容貌相似来解释圣卢的转变。
- `Aimé` / `liftier` / `maître d'hôtel`：艾梅为海滨大酒店领班；开电梯的统一作「开电梯的」。
- `Mme Swann` / `Mme de Forcheville` / `Odette`：同一人三层称谓，随婚姻变化，不点破等同。
- `Sodome` / `Gomorrhe`：本章只用形容词性说法（de Gomorrhe / de Sodome），不作书名。
- `Muses`：本章明写九位文艺女神，与帝政家具装饰的「缪斯像」（Muse 条）分列。
- `faubourg Saint-Germain`：转喻贵族社交圈，译「圣日耳曼区」。
- `princesse de Silistrie` / `duc de Luxembourg` / `duc de Châtellerault`：婚配市场的三方，princesse 作「亲王妃」。
- `whist` / `tennis` / `tramway` / `fiacre`：时代风物，分别作「惠斯特牌」「网球」「有轨电车」「出租马车」。

# Chunk 08 校对报告 (第 001 章)

## 术语审查
- `Gilberte` → 「希尔贝特」：初译正确，未改动，与术语表一致。
- `chagrin d'amour`：初译作「爱情之痛」，保留。建议上游在 glossary 中收录该词组，后续 chunk 若再出现此主题词，统一作「爱情之痛」，不要另作「恋爱的痛苦」「失恋之苦」。
- `isolement`：初译作「隔绝」，保留。此处指与人断绝往来的状态，「隔绝」比「隔离」「孤立」更贴合议论语境。
- `amabilité`：初译作「殷勤」，保留。语境是对方示好的举动与言语，而非性情上的和蔼，L2 的判断正确。

## 初译稿典型错误
- 问题类型：单字重复造成句内语感滞涩（「沾不上希望……／沾上……理智的反光」）→ 修正方式：前一处改为「享受不到希望常有的那种甘甜」，后一处保留「映上……光」，避开同字叠现。
- 问题类型：「遗憾那种忧郁的平静」中「那种」指代含混，原文 le calme mélancolique du regret 是「追悔所特有的忧郁的平静」→ 修正方式：改为「在追悔所特有的那种忧郁的平静中端详它」，补出 regret 与 calme 的所属关系。
- 问题类型：比较句宾语错位——「并不比一颗心为改变自己而索取的时间少一分苛刻」把 temps 与 exigences 混在一个比较里 → 修正方式：改为「我们在时间方面提出的要求，与一颗心为改变自己而提出的要求同样过分」，恢复 exigences 对 exigences 的平行。
- 问题类型：「正是由于这份贪婪，我们也许反倒使那些东西未能出现」中「那些东西」孤立悬置，读者需回跳三段才知所指 → 修正方式：改为「我们本希望看到它们立即引出的那一切」，用「它们」承接前句的「温存的话、约会的提议」。
- 问题类型：「一个它也许会被我们看得极不完整的时期」被动加长定语，主语「它」离先行词过远 → 修正方式：改为「在一个我们或许会觉得它很不完整的时期」。
- 问题类型：「意外的不幸」中「意外」在中文里偏中性（意外之喜亦可用），原文 inattendu 在此是负面突袭 → 修正方式：改为「不期而至的不幸」。
- 问题类型：译文把 "ces souvenirs, ces lettres" 的指示回指译丢，改作泛指的「这些回忆、这些信」尚可，但「这个往昔仍在延续，只是在我们心里已经不再如此」一处原译「已经不再如此」过于抽象 → 修正方式：改为「唯独在我们心里不是这样」，并保留破折号引出的「黄金时代／天堂」同位解释。

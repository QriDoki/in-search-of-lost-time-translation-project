## 分寸复核（第 8、9 条细则）

- **失望线**：全段保持「愉快—担忧—愉快延续—愉快终止—一条也拾不起来—只到最后一行才听出‘有意为之的单调’」的递减，未添加“愤怒”“受骗”一类原文没有的判词；末句“她强加在最初几行上的那种有意为之的单调”仍带叙述者事后追认的迟疑，未写成定论。
- **掌声**：只作外部事件处理（贝尔玛换位、画面消失），未写成转机或顿悟。
- **“两个贝尔玛当中，哪一个才是真的？”**：保留疑问句，未作断言。
- **对贝尔玛**：只说“与我前来听的那个人毫无相像之处”“她的才能仿佛没有给它们添上任何东西”，保留原文克制的否定；未加“平庸”“拙劣”。
- **对观众**：“教养糟糕”“跺脚的粗人”是叙述者少年时的视角，未升级为作者评断；也未替他补一句“我后来才明白”。
- **对外祖母**：仅“我对外祖母说我看不清楚，她把观剧镜递给我”，不加亲昵或感伤语。

## 初译稿典型错误（逐条）

1. 「生活在创作的沸腾里」直译 effervescence，中文不自然 → 「沉浸在创作的亢奋里」。
2. 「名义上轮流坐在首位的经理们不过是些昙花一现、有名无实的人物」语序拗口，“轮流坐在首位”生硬 → 「剧院的首脑却是一些昙花一现、有名无实的经理，一个个无声无息地来去」。
3. 「打发一名随从去打听」丢失原文 une de ses suivantes 的女性身份 → 「打发一名侍女去打听」。
4. 「只是她将要穿上的一件更外层的第二件衣服，只是她那份才能必须穿越的一个传导性好坏不等的介质」两处“只是”并列、比喻层次塌陷 → 「不过是罩在身外的第二层衣服，她要穿着它走进去，也不过是一道传导性好坏不等的介质，她的才能必须从中穿过」。
5. 「以三下敲击那不容分说的形式，明明白白地向我们发过来」为英文式同位语硬译 → 「开演前那三下敲击，以一种不容分说的架势，明确无误地朝我们发话了」。
6. 「而我是不请自来地闯进了这一天」把 par effraction（破门而入）弱化 → 「而我破门闯进了他们的这一天」。
7. 「我反倒希望她能在这群人里满意地认出几位她看重的名人」漏掉“她本会看重这些人的评判”这一层，且与下句“表达她的不满”重复 → 「——我反倒希望她能在这群人里满意地认出几位名人，她本会看重这些人的评判——便以演得糟糕来向他们表示自己的不满与鄙夷」。
8. 「这下全白费了」口语偏重，devenait inutile 只是“用不上了” → 「这下全用不上了」。
9. 「可是另一个女演员给头一个配起戏来」搭配生硬 → 「可是另一个女演员接上了头一个的台词」。
10. 「我准是弄错了，不该把这一个当成贝尔玛，因为第二个比她更像，而且念白比前一个更肖似她」双重比较叠床架屋 → 「才把这一个当成贝尔玛：第二个比头一个更像她，念白也比头一个更肖似她」。
11. 「单凭我涌起的那阵恐惧（它比贝尔玛本人可能有的还要不安）……再加上我自己那种……」括号里比较对象残缺，“还要不安”与“恐惧”搭配失当 → 「凭着我心头涌起的那阵恐惧——它比贝尔玛本人可能有的那份不安还要重得多……——这就够了；也凭我自己那种……」。
12. 「我听她，就像我在读*《费德尔》*」前半句缺“在”，与后半句“又像此刻是……”不对称 → 「就像在读*《费德尔》*」。
13. 「尽力不把一星半点的准备时间从每个字、每个动作的持续里扣掉」直译 décoller，中文不可解 → 「尽力不让准备功夫占去每个字、每个动作哪怕一瞬的时间」。
14. 「其深度要一如我有整小时整小时可以支配时那样」句式欧化 → 「深得就像我有漫长的几个小时可以自由支配时那样」。
15. 「她拿单调吟唱的刨子把整段台词推了一遍，而那段台词里本来聚着许多对照」把 rabot 处理成名词工具、“推”字悬空，“聚着许多对照”是英文式搭配 → 「她拿单调一致的吟唱当刨子，把整段台词刨了一遍：那些本来那么分明的对照……」。
16. 「连中学里的学生也不会忽略其效果」冗赘 → 「连中学生也不会忽略其效果」。
17. 「耗去的热劲如此之盛」文白夹杂 → 「投入的劲头如此之大」。
18. 「劳累成疾」是文言压缩 → 「劳累过度而病倒」。
19. 「她以为语言没有它实际那么丰富」缺比较基准、读来歧义 → 「她总以为语言不如实际那么丰富」。
20. 「阔气得令人难以置信」prodigalité 指挥霍铺张，非“有钱” → 「奢侈得令人难以置信」。
21. 「她是一片至诚地对厨房女工说」四字伪古雅 → 「她就这么真心实意地对厨房女工说」。
22. 「她念作 Nev’」照搬法文撇号，中文行文突兀 → 「而她把这 New 念作 Nev」。
23. 「我在剧场里面也感到愉快」salle 指观众厅 → 「在剧场大厅里」。
24. 「在那圣所的红幕拉开之处」sanctuaire 在此为“内殿”，宗教词误植 → 「内殿」。
25. 「她们撩起美丽的袍裾时」péplum 是长袍，“袍裾”仅指下摆 → 「撩起美丽的长袍时」。
26. 「全场被一片一致的寂静淹没，不久这里那里又响起零星的轻笑」clapoter 的“水声拍打”意象被抹平 → 「全场已被一片一致的寂静淹没，不久，笑声便在这片寂静上东一下、西一下地轻轻拍响」。
27. 「就要上场的角色」personnages 指人物而非“角色行当” → 「就要上场的人物」。
28. 「我全部的愉快都中止了」与上文“愉快仍在延续”缺衔接 → 「我所有的愉快也终止了」。
29. 「想一星半点也不漏掉她将给我的那些值得赞叹的理由」宾语后置过长、三个“的”叠用 → 「想把她会给我的那些让我钦佩她的理由一星半点也不放过」。
30. 「生怕贝尔玛被这样一群……惹恼」与后文“这群”重复 → 统一为「这群」。

## 对后续章节的建议

1. **三下开场的敲击**：本 chunk 统一为「开演前那三下敲击」，建议全书沿用此说法，不再另创“三通锣”“三响板”。
2. **étoile / tragédienne**：本 chunk 已分工为“名角”“悲剧女演员”，后文遇到 la divine Berma 一类称号宜另立译法，勿与“名角”混。
3. **弗朗索瓦丝式错听**：中文只能保留错听形式（“纽-约克”）并用一句解释交代；后文若再现同类错听，建议同一处理法（错听形式加引号，解释句用正确形式），绝不加脚注。
4. **米开朗琪罗双喻**：本段先用全名、后用“美第奇家族陵墓的作者”回指，是原文避复手法；后文再提时宜继续用回指。
5. **观剧镜段的认识论**：与后文“名字的幻灭”呼应，建议保持“放大／影像／近旁”三个词根，勿改作“望远镜”“看不清楚”。
6. **“内殿”“长袍”**：属术语表未收的《费德尔》剧场用语，建议补入 glossary，以免后文各译其是。

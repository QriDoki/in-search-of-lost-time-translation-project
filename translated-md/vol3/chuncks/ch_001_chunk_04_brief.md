# vol3 第 001 章 chunk 04 任务简报

## 全书前文
《追忆似水年华》第三卷《在花季少女倩影下》第一部。本卷回到第一人称：叙述者仍是巴黎的少年，与希尔贝特·斯万在香榭丽舍的初恋正由热转冷——本章结束时尚未赴巴尔贝克，全章没有离开巴黎。前两卷已确立：贡布雷的童年、玛德莱娜小蛋糕、斯万与奥黛特的爱情、凡德伊小乐句、维尔迪兰家的「小核心」、盖尔芒特家那边与斯万家那边两条散步路线。前卷术语一律沿用：斯万、奥黛特、希尔贝特、圣卢、夏吕斯男爵、维尔巴里西斯侯爵夫人、盖尔芒特、维尔迪兰、布里肖、福什维尔、凡德伊、莱奥妮姑妈、弗朗索瓦丝、贝戈特、贝尔玛。

## 本章前文与本 chunk 位置
前文：诺尔普瓦首次来家晚餐的那天下午，叙述者终于获准去看贝尔玛的日场《费德尔》；父亲因诺尔普瓦一句话改变了对「文学事业」的态度；祖父母与父母围绕看戏的争执。叙述者期待《费德尔》：只肯在古典剧里看贝尔玛，把《费德尔》与威尼斯的提香、卡尔帕乔并置；论「只有在名作上才能真正看见演员」。 本 chunk：看戏当天：医生反对，他仍执意；对「真理」的渴望压过对病痛的恐惧。

## 格式硬约束（逐条遵守；校对者须逐条核对并在报告中记录）
1. 段落一一对应：译文段落数必须与本 chunk 原文（空行分隔）的段落数完全一致，不得合并或拆分（原文单段的 chunk 译文也只能是一段）。
2. 全文零反引号：任何位置都不得出现反引号；初译若出现，必须移除。
3. 引号：外层“”，内层‘’，左右配对；不得用半角 " 或 ' 充当中文引号。原文以「-- 」起首的对话行译作「——」开头，且不再加引号。
4. 原文用星号标记的斜体一律保留为 Markdown 斜体；斜体内的作品名加书名号（如 *《费德尔》*），外来词、拉丁语、英语斜体不加书名号，按原样保留。
5. 不新增脚注、尾注、译注、解释性夹注；删除任何图片、图注与图片占位符。
6. 原文的 M^me^、M^lle^、M^r^ 是上标写法，译作「夫人」「小姐」「先生」，不带符号。
7. 法文省略号 \... 一律作「……」；破折号用「——」；不用「──」「—」单个代替。

## 文化硬约束（与术语表 note 冲突时以 note 为准）
- 爵位：princesse de X → X 亲王妃（禁「公主」「亲王夫人」）；duchesse → 公爵夫人；baron → 男爵；princesse Mathilde（王室公主）→ 玛蒂尔德公主；grande-duchesse → 大公夫人。
- princesse de Metternich → 梅特涅亲王妃；princesse des Laumes → 洛姆亲王妃；princesse de Parme → 帕尔马亲王妃；princesse de Guermantes → 盖尔芒特亲王妃（与「盖尔芒特公爵夫人」是两个人）。
- 文化词：houris → 天国仙女；维米尔、皮特·德·霍赫；《第九交响曲》《名歌手》；葡萄酒市场（禁「货栈」）；圣心会女子寄宿学校。
- 禁用译名：史万（应作斯万）、黛奥特（应作奥黛特）、虐待狂（应作施虐狂）、亲王夫人。
- 时空边界：本章仍在巴黎，叙述者尚未赴巴尔贝克；Elstir、Charlus、Villeparisis、Saint-Loup、Andrée、Gisèle、Rosemonde 全章不出现，不得引入。
- 阿尔贝蒂娜在本章仅被提及（博纳唐夫人的侄女），不得写成在场人物。
- la Patronne / la patronne（大写、指人时）＝维尔迪兰夫人（老板娘），不是旅馆老板娘。
- 「chez la Patronne, au château de la Raspelière」是预叙伏笔：照原文译出，不改写为已发生之事，不加注。

## 语言质量要求
- 消除翻译腔；长句按原文的思想层次重组，不切成等长短句，也不制造中文无法解析的欧化长句。
- 普鲁斯特的反讽、迟疑、自我欺瞒必须保留分寸：不把「也许」译成断言，不把讥讽加强成斥责，不用四字成语替换原文比喻。
- 不添加原文没有的抒情、典故、解释；不弱化粗俗语；不美化笨拙与重复。
- 对话须见人物：诺尔普瓦的旧式外交辞令、斯万夫人的附庸风雅、弗朗索瓦丝的仆妇口语、科塔尔的医生行话、贝戈特的口语与文体的落差。

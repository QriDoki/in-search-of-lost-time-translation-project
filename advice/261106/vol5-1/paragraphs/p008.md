# p008 逐句审校

## 原文与现译

- 法文：*\... Passe dans son domino noir*
- 现译：*……裹着黑色化装斗篷走过*
- 本行下接 p009 的 `La Toppatelle.`，构成谓语在前、主语在后的跨行诗句；不能把本行单独当作省略主语的完整散文句，也不能误把 `Passe` 当作命令式。

## 逐句／意群分析

1. **\...** → “……”。这是引诗内部的省略，现译保留，未将省略部分补写成原文没有的内容；Markdown 中反斜线只用于转义，不是待译文字。
2. **Passe** → “走过”。结合下行主语 `La Toppatelle`，此处为 `passer` 的直陈式现在时第三人称单数，写人物经过的画面。“走过”准确表达经过这一动作，并没有译为“过去了”而平白引入完成状态。原文为诗歌截句，经过何处在截引中未明示，中文也不应为凑足宾语擅补地点。下一行的名字接在“走过”之后，保留了原诗倒装与延迟揭示人物的节奏。
3. **dans son domino noir** → “裹着黑色化装斗篷”。`dans` 此处写人物穿着、处于斗篷包裹之中，不宜机械译作“在她的斗篷里面”；“裹着”能自然表现这层穿戴关系。`son` 随名词 `domino` 的阳性形式变化，不能据此认定人物为男性；汉语此处省去“她的”不影响归属，也避开跨行主语尚未出现时的冗赘。`noir` 修饰斗篷，译“黑色”准确。`domino` 在这组服饰语境中是化装服饰，并非骨牌；“化装斗篷”已经说明用途，没有误读为普通的黑色物体。
4. **中文句式及跨行衔接**。把两行连读为“……裹着黑色化装斗篷走过／托帕泰拉”，主语后置使译文带诗歌倒装色彩，与法文一致。“披着”也是可用译法，但现译“裹着”没有造成语义偏差或理解障碍，不作仅属措辞偏好的修改。本行不加句号，斜体独立排版保留。

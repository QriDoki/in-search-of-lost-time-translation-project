| Chapitre III — Matinée chez la princesse de Guermantes | 第三章 — 盖尔芒特亲王妃家的午后聚会 | 章题格式照全书：`# 第三章 — …`。源文标题下一行另有同句斜体副题 *Matinée chez la princesse de Guermantes*，须照译、单独成行、保留斜体。matinée 指白天的社交招待会，不作「早晨」「日场」。此处的亲王妃是 avenue du Bois 新宅的女主人，不是公爵夫人。禁用「亲王妃的早晨」「亲王夫人家的下午茶」。 |
| matinée | 午后聚会 | 第003章 4 处均指亲王妃家的白天招待会；章题与正文统一「午后聚会」。与 goûter（下午茶会，规模更小）区分。禁用「早晨」「日场」（日场义见 vol11 条）。 |
| princesse de Guermantes | 盖尔芒特亲王妃 | 本章午后聚会的女主人，与亲王同住 avenue du Bois 新宅。princesse de X 一律「X 亲王妃」；禁用「公主」「亲王夫人」。与公爵夫人严格区分。 |
| prince de Guermantes | 盖尔芒特亲王 | 公爵的堂弟吉尔贝；已迁出旧府、在 avenue du Bois 新建府邸，聚会即在其家举行。禁用「亲王殿下」（源文无 Monseigneur）、「盖尔芒特亲王先生」。 |
| la Berma / Berma | 贝尔玛 | 悲剧女演员。本章：她为女儿与女婿举办 goûter，请帖送到叙述者手中，他最终未去。源文无 madame，不得作「贝尔玛夫人」；不加冠词式的「拉贝尔玛」。 |
| Gilberte | 希尔贝特 | 本章回忆：在坦松维尔与她每日散步、深夜才回房吃饭，正是在那时认定自己无文学天赋。禁用「吉尔贝特」。 |
| Guermantes | 盖尔芒特 | 家族名与地名。本章：请帖上这个名字重新唤起贡布雷的空气、鸟街与彩窗的旧魔力，随后又因亲王迁居而失效。le côté de Guermantes（散步路线）作「盖尔芒特家那边」；les Guermantes 作「盖尔芒特一家」。 |
| du côté de Guermantes | 盖尔芒特那边 | 本章 « du côté de Guermantes » 是方位短语（「当年我自以为在盖尔芒特那边发现了文学天赋」），**不加书名号**；与书名《盖尔芒特家那边》分列。 |
| Combray | 贡布雷 | 童年度假小镇。本章：盖尔芒特之名使他想起贡布雷「酸涩而端正的空气」，觉得这一家「与任何活人不可比」。 |
| rue de l'Oiseau | 鸟街 | 贡布雷的一条街。本章：童年傍晚回家前从这条街外望见教堂彩窗，那彩窗像一块深色漆屏。禁用「奥瓦索街」「鸟之街」「百鸟街」。 |
| Tansonville | 坦松维尔 | 斯万家的乡间宅邸，希尔贝特婚后居此。本章：在此读到《龚古尔兄弟日志》，由此认定文学是虚荣、自己无才。禁用「唐松维尔」「坦松维勒」。 |
| Paris | 巴黎 | 本章「回巴黎」「久离巴黎」，照常作「巴黎」。 |
| journal des Goncourt | 《龚古尔兄弟日志》 | 本章小写 journal，仍作《龚古尔兄弟日志》，不作《龚古尔日记》。叙述者在坦松维尔读它，由此认定「文学是虚荣与谎言」。 |
| maison de santé | 疗养院 | 本章开篇：第二家疗养院并未治好他，且住了很久。不作「医院」「疗养所」。 |
| gens du monde | 上流社会的人 | 本章 `C'est un des torts des gens du monde de ne pas comprendre que…` 作「上流社会的人有一桩毛病：不明白……」。 |
| homme du monde | 上流社会的人 | 本章 `mener la vie de l'homme du monde` 作「过上流社会的生活」。禁「世界人」「世俗之人」。 |
| esprit | 机智／心智 | 沙龙式的急智义作「机智」；本章 `netteté d'esprit` 作「头脑清楚」，`joies de l'esprit` 作「精神的快乐」。按语境，不一律「机智」。 |
| travail | 「写作」 | 叙述者念兹在兹的「写作」，源文加引号，译文保留引号。不作「工作」「劳动」「活儿」；禁用「那部大作」（此时尚未动笔）。 |
| Gilbert le Mauvais, sire de Guermantes | 盖尔芒特领主恶人吉尔贝 | 贡布雷教堂彩窗上的盖尔芒特家先祖。既有条目作「恶人吉尔贝」，禁「坏国王吉尔贝」「恶人吉尔伯特」；sire 只作「领主」，**不得升格为「国王」「陛下」**。全句宜作「盖尔芒特领主恶人吉尔贝的彩窗」。禁用「吉尔贝·勒·莫韦」。 |
| vitrail | 彩绘玻璃窗 | 本章：童年从鸟街外望见的那扇彩窗，像一块深色漆屏。不作「花玻璃」。 |
| goûter | 下午茶会 | 贝尔玛为女儿与女婿举办，请帖送到叙述者手中。与 matinée 区分；不作「点心」「品尝会」。禁用「午后点心」。 |

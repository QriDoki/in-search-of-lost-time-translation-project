# Chunk 22 校对报告 (第 004 章)

## 术语审查
- Gilberte → 希尔贝特、Balbec → 巴尔贝克、Albertine → 阿尔贝蒂娜、Andrée → 安德蕾：初译均按术语表执行，未改动。
- rythme binaire → 「双重节奏」：保留初译，与本章「反向的节奏／退潮」呼应；未采用「二元节奏」，建议后续 chunk 沿用。
- dureté → 「严厉」，froideur → 「冷淡」：初译把两词都译作「冷淡」。原文此处刻意区分严厉与冷淡（后文 protestations de froideur 才是「冷淡」），故将 Ma dureté 改译为「严厉」，后半仍作「冷淡」。建议上游为 dureté 登记本 chunk 译法。
- lampas aurore → 「曙光色的锦缎」：保留初译。lampas 为有光泽的提花丝织物，中文无通行对应，「锦缎」可读；是否需要入表由 L1 决定。
- bonne camarade → 「好伙伴」：保留。建议 L1 核对本章前文是否已用「好同志／好朋友」，若已用则统一，择一即可。

## 初译稿典型错误
- 词义混同：「Ma dureté avec elle」译作「我对她的冷淡」，与同段 froideur 撞车 → 改为「严厉」。
- 指代缩水：「une simplicité et une franchise … qu'on n'a guère … que pour les amours…」初译只保留「这种坦率」，漏掉 simplicité → 补为「这种单纯与坦率」。
- 悬空结构：「这种双重节奏，是爱情在……的人身上所采取的。」缺宾语 → 重组为「那些过分怀疑自己的人……在爱情中都会采取这种双重节奏」。
- 搭配生硬：「纯粹人的情感」→「仅仅属于常人的情感」；「几乎毫不真实」自相矛盾 → 「就变得如此不真」（对应 ce qui le devenait si peu）；「认出了……明晰」→「看出了……清晰」。
- 长句欧化：「我们说话时便带着学究……时的那种缺乏品味与不知羞耻」名词化堆叠、双「的」 → 改为「便像学究对着无知者抛出……，既没有品味，又不知羞耻」。
- 隐喻脱落：「inventaient les mêmes romans」译「编造的是同样的故事」→「编造的是同样的爱情小说」，保留 romans 的小说隐喻。
- 标点体例：「我让阿尔贝蒂娜看这景象：」后接她的答话，冒号易被误读为引出所示之物 → 改为句号；「走进走廊、单独相处」以顿号连接两个动作 → 「我们刚一单独待在走廊里」。

## 格式自检
- 段落数 2，与源文第 35、36 段一一对应，未合并或拆分。
- 第 1 段两处对话均按源文 « » 位置起收（“您对我有什么不满？”“别转移话题……像我一样坦率吧。”），未整段加引号；末尾自由间接引语「机遇又怎会……」保持无引号。
- 引号逐段成对；无 ASCII 引号、无反引号、无图片、无脚注、无 ASCII 双连字符、无 ASCII 省略号、无 ^、无『』、无 [待定]、无出版机构信息。

## 对后续章节的建议
- 全章反复出现 dureté／froideur／indifférence 近义层次，建议统一为「严厉／冷淡／无动于衷」，避免一律作「冷淡」。
- 「双重节奏」（rythme binaire／rythme double）是本章分析性关键词，后续 chunk 宜沿用，勿改「二元节奏」。
- franc parler 与 franc（坦率）的词根呼应，本 chunk 以「直言不讳」与「坦率」保留；后文再出现时建议沿用这一对。

# 《追忆似水年华》阅读器 · 云存储与摘录系统前端交互设计

本文是 [plan.md](./plan.md) 的交互层设计，覆盖摘录、批注、书签、阅读进度、OneDrive 同步与分享的完整用户流程。实现基于现有 VitePress 主题（`site/.vitepress/theme/`），沿用 `ReaderDock` 面板、`ReaderAnnotations` 弹层等既有交互模式，不引入新的 UI 框架。

## 0. 交互总原则

1. **阅读优先**：所有摘录/同步 UI 不得打断阅读。同步、冲突、重定位一律非阻塞提示；任何云端失败不影响本地操作。
2. **无登录可用**：未连接 OneDrive 时，除「同步」相关入口外全部功能可用，且界面不出现登录劝诱弹窗。连接入口只在用户主动打开的面板里出现。
3. **沿用既有语言**：面板 = `reader-panel`（右侧抽屉 + 遮罩，Esc/点击遮罩关闭）；弹层 = `reader-annotation-popover` 的定位与 hover/pin 模式；轻提示 = toast。新组件复用这些 class 与动效。
4. **可撤销优于确认**：单条删除用「撤销 toast」，不用确认弹窗；批量删除、断开连接、导入覆盖等不可逆或影响面大的操作才用确认对话框。
5. **状态诚实**：同步状态、定位失效、冲突必须可见，不静默吞掉（对应 plan §6、§5.2「宁可无法精确定位，也不错误关联」）。

## 1. 信息架构与入口

### 1.1 顶部导航（`Layout.vue` 的 `reader-nav`）

现有：`目录`、`阅读设置`。新增：

```text
[下载EPUB] [GitHub]                [目录] [摘录] [阅读设置] [☁︎]
```

- **摘录**：打开摘录面板（§3）。所有页面可见（与「目录」一致），面板内可跳转任意章节。
- **☁︎ 同步状态图标**：仅在已连接 OneDrive 后出现；未连接时不显示（入口收在「阅读设置 → 云同步」里，见 §5）。图标本身即状态指示（§6.1），点击打开「云同步」面板。
- 「摘录」按钮右上角可出现小红点：存在未处理冲突或失效摘录时提示，处理后消失。

### 1.2 面板体系

### 1.3.1 现有可复用组件调研清单

以下结论基于对 `site/.vitepress/theme/` 全部 10 个组件、4 个 composable 及构建脚本的逐一阅读。

**① `ReaderAIEdit.vue` —— 选区交互的直接前身（复用度最高）**

已实现本设计 §2.1 所需的大半基础设施：

- `selectionchange` 监听 + 选区必须完整落在 `.reader-chapter .vp-doc` 内的校验（`updateSelection`）——工具条触发逻辑直接沿用，含「选区跨出正文则无效」的判定。
- 浮动按钮的 fixed 定位、`env(safe-area-inset-*)` 适配、`@pointerdown.prevent` 防止点击按钮清除选区——工具条必须继承这一细节，否则点色块瞬间选区就没了。
- `reader-ai-notice` 提示条（`role="status"` + `aria-live="polite"` + 关闭按钮 + 成功/失败两态）——泛化为 `ReaderToast`，撤销按钮即在此结构上加一个 action 槽位。
- 原生 `<dialog>` 模态（backdrop 点击关闭、`autofocus`、Esc 原生 cancel）——§5 连接说明、断开确认、§10 导入预览等所有确认对话框复用此模式，不引第三方 modal。
- `navigator.clipboard.writeText` + generation 竞态守卫 + 失败提示——「复制」「复制链接」直接沿用，含剪贴板不可用时的错误文案。

**交互冲突与决策**：现有 AI 编辑浮动按钮（右下 58px 圆钮）同样由选区触发，与新工具条并存会出现两个选区 UI 互相打架。**决策：将「✦ AI修订」收编为工具条末尾的一个动作**，点击后走现有 `copyPrompt` + Agent 对话框流程（逻辑原样保留）；独立的浮动圆钮在阅读页退役。`ReaderAIEdit` 组件不删除，改造为工具条的动作提供方。

**② `ReaderSearchHighlight.vue` + `search.mjs` —— 高亮渲染与文本定位的现成算法**

- 「字符区间 → 跨 Text 节点拆分包裹 `<mark>`」算法（`splitText` 从后往前拆，能跨越强调/注解锚点）——用户高亮渲染器（anchor.ts 的 render 部分）与分享落地的临时高亮直接复用，只换 mark 的 class 与数据来源。`clearMarks` 的 `replaceWith(...childNodes)` + `normalize()` 清理逻辑同样复用。
- 滚动到首个 mark 的偏移公式（`max(90, innerHeight * .35)`）——§8.3 跳转定位沿用，保证全站跳转落点一致。
- `search.mjs` 的 `matchRanges`（精确文本匹配）、`highlightParts`/`excerptParts`（命中高亮与上下文窗口摘录）——分别用于定位策略级别 2（原文精确匹配）、摘录面板关键词搜索的命中高亮、书签列表的段落首句截取。
- **共存规则**：搜索高亮（`mark[data-reader-search]`）、用户高亮（`mark.reader-highlight`）、分享临时高亮三者可同时存在于同一段正文。渲染顺序：用户高亮先注入，搜索/分享高亮后注入且允许嵌套；清理各自只认自己的 data 标记，互不误删。

**③ `ReaderAnnotations.vue` —— 弹层机制整体提取复用**

- `updatePosition`（锚点居中、上下翻转、视口边界 clamp）、ResizeObserver 重定位、scroll/resize 跟随——提取为 `composables/usePopoverPosition.ts`，书内注解弹层与用户摘录弹层共用。
- hover 预览 / click 固定的双态（`pinned`、120ms 延迟关闭、`any-hover: hover` + `pointerType === 'mouse'` 检测排除触屏合成事件）——§2.2 的 hover 预览原样沿用。
- 固定态遮罩、Esc 关闭并归还焦点、`aria-expanded`/`aria-controls` 联动——§2.3 沿用。
- 注意：书内注解弹层与摘录弹层**互斥**（打开一个关闭另一个），避免两个 popover 叠在同一触发区。

**④ `ReaderDock.vue` —— 面板骨架与进度定位原型**

- 面板体系（`reader-panel` + `reader-backdrop` + `reader-panel`/`reader-fade` 过渡 + Esc/遮罩关闭 + 打开目录自动滚到当前条目）——摘录面板、云同步面板直接套用，仅扩展 `panel` 联合类型。
- `maybeResume` 的「段落 ID 命中 → paragraphHash 回退 → 页面百分比兜底」三级恢复——正是 plan §5.2 定位策略的进度版原型，anchor.ts 将其泛化为摘录的五级定位；`hashText`（FNV-1a）可继续用作段落内容指纹。
- `scheduleSave` 650ms 防抖 + `pagehide`/路由切换强制落盘——批注自动保存与同步队列防抖沿用同一节奏。
- `collectParagraphs` 的段落采集与 `data-reader-paragraph` 标注——高亮渲染器遍历正文的入口。

**⑤ `ReaderSearch.vue` —— 列表搜索交互范式**

- 100ms 防抖 + `sequence` 竞态守卫 + `isComposing` 中文输入法保护——摘录面板搜索框直接沿用（数据量小，无需 Worker，本地过滤即可）。
- ↑↓ 循环选择 / Enter 跳转 / Esc 关闭、`role="combobox"`/`listbox`/`option` + `aria-activedescendant`——摘录列表与冲突列表的键盘导航沿用。
- `sessionStorage` 记住查询词、`loadMore` 分页——摘录面板筛选状态记忆沿用。
- 原生 `<dialog>` 全屏搜索的 `overflow: hidden` 锁定/恢复——任何全屏模态沿用。

**⑥ `ReaderAnnotationTypes.vue` —— 下拉多选菜单范式**

- Teleport 到 body 的下拉菜单、按剩余空间自动上/下翻转、外部 pointerdown 关闭、页面滚动关闭（菜单内滚动除外）、checkbox 组——摘录面板的「卷/章」「颜色」筛选器与「导出 ▾」菜单直接套用此结构。

**⑦ `ReaderVersionMenu.vue` / `ContinueReading.vue` / `ReadingProgress.vue` / `ChapterNav.vue`**

- `ContinueReading`：首页「继续阅读」入口，数据源从 localStorage 换成合并后的进度即可，`?resume=1` 约定不变（§6.2）。
- `ReaderVersionMenu`：站点存在 dev 与多个发布版本（`/versions/*`），版本切换是整页导航。**摘录数据必须跨版本可用**：以永久段落 ID 为键（见 §1.3.5），`revision` 记录创建时版本；切换版本后对当前页摘录重跑定位流程。版本下拉的 details/radiogroup + localStorage 记忆模式可供账号菜单参考。
- `ReadingProgress`（顶部进度条）、`ChapterNav`（翻页卡片）：不改动。

**⑧ composables 与构建脚本**

- `reader.ts`：`sanitizePrefs`/`sanitizePosition` 的白名单校验、v1→v2 迁移、`try/catch` 包裹的存储降级——IndexedDB 层与 JSON 导入校验沿用同一套防御模式；`prefs` 未来对应云端 `settings.json`。
- `book.ts`/`toc.ts`：`PageMeta`（卷/章/字数/路径）、`flattenEntries`、`currentEntryPath`——摘录面板的分组、筛选、「第一卷 · 贡布雷 · ¶123」位置标签、按正文位置排序全部由现成元数据驱动，无需新数据结构。
- `search.ts` 的 Worker 封装（requestId + pending Map + 错误重建）：同步模块的并发请求管理参考此模式；摘录搜索本身不需要 Worker。
- `scripts/lib/annotation-types.mjs`：构建期注解类型过滤，与用户摘录无关，但「类型多选过滤」的 sanitize 模式可参考。

### 1.3.2 样式与层级约定（复用现有 token，不引 UI 框架）

- 设计 token 全部沿用 `custom.css`：`--reader-accent`/`--reader-accent-soft`（四主题各有一套）、`--reader-panel-shadow`、`--reader-serif`/`--reader-sans`、VitePress 的 `--vp-c-bg-elv`/`--vp-c-divider`/`--vp-c-text-1/2`/`--vp-c-brand-*`。
- 复用 class：`reader-panel*`（面板骨架）、`reader-setting*`（设置行）、`reader-text-button`/`reader-icon-button`、`reader-segmented`（分段选择器，可用于排序切换）、`reader-note-select*`（下拉）、`reader-ui`（浮层统一标记）、`reader-fade`/`reader-panel` 过渡。
- **新增 token**：四色高亮底色 `--reader-highlight-yellow/green/blue/purple`，在 paper/light/sepia/dark 四个主题块各定义一份（深色主题提亮降饱和）。
- z-index 层序（现有值，新组件对号入座）：正文 mark（文档流）< 注解触发器 45 < AI 按钮 46（退役）< 面板遮罩 47 / 面板 48 < 注解遮罩 60 / 弹层 61 < 提示条 65。**选区工具条取 62**（压过弹层、低于 toast）；分享落地卡取 63；确认对话框用原生 `<dialog>` top layer，天然最高。

### 1.3.4 构建侧依赖（P0 前置，非前端组件但阻塞交互）

- **现状**：`site/.vitepress/paragraphs.mjs` 的 `paragraphAnchorsPlugin` 按渲染顺序生成 `p-000001` 式**位置 ID**，译文增删段落即整体漂移——不满足 plan §5.1 的永久 ID 要求。

- 进度与摘录的存量数据迁移：旧 `p-000001` 键按「同版本位置 ID → 永久 ID」映射表一次性升级（沿用 `reader.ts` 的 v1→v2 迁移模式）。

## 2. 摘录核心交互

### 2.1 选中文字 → 浮动工具条

**触发**：在 `.vp-doc` 正文内产生非折叠选区（桌面 `mouseup`/`selectionchange` 稳定后；触屏选区手柄释放后）。选区可跨段落（plan §4），工具条锚定选区首行上方，空间不足时翻到下方，复用 `ReaderAnnotations.updatePosition` 的边界算法。

```text
        ┌────────────────────────────────────────────────────────┐
        │ 🟡 🟢 🔵 🟣 │ ✎ 批注 │ 🔖 书签 │ ⧉ 复制 │ 🔗 链接 │ ✦ AI修订 │
        └────────────────────────────────────────────────────────┘
   正文……那是【很久以前的事了，那时贡布雷的】教堂……
              ↑ 选区（跨段落时工具条锚定起点）
```

- **色块 ×4**：黄（默认）/绿/蓝/紫。点击即创建高亮并关闭工具条；色块在四种主题（纸张/浅色/护眼/深色）下分别定义半透明底色，深色主题提高明度、降低饱和，保证正文对比度 ≥ 4.5:1。
- **批注**：以默认色创建高亮并立即打开弹层的批注编辑态（§2.3）。
- **书签**：对选区起始段落添加/移除书签（toggle，§4）。
- **复制**：复制选区纯文本，toast「已复制」。
- **链接**：创建永久链接并复制（§8），不要求先创建高亮。
- **✦ AI修订**：收编自现有 `ReaderAIEdit` 浮动按钮（§1.3.1 ①）。点击复制修订提示词并弹出现有 Agent 选择对话框，流程与文案不变；独立浮动圆钮退役，避免两个选区 UI 并存。
- 工具条按钮一律 `@pointerdown.prevent`（沿用 `ReaderAIEdit` 的关键细节），防止按下按钮的瞬间选区被清除。
- 点击工具条以外区域、按 Esc、选区塌陷、开始滚动 → 工具条消失。
- 工具条出现时**不**触发 `Layout.vue` 的「整页点击收起页头」逻辑（选区非折叠已被排除，保持现状）。

**触屏差异**：不覆盖系统原生选区菜单（复制/查询），在视口底部固定一条同款动作栏（bottom action bar），避开系统菜单；动作栏不随滚动移动，选区清除即消失。

**键盘**：选区存在时工具条按钮可 Tab 聚焦；`Esc` 关闭并保留选区。

### 2.2 高亮的正文呈现

- 渲染：`<mark>` 包裹精确选区；底色 = 用户色；有批注的高亮在末尾追加一个细笔下划线标记（或段末小图标），与书内注解的角标样式区分。注入算法复用 `ReaderSearchHighlight` 的跨 Text 节点拆分方案（§1.3.1 ②），天然支持跨越强调、书内注解锚点的选区；与搜索高亮、分享临时高亮按 data 标记各清各的，可共存嵌套。
- **重叠高亮**：允许重叠，底色叠加加深；点击重叠区时弹层列出覆盖该位置的全部摘录（最多 3 条 + 「在摘录面板中查看全部」）。
- **hover（仅鼠标设备）**：指针悬停 300ms 显示只读预览弹层（原文 + 批注前 2 行），移开 120ms 延迟关闭——完全复用 `ReaderAnnotations` 的 preview/pin 双态与 `any-hover` 检测。
- **点击/触屏轻点**：固定（pin）弹层，进入可操作态。

### 2.3 摘录弹层（ReaderHighlightPopover）

```text
┌────────────────────────────────────────┐
│ 「那是很久以前的事了，那时贡布雷的…」   │  ← 摘录原文（serif，可折叠超长）
│ ────────────────────────────────────── │
│ 批注内容（无批注时显示「添加批注…」）   │
│                                        │
│ 🟡 🟢 🔵 🟣   第一卷 · 贡布雷 · ¶123   │  ← 改色即生效；位置信息可点击跳转
│ [✎ 编辑批注] [🔗 复制链接] [🗑 删除]    │
└────────────────────────────────────────┘
```

- **编辑批注**：原位切换为 textarea（自动聚焦、自动增高），纯文本，失焦或 `Cmd/Ctrl+Enter` 保存（650ms 防抖自动保存，与进度保存节奏一致），`Esc` 放弃未保存修改并退出编辑态。保存后 `updatedAt` 更新并进入同步队列。
- **改色**：点击色块立即生效，无确认。
- **删除**：软删除（写 `deletedAt`），高亮即时从正文移除，toast「已删除摘录 · 撤销」（5 秒）。撤销 = 清除 `deletedAt`。同步队列合并「创建+删除」为无操作。
- **复制链接**：生成永久链接（§8），toast「链接已复制（不含批注）」。
- 弹层定位、遮罩、Esc、焦点归还均沿用 `ReaderAnnotations` 现有实现（定位逻辑提取为 `usePopoverPosition` 共用，§1.3.1 ③）；与书内注解弹层互斥，打开一个即关闭另一个。
- 弹层内**不显示**同步状态细节；仅在同步失败且该条受影响时显示一行小字「未同步 · 查看详情」（链到云同步面板）。

### 2.4 空选区/无效选区

- 选区完全落在书内注解弹层、面板、工具条自身内 → 不触发。
- 选区跨出正文（含标题、页脚）→ 截取正文内部分；截取后为空则不触发。
- 同一选区重复创建相同范围+颜色的高亮 → 不重复创建，直接打开已有摘录弹层。

## 3. 摘录面板（ReaderExcerpts）

```text
┌─ 摘录 ─────────────────────────── × ─┐
│ [摘录] [书签]            🔍 搜索摘录  │  ← 两个 tab
│ 筛选: 全卷 ▾  颜色 ▾  ☐ 只看有批注    │
│ ☁︎ 已同步 · 3 分钟前        [导出 ▾]  │  ← 状态行（未连接时显示「仅保存在本机」）
│ ──────────────────────────────────── │
│ ▍🟡 那是很久以前的事了，那时贡布雷…   │  ← 左缘色条 = 高亮色
│   批注：这里和斯万的爱情形成对照…     │
│   第一卷 · 贡布雷 · 2026-11-20        │
│   [跳转] [🔗] [🗑]                    │
│ ──────────────────────────────────── │
│ ▍🔵 ……（定位失效的条目见 §9.3）       │
│ …                                    │
└──────────────────────────────────────┘
```

- **排序**：默认按正文位置（卷→章→段落序），可切换「最近创建/最近修改」。
- **筛选**：卷/章下拉（复用目录数据）、颜色多选、「只看有批注」、关键词搜索（原文+批注，本地即时过滤）。下拉菜单套用 `ReaderAnnotationTypes` 的 Teleport + 上下翻转 + 外点关闭范式；搜索框沿用 `ReaderSearch` 的防抖、中文输入法保护与 ↑↓/Enter/Esc 键盘导航（§1.3.1 ⑤⑥），命中文字用 `highlightParts` 高亮。
- **条目操作**：
  - 点击条目主体或「跳转」→ 关闭面板，滚动到对应段落，目标高亮闪烁 2 次（§8.3 同款动效）。
  - 🔗 复制永久链接；🗑 软删除 + 撤销 toast。
  - 条目上的批注可直接展开编辑（同 §2.3 规则）。
- **批量模式**：长按/勾选进入多选，底部出现「删除所选 (N)」「导出所选」；批量删除用确认对话框（不可撤销提示 + 数量）。
- **空态**：
  - 摘录 tab：「选中正文文字即可划线摘录。摘录保存在本机，连接 OneDrive 后可跨设备同步。」+ 指向正文的示意小图。
  - 书签 tab：「在选区工具条上点 🔖，为段落加书签。」
- **失效摘录**：定位降级的条目带「定位失效」徽标并可用筛选器单独列出（§9.3），不混入正常排序的视觉噪声。

## 4. 书签

- **粒度**：段落级（永久段落 ID），不做字符级。
- **添加**：选区工具条 🔖（toggle）；桌面端另在段落 hover 时段落左侧页边显示淡色 🔖 快捷按钮（触屏不显示，避免误触）。
- **正文呈现**：已 bookmark 的段落左缘显示常驻小书签图标（主题色，低对比），点击 = 移除 + 撤销 toast。
- **列表**：摘录面板「书签」tab，按正文位置排序，显示段落首句摘录（前 40 字）+ 章节 + 添加时间；操作：跳转 / 删除。
- 书签与阅读进度相互独立：加书签不改变「在读」位置。

## 5. OneDrive 连接与账号（云同步面板 · 账号区）

### 5.1 入口

- 未连接：「阅读设置」面板底部新增「云同步」区块，一行状态「未连接 · 数据仅保存在本机」+ 按钮「连接 OneDrive」。摘录面板状态行点击同样进入。
- 已连接：顶部 ☁︎ 图标 → 云同步面板。

### 5.2 首次连接流程

```text
[连接 OneDrive]
   ↓ 说明对话框（一次性，可勾选「不再提示」）
   ┌────────────────────────────────────────────┐
   │ 把摘录同步到你自己的 OneDrive               │
   │ · 数据存放在 OneDrive「应用/Proust Reader」 │
   │ · 本应用只能访问这一个文件夹，              │
   │   无法读取你的其他文件                      │
   │ · 不登录也能正常阅读和摘录                  │
   │ · 可随时断开并导出全部数据                  │
   │              [取消]  [前往微软登录]         │
   └────────────────────────────────────────────┘
   ↓ MSAL popup（Authorization Code + PKCE，仅 Files.ReadWrite.AppFolder）
   ↓ 成功回调
   ┌────────────────────────────────────────────┐
   │ 已连接：user@example.com                    │
   │ 本机已有 23 条摘录、5 个书签、阅读进度      │
   │ 云端已有 41 条摘录（来自其他设备）          │
   │ 将合并两边数据；相同摘录的冲突会请你选择。  │
   │                    [开始同步]  [稍后]       │
   └────────────────────────────────────────────┘
```

- 两个对话框均用原生 `<dialog>` 模式（复用 `ReaderAIEdit`/`ReaderSearch` 的模态范式：backdrop 点击关闭、Esc 原生 cancel、autofocus，§1.3.1 ①⑤），不引第三方 modal。
- 首次同步前拉取云端清单做预览计数；「稍后」= 保持已连接但暂停自动同步，状态显示「同步已暂停」。
- 登录失败/用户关闭 popup：toast「未完成登录」，回到未连接态，不重试轰炸。
- 权限说明措辞必须与真实 scope 一致（AppFolder），不得出现「访问全部文件」类表述。

### 5.3 已连接态

```text
┌─ 云同步 ───────────────────────── × ─┐
│ 👤 user@example.com      [断开连接]  │
│ ☁︎ 已同步 · 今天 14:32     [立即同步] │
│ ──────────────────────────────────── │
│ ⚠ 2 条摘录冲突待处理        [查看]   │  ← 有才显示
│ ──────────────────────────────────── │
│ 数据                                 │
│ [导出 JSON 备份] [导入 JSON]         │
│ [生成摘录集 DOCX / Markdown]         │
│ 上次备份：从未（建议定期导出）        │
└──────────────────────────────────────┘
```

- **断开连接**：确认对话框，默认选项「断开并保留本机数据」（推荐项）；附加勾选「同时清除本机缓存的云端数据」。断开后本地摘录/书签/进度全部保留，回到未连接态。明确文案：「断开不会删除 OneDrive 中已同步的文件」。
- **切换账号**：即「断开 → 连接新账号」。本地数据按账号 ID 命名空间隔离（plan §7）：切换后界面只显示新账号空间 + 本机未连接期间的数据；旧账号数据保留在其命名空间，切回即恢复。切换确认对话框需说明这一点。
- **凭证过期**：MSAL 静默续期；失败则状态变为「需要重新登录」，云同步面板顶部出现横幅 + 按钮「重新登录」（走 popup，不丢本地数据）。阅读与本地摘录不受影响。

## 6. 同步状态与反馈

### 6.1 状态机（☁︎ 图标 + 面板状态行共用）

| 状态 | 图标 | 文案 | 触发 |
|---|---|---|---|
| 未连接 | （不显示图标） | 数据仅保存在本机 | 默认 |
| 已同步 | ☁︎✓ | 已同步 · 相对时间 | 队列清空且无冲突 |
| 同步中 | ☁︎ 旋转 | 正在同步… | 增量读写进行中 |
| 待同步 | ☁︎·N | N 项待同步 | 本地有未上传变更（含离线积压） |
| 离线 | ☁︎̸ | 离线 · 更改已保存在本机 | `navigator.onLine === false` 或请求网络错误 |
| 冲突 | ☁︎⚠ + 红点 | N 条冲突待处理 | eTag 校验发现同条并发修改 |
| 错误 | ☁︎! | 同步失败 · 重试 | 非网络错误（401 除外，走重新登录） |
| 暂停 | ☁︎⏸ | 同步已暂停 | 首次连接选了「稍后」/手动暂停 |

- 状态切换不打断阅读：图标原位变化，无 toast；仅「同步完成且本次有冲突/失败」时发一条 toast。
- 「立即同步」按钮在同步中变为「同步中…」禁用态；失败后变为「重试」。
- 自动触发时机与 plan §6 一致：打开阅读器、数据变更（防抖 3s 合并）、`online` 事件、手动。同步全程后台进行，无全屏 loading。

### 6.2 阅读进度的跨设备交互

- 打开章节时：本地与云端进度合并取 `updatedAt` 较新者，**同页**差异静默采用，不打扰。
- **异页**且云端更新（另一台设备读到了别处）：页面顶部出现非阻塞横幅卡片：

```text
┌────────────────────────────────────────────────┐
│ 另一台设备读到了 第三卷 · 盖尔芒特家那边 · 62% │
│                        [跳转过去]  [留在这里]  │
└────────────────────────────────────────────────┘
```

- 「跳转过去」= 导航 + 恢复进度；「留在这里」/忽略/开始滚动 → 横幅消失，本地位置成为最新。绝不自动跳转。
- 现有「继续阅读」入口（`ContinueReading`）数据源改为合并后的进度，交互不变。

## 7. 冲突处理

- 入口：☁︎ 红点 / 摘录面板状态行 / 云同步面板「N 条冲突待处理」。
- 冲突列表 → 单条冲突卡片，两版本并排（移动端上下排）：

```text
┌─ 摘录冲突 (1/2) ──────────────────────────────┐
│ 原文：「那是很久以前的事了……」                │
│ ┌─ 本机版本 ──────────┐ ┌─ 云端版本 ─────────┐ │
│ │ 🟡 批注：A……        │ │ 🟢 批注：B……       │ │
│ │ 修改于 14:20        │ │ 修改于 14:31       │ │
│ └─────────────────────┘ └────────────────────┘ │
│ [保留本机] [保留云端] [两者都保留]   ‹ 1/2 ›   │
└───────────────────────────────────────────────┘
```

- **两者都保留**：云端版本另存为新摘录（新 UUID，原文相同、批注/颜色取云端），两条都回到正常态。
- 逐条处理，处理完自动进入下一条；全部解决 → toast「冲突已处理，正在同步」→ 状态回「同步中→已同步」。
- 允许「稍后处理」关闭；冲突未处理期间该两条摘录在正文按**本机版本**渲染，弹层带「冲突待处理」小字。
- 删除 vs 修改的冲突同样出卡片（一版显示「已删除」），不静默复活已删除摘录（plan §6 软删除）。

## 8. 永久链接与分享

### 8.1 链接生成

- 入口：选区工具条 🔗、摘录弹层 🔗、摘录面板条目 🔗。
- URL 自包含（plan §5.3）：章节路径 + 永久段落 ID + 编码后的摘录原文与前后上下文（`exact/prefix/suffix`），不含批注、不含任何凭证。
- 生成即写入剪贴板，toast「链接已复制（不含批注）」。剪贴板 API 不可用时降级为可选中复制的输入框弹层。

### 8.2 打开链接（无需登录）

1. 正常加载章节 → 按五级定位策略找到段落与范围（§9）。
2. 滚动至目标段落（居中偏上，沿用 `maybeResume` 的锚点偏移）。
3. 目标文字渲染**临时高亮**（分享者颜色，2.5s 呼吸闪烁后转为常驻淡色，直到用户离开本页）。
4. 视口底部出现落地卡（ReaderShareLanding）：

```text
┌────────────────────────────────────────────┐
│ 来自分享的摘录                              │
│ 「那是很久以前的事了，那时贡布雷的……」     │
│ [保存到我的摘录]  [复制正文]  [×]           │
└────────────────────────────────────────────┘
```

- 「保存到我的摘录」：以当前用户颜色创建本地高亮（进入同步队列），卡片变为「已保存 ✓」后自动收起。
- 定位失败（译文已更新且模糊匹配失败）：仍滚动到永久段落 ID 对应段落，落地卡显示「译文已更新，原文可能略有出入」+ 展示分享时的原文，供读者对照；不假装精确命中。
- 落地卡可手动关闭；关闭后临时高亮保留至离开页面。

### 8.3 跳转闪烁动效（全站统一）

面板跳转、分享落地、书签跳转共用：目标高亮/段落底色脉冲 2 次（约 1.2s），`prefers-reduced-motion` 时改为静态描边 2s。

## 9. 译文更新后的定位与重锚

### 9.1 渲染分级

| 定位结果 | 正文呈现 | 面板标记 |
|---|---|---|
| 精确（级别 1–2） | 正常 `<mark>` | 无 |
| 模糊命中（级别 3–4） | 正常 `<mark>` + 弹层小字「译文已更新，按相似文本定位」 | 「已重新定位」淡徽标 |
| 段落级降级（级别 5） | 整段淡色底 + 虚线左缘，不假装精确范围 | 「定位失效」徽标 |
| 段落消失 | 正文不渲染 | 「段落已不存在」，归入失效筛选 |

### 9.2 手动重锚流程

失效摘录弹层/面板条目提供「重新关联」：

1. 进入重锚模式：页面滚动到降级段落，顶部出现提示条「选中与摘录对应的文字」+ 摘录原文对照卡（可折叠）+ [取消]。
2. 用户在正文选中文字 → 提示条变为「关联到这段文字？[确认] [重选]」。
3. 确认 → 更新 `selector`（保留 `revision` 历史与原始 `exact` 于 `selectorHistory`），徽标消除，toast「已重新关联」。
4. 取消 → 原样保留，绝不自动改写（plan §4：原始摘录内容不得被自动覆盖）。

### 9.3 失效摘录管理

- 摘录面板筛选器增加「定位失效」；失效条目仍显示原始摘录全文与创建时版本信息，可复制/导出/删除。
- 译文更新后首次打开阅读器：若产生新的失效摘录，发一条 toast「译文已更新，N 条摘录需要重新定位 · 查看」，点击进面板失效筛选。不弹窗、不阻塞。

## 10. 导入 / 导出 / 备份

### 10.1 JSON 导出（P0）

- 云同步面板「导出 JSON 备份」→ 直接下载 `proust-reader-backup-YYYYMMDD.json`（全量：摘录含软删除标记、书签、进度、设置、schemaVersion）。
- 未连接 OneDrive 时同样可用（入口同时在摘录面板「导出 ▾」菜单）。
- 导出成功 toast；文件内容不含任何 token。

### 10.2 JSON 导入（P0）

```text
[导入 JSON] → 文件选择 → 预览对话框
┌────────────────────────────────────────────┐
│ 备份文件：2026-11-01 · 23 条摘录 · 5 书签  │
│ 与本机合并：新增 12 · 更新 3 · 跳过 8      │
│ 其中 2 条与本机修改时间冲突：              │
│   ○ 以导入文件为准  ● 以本机为准  ○ 都保留 │
│                     [取消]  [导入并合并]   │
└────────────────────────────────────────────┘
```

- 按 `id` 去重；同 `updatedAt` 跳过；冲突策略用户显式选择，默认「以本机为准」。
- 校验失败（非法 JSON / schemaVersion 不支持）→ 明确错误文案，不写入任何数据。
- 导入结果 toast「导入完成：新增 12 · 更新 3」，进入同步队列。

### 10.3 可读摘录集导出（P2）

- 「生成摘录集」对话框：格式（DOCX/Markdown）、范围（全部/当前筛选结果/勾选条目）、选项（含批注 ✓、含永久链接 ✓、按卷分章 ✓）。
- 生成中按钮内联 spinner；完成直接下载。已连接 OneDrive 时附加勾选「同时存到 OneDrive exports/」（plan §3 目录）。
- 导出文件内每条摘录附永久链接（§8），不含凭证。

### 10.4 备份提醒

- 已连接且距上次 JSON 导出 > 30 天：云同步面板「上次备份」行变为提醒色 + 「立即备份」；不发全局弹窗（plan §7：目录内数据仍可能被恶意删改，独立备份不可省略——用低打扰的常驻提醒落实）。

## 11. 离线、错误与降级

| 场景 | 行为 |
|---|---|
| 断网阅读/摘录 | 一切照常；☁︎ 变离线态；变更积压入队 |
| 网络恢复 | `online` 事件自动同步；成功无 toast（状态图标变化即可），失败/冲突才 toast |
| IndexedDB 不可用（隐私模式等） | 沿用现有 localStorage 降级路径；面板顶部常驻小字「当前浏览器无法持久保存，请及时导出」+ 导出按钮 |
| 同步请求失败（非 401/网络） | 指数退避重试 ≤3 次；仍失败 → 错误态 + 手动重试；本地数据永不丢失 |
| 401/续期失败 | 「需要重新登录」横幅（§5.3），不弹全局窗 |
| OneDrive 目录被外部删改 | 同步发现文件缺失 → 以本地为准重建上传；发现未知文件 → 不读取不删除，仅在面板提示「云端目录存在本应用之外的文件」 |

## 12. 无障碍与键盘

- 所有新弹层/面板：`role="dialog"` + `aria-label`，Esc 关闭并归还焦点（沿用 `ReaderAnnotations` 模式）。
- 工具条色块：`aria-label="黄色高亮"` 等，选中态 `aria-pressed`。
- 高亮 `<mark>`：`tabindex="0"`，键盘 Enter 打开弹层；`aria-label` 含「摘录，有批注」摘要。
- 冲突卡片两版本用标题区分，按钮文案自解释（「保留本机版本」）。
- 动效遵循 `prefers-reduced-motion`（§8.3）。
- 触屏目标 ≥ 44×44px；底部动作栏避开 iOS 安全区（`env(safe-area-inset-bottom)`）。

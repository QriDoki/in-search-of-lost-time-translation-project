## 已有术语审查（本章语境复核）

- `Cambremer` / `Mme de Cambremer` / `marquis de Cambremer`：沿用「康布雷梅尔」。本章新增「康布雷梅尔-勒格朗丹夫人」（儿媳）与「康布雷梅尔侯爵太夫人」（婆婆，douairière）两条，三人在同一场戏同时在场，绝不可混称；旧译「康布尔梅」仍禁用。
- `lift` / `liftier`：沿用「电梯」／「开电梯的」；`liftier` 的 note 补写「第004章全章即指此人」，并明确不作「电梯工」。`chasseur` 仍作「侍应生」，`sommelier` 作「酒务总管」，`maître d'hôtel`（酒店）作「领班」。
- `premier président`：沿用「首席院长」；本章他与康布雷梅尔家、与叙述者的关系是喜剧材料，不作「首席庭长」。
- `Casino`：沿用「娱乐场」；本章的 Incarville 小娱乐场亦然，不作「赌场」。
- `princesse de Luxembourg`（vol4 的酒店闲话人物）与本章 `duchesse de Luxembourg`（夏吕斯的姻亲）**不合并**：原文称谓不同，按原文分别译；belle-sœur 未指明是嫂、弟媳或姑姨，译「姻亲」，不擅自补足亲属关系。
- `Balbec-Plage`：沿用「巴尔贝克海滩」；本章小火车终点站语境，与内陆的巴尔贝克镇区分。
- `nectar`：原 note 只含植物义「花蜜」；本章「酒是真正的 nectar」为「琼浆玉液」，note 已补两义并存，按句意择一。
- `cure`：原 note 只含医学义「疗法」；本章 `cure de Criquetot` 为「本堂区」，note 已补第二义。
- `gomorrhéen`：本章作定语（caractère gomorrhéen），note 补「作定语时译『蛾摩拉式的』」。
- `Verdurin` / `Mme Verdurin` / `Patronne` / `fidèles` / `mercredi`：本章维尔迪兰家的「星期三」是社交机制的核心名词，新增 `mercredi` 条作「星期三聚会」，与既有的「老板娘」「信徒」配套。
- `Elstir` / `Cottard` / `du Boulbon` / `Andrée` / `Rosemonde` / `Gisèle` / `Bloch` / `Nissim Bernard` / `Morel` / `Charlus` / `Saint-Loup` / `Jupien`：全部沿用既有译名，无改动。
- `Sodome` / `Gomorrhe` / `saphisme`：「蛾摩拉」「索多玛」沿用；新增 `saphisme`＝「萨福主义」，保留时代语汇。

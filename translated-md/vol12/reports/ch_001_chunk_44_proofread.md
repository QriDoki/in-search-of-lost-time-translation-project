# Chunk 44 校对报告 (第 001 章)

## 术语审查
- `Brichot` → 布里肖：初译作「布里肖」，正确，未改（禁用「布里绍」）。
- `Verdurin` / `Charlus` / `Morel` / `Ski` / `Albertine` / `Dostoïewski` / `Mme de Cambremer` → 维尔迪兰／夏吕斯／莫雷尔／斯基／阿尔贝蒂娜／陀思妥耶夫斯基／康布雷梅尔夫人：均与术语表一致，未改。
- `reine de Naples` → 那不勒斯王后；`impératrice Élisabeth` → 伊丽莎白皇后：均按术语表，未混同「公主」或「亲王夫人」。
- `archange Gabriel` → 天使长加百列；`archange Raphaël` → 天使长拉斐尔：与建筑师加布里埃尔、画家拉斐尔分列，未混。`Tobie` → 多俾亚；`Daniel` → 但以理；`Bethsaïda` → 贝特赛达；`Gaète` → 加埃塔；`Esther` → 《以斯帖》；`Andromaque` → 《安德洛玛克》：全部照 note 落笔。
- `les êtres sympathiques`：初译「值得同情的人」有歧义（易读成「令人怜悯的人」），改为「她心目中的可亲之人」，与下文陀思妥耶夫斯基小说中「谄媚的寄生虫」形成对照。建议上游不必入 glossary，属语境处理。
- `piscine probatique de Bethsaïda`：初译「贝特赛达那能治病的水池」准确，保留。
- `métastase`：初译「转移（症）」；终稿统一作「转移」，后文「不该到转移里去找解释」与「一次身体上的转移」前后一致，删去括注以免打断文气。

## 初译稿典型错误
- **句法直搬**：「远远超过盖尔芒特家的夫人们或康布雷梅尔夫人所能做、所做的一切」中「所能做、所做」并列生硬，改为「平生所能做、所做的一切」，主语补「平生」使比较落到实处。
- **冒号句断裂**：「然而终究必须承认，在她心里，值得同情的人完全不是……的样子」中「在她心里」冗赘且句子过长，改为「然而终究必须承认：她心目中的可亲之人，完全不是……的模样——」，以破折号领出同位列举，层次更清。
- **名词化与「的」字堆叠**：「德行四周环绕着许多恶习的人」为逐字直译，改为「德行被许多恶习团团围住的人」，恢复原文 «la vertu s'entourait de beaucoup de vices» 的主动意象。
- **书面腔**：「为温柔的话语、福音书的比喻和对死亡的一种表面顺从所点缀」是典型「为……所」被动长句，改为「点缀其间的，是温柔的话语、福音书的比喻，以及一种表面上的顺从死亡」。
- **指代含混**：末句「被更切近的愤怒挡着，无法重新浮现」中「更切近」与「回忆」搭配不当，且原句 «que des colères plus immédiates empêchèrent de se raviver» 主语为「回忆」、施动为「愤怒」，改为「被更迫近的愤怒挡着」，主语承前明确。
- **时态层次**：「此后不久」前加「此后」替代初译「后来」，与 «à quelque temps de là» 的「稍后」义相符；「已到弥留之际」替代「判为……濒临死亡」，避免「判为濒临死亡」的搭配不顺。
- **重复用词**：初译两处「濒临死亡／半死不活」，终稿分别作「已到弥留之际」「已处于半死状态」，保持原文 «à deux doigts de la mort» 与 «à demi mourant» 的强度差别。

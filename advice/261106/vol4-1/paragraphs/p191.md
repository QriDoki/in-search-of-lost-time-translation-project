# vol4-1 P191 逐句审校

- 法语原文行号 `raw-md/vol4/chapters/001.md:385`
- dev 底稿行号 `polish/dev/chapters/polished-vol4-1.md:385`

本段是叙述者对外祖母的回应，承接她希望他懂事、快活的安慰，紧接着把假设离开几天与“数小时”相对照。已按句首、句尾和上下文核实法中对应准确；本段只有一个句子。

1. **Je saurais être raisonnable si tu partais pour quelques jours, mais je compterais les heures.** 对应「你要是走几天，我还能懂事，可我会一小时一小时地数。」。分意群核对：
   - **Je saurais être raisonnable**：saurais 为条件式，表示假设情形下“我能做到/我会表现得”；raisonnable 在此是克制、懂事，译作「懂事」符合外祖母与外孙的亲密语境。「还能懂事」用「还」承接后面的转折，语气自然；没有把合理判断误解成“理性思考”。
   - **si tu partais pour quelques jours**：partais 是假设条件，指外祖母若离开几天；「你要是走几天」保留假设和时长，中文口语自然。这里“走”按上下文理解为离开一段时间，不会误作步行。
   - **mais je compterais les heures**：compterais 与 saurais 呼应，仍是条件式；「可我会……」保留转折和假设结果。译文「一小时一小时地数」传达了逐小时数时间、盼望她回来的意思，但省略「数」的对象，中文读者可能短暂疑惑是在数什么；补出「时间」会更完整顺口。建议改为「可我会一小时一小时地数着时间」，不补原文没有明说的“等你回来”。

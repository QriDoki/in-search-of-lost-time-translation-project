# Chunk 07 校对报告 (第 001 章)

## 术语审查

- `Herbinger` → 埃尔班热：初译照术语表，正确。原文 `celui qui est chez un coulissier` 意为「在一位场外证券经纪人那里做事的人」，初译作「那个在场外证券经纪人手下做事的人」，与原文相符；术语表 `coulissier` 条已收「场外证券经纪人」，建议再补一条短语注，说明此处是奥黛特用埃尔班热的职业背景替他贴金。
- `marquise de Villeparisis` → 维尔巴里西斯侯爵夫人：正确，符合禁令（非「亲王夫人」）。
- `pschutt` → 「有派头」：照术语表，保留引号。初译语气成立，未替换。
- `Mme Cottard` → 戈达尔夫人：正确。
- `cocotte` → 交际花：末句「交际花的鉴赏趣味」沿用其名词义，符合术语表。
- `respect humain` → 「怕人议论」：初译处理得当，保留，未按字面「人类的尊敬」误译。
- `dilettantisme` → 「赏玩趣味」：此处指交际花式的审美玩赏，非哲学术语「涉猎主义」。初译作「赏玩趣味」，本稿改为「鉴赏趣味」，以与小市民的「怕人议论」构成更清晰的雅俗对照；建议 glossary 不必单列此词。
- `avenue de l'Impératrice` → 皇后大道；`Hippodrome` → 竞技场；`Éden Théâtre` → 伊甸剧场；`cartes de pesage` → 赛马场过磅处的入场券：均按 L2 报告处理，本 chunk 术语表未收，建议上游补入 glossary 统一（尤其 `Hippodrome` 存在「跑马场」异译风险）。
- `petit hôtel` → 小住宅：末段「她那座小住宅」，符合术语表。
- `quai d'Orléans` → 奥尔良码头：两处均正确。
- `Louis XVI` → 路易十六式：正确。
- `château de Blois` → 布卢瓦城堡：正确。
- `bibeloter` → 「淘古董」：正确，且与「旧货」「旧时候的东西」形成奥黛特式的同义反复，保留。

## 初译稿典型错误

- **引号层级**：初译把奥黛特转述自己的一句话「我进过埃尔班热家」用作内层引号，与原文 `afin de pouvoir dire qu'on était chez Herbinger`（间接引语，无引号）不符；已改为间接引语「能说上一句自己进过埃尔班热家」，同时保留叙述者转述时那种半是模仿、半是讥诮的语调。全 chunk 对话均以「——」起行、外层不加引号，符合硬约束。
- **人物指代误置**：末段原文 `comme il avait critiqué que l'amie d'Odette donnât non pas dans le Louis XVI... mais dans le faux ancien`，初译「他刚才批评奥黛特的女友走的路子……」中「他」指斯万无误，但初译紧接的引语前用「她便对他说」，主语跳转略生硬；已补「因为斯万之前批评过……」使因果链清楚，并把 `faux ancien` 定为「仿古的假货」而非「假古董」（后者易与「赝品」混淆，原文指仿古风格的装修）。
- **长句切分过碎**：第一段 `il arrive en effet souvent pour de plus grands que n'était Swann...` 初译拆成数个并列短句，削弱了「不是钦佩思想、而是敬重善心」的对照重量；已重组为单句，以「并不是……而是……」承载原文的让步与转折。
- **比喻落地过实**：`le chic est une émanation de quelques personnes...` 初译「时髦是少数几个人的散发物」过于生硬；改为「时髦是从为数不多的几个人身上散发出来的」，保留「散发—投射—距离衰减」的物理隐喻链。
- **口语语气偏书面**：奥黛特台词中 `parbleu`、`tu sais`、`mais si`、`Au fond j'aime autant`、`la gloriole` 等，初译多处译得过于整饬；已改为「还用问」「你知道的」「当然啦」「说到底，我倒也乐得没去」「我就好这点虚荣」等口语，恢复她自得又心虚的声口。
- **「的」字堆叠**：第一段与末段各有三处以上「的」连缀的名词短语，已通过改动词结构、拆分子句化解。
- **数字与中文间距**：本 chunk 无阿拉伯数字，无需处理；已确认全文零反引号、无图片、无脚注、段落数与原文一致（10 段）。

## 对后续章节的建议

- `Hippodrome` 在奥黛特口中是「星期五的去处」，译为「竞技场」易与古罗马竞技场混淆，建议 glossary 统一为「跑马场」或加注「巴黎跑马场」；本 chunk 依 L2 与简报暂作「竞技场」，请上游裁定。
- 奥黛特列举时髦去处的四个专名（皇后大道、天鹅湖/湖、伊甸剧场、竞技场）是同一段排比，后续若再出现，应保持「星期天上午—五点钟—星期四—星期五」的节奏与译名一致。
- `faux ancien` 与 `Louis XVI` 构成一组风格对立，建议 glossary 收录「仿古的假货 / 路易十六式」这一对，避免后续译作「假古董」「老式样」等漂移。
- 叙述者转述奥黛特话语时惯用「她说……」「她说过……」，与直接引语「——」交替；建议后续 chunk 保持这一层次，不要把她的话一律并入叙述句。

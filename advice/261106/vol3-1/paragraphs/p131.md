# vol3-1 P131 逐句审校

- 法语原文行号 `raw-md/vol3/chapters/001.md:263`
- dev 底稿行号 `polish/dev/chapters/polished-vol3-1.md:264`

法文基线 `raw-md/vol3/chapters/001.md:263`，dev 译文基线 `polish/dev/chapters/polished-vol3-1.md:264`。本段无译注。

1. **« Les amies de Gilberte n'étaient pas toutes plongées dans cet état d'ivresse où une décision est impossible. »** 现译“希尔贝特的女友们并不都沉在这种让人无从下决心的陶醉状态里”。“并不都”准确保留部分否定，“女友们”在受邀来吃茶点的语境里指女性朋友，可保留。前段叙述者连自己喝下的是茶都无暇辨认，`ivresse` 在这里是这种忘乎所以的陶醉。拒茶只是一个极小的日常决定，译作“下决心”容易使事情显得需要意志或勇气。改为“希尔贝特的女友们并非个个都陷在那种连个决定都做不了的陶醉里。”
2. **« Certaines refusaient du thé ! »** 现译“有几个竟拒绝喝茶！” `Certaines` 回指女友中的一部分，`refusaient du thé` 指有人谢绝了茶。“有几个”和“竟”分别保留部分指称及感叹号所传达的惊讶，“拒绝喝茶”也保留了她们主动谢绝的意思。全句保留。
3. **« Alors Gilberte disait, phrase très répandue à cette époque » / « Décidément, je n'ai pas de succès avec mon thé ! »** 现译“于是希尔贝特便说那句当时极流行的话”及“说来说去，我这茶就是不受欢迎！” `Alors` 承接有人谢绝，`phrase très répandue` 是叙述者插进来的时代观察，现译可保留。`Décidément` 是从眼前反应作出带点无奈的判断，“说来说去”平添了反复谈论的过程。“不受欢迎”大意对，结合上句把语气收在“不怎么受欢迎”。改为“看来我这茶还真不怎么受欢迎！”
4. **« Et pour effacer davantage l'idée de cérémonie, dérangeant l'ordre des chaises autour de la table » / « Nous avons l'air d'une noce ; mon Dieu que les domestiques sont bêtes. »** 现译“为了更进一步抹去仪式的意味，她还把桌边椅子的次序弄乱”及“我们这样子像在办婚礼；天哪，这些仆人真笨。” `davantage` 说的是继续冲淡茶点聚会的郑重气氛，`dérangeant` 则让挪椅子与说话同时发生。`l'ordre` 在此指围桌排好的格局，“次序”容易让人以为她特意调换几把椅子的先后。`une noce` 可指婚宴或参加婚宴的一群人，`nous avons l'air` 是说在座的人看着像婚宴上的一桌，现译“办婚礼”容易让人理解为这群人在操办婚礼。“天哪，仆人们真笨”可保留对仆人随口抱怨的语气。改为“为了再冲淡一点郑重其事的气氛，她一边挪动桌边排好的椅子，一边说：‘咱们这样子活像在吃喜酒。天哪，仆人们真笨！’”

## dev 稿处理

已应用以下修订。

希尔贝特的女友们并非个个都陷在那种连个决定都做不了的陶醉里。有几个竟拒绝喝茶！于是希尔贝特便说那句当时极流行的话：“看来我这茶还真不怎么受欢迎！”为了再冲淡一点郑重其事的气氛，她一边挪动桌边排好的椅子，一边说：“咱们这样子活像在吃喜酒。天哪，仆人们真笨！”

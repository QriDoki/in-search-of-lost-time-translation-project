# 第 002 章《地名：那个名字》chunk 12 任务简报

## 全书前文（≤300 字）
《追忆似水年华》第二卷《在花季少女倩影下》第一部。叙述者「我」童年在贡布雷，母亲睡前吻、玛德莱娜小蛋糕与椴花茶。本卷上一章《斯万之恋（续）》讲完斯万与奥黛特的恋情：维尔迪兰家「小核心」、凡德伊奏鸣曲的「小乐句」、卡特兰、福什维尔、圣厄韦尔特晚会，终以斯万爱情熄灭。奥黛特后嫁斯万，生女希尔贝特。本章叙述者重新成为主视角。

## 本章前文（≤200 字）
布洛涅树林作为「女人的花园」：金合欢道、斯万夫人的马车、车夫与小跟班、路人的低语；叙述者远远向她脱帽。

## 格式硬约束（逐条遵守；L3 须逐条核对并在报告中记录）
1. 段落一一对应：译文段落数必须与原文（空行分隔）段落数完全一致，不得合并或拆分。原文只有一段的 chunk，译文也只能有一段。
2. 全文零反引号：任何位置都不得出现反引号（`）；初译若出现，L3 必须移除。
3. 引号：外层“”，内层‘’；原文以「-- 」开头的行是对话，译文以「——」开头，不再额外加引号。
4. 斜体：原文星号标记的斜体保留为 Markdown 斜体；斜体内的作品名加书名号（如 *《帕尔马修道院》*）；卷内部次、外来词、拉丁语斜体不加书名号；拉丁语、英语、意大利语原文按原样保留。
5. 不新增脚注、尾注、译注、解释性夹注；删除任何图片、图注、图片占位符。
6. 阿拉伯数字与中文之间保留半角空格（如「12 世纪」「1 小时 22 分」）。
7. 不拆段、不加小标题；不把叙述者的「也许」「似乎」译成断言。

## 文化硬约束（与术语表 note 冲突时以 note 为准）
- princesse de X → X 亲王妃（禁「公主」「亲王夫人」）；prince de Galles → 威尔士亲王；princesse Mathilde → 玛蒂尔德公主。
- houris → 天国仙女；维米尔、德·霍赫；《第九交响曲》《名歌手》；葡萄酒市场（禁「货栈」）；圣心会女子寄宿学校；粉红版《辩论报》（本章的 Débats 作《辩论报》）。
- 禁用译名：史万（应为斯万）、黛奥特（应为奥黛特）、虐待狂（应为施虐狂）、亲王夫人。
- 人物译名与第一卷、本章前文一致：斯万、奥黛特、希尔贝特、希尔贝特·斯万、斯万夫人、斯万先生、弗朗索瓦丝、莱奥妮姑妈、贝戈特、贝尔玛、勒格朗丹、布拉坦夫人、拉辛、司汤达。
- 地名：巴尔贝克、威尼斯、佛罗伦萨、帕尔马、比萨、香榭丽舍、布洛涅树林、金合欢道、玛格丽特王后道、大湖、射鸽场、太子门、特里亚农。
- 本章主题词「名字」（le nom）：地名之名的魔力；不要把它译成「名称」「名词」。

## 语言质量要求
- 普鲁斯特的长句保留思想层次与绵延感，不切成均齐短句；避免翻译腔与四字成语堆砌。
- 保留回忆的双重时间（少年之「我」与多年后叙述之「我」）；自由间接引语不加引号、不补「他想」。
- 反讽、自欺与迟疑保留分寸：不把「也许」译成断言，不把讥讽加强成斥责。
- 不添加原文没有的抒情、典故、解释；不弱化原文的俗语与物质细节。

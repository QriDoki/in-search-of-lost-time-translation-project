# vol4-1 P093 逐句审校

- 法语原文行号 `raw-md/vol4/chapters/001.md:189`
- dev 底稿行号 `polish/dev/chapters/polished-vol4-1.md:189`

本段承接 P092 律师公会会长「请朋友吃顿午饭有什么派头」的自谦，说话人反驳说确有派头，并点出在座的是康布雷梅尔夫妇、那位侯爵夫人的爵位出自男系。已按本段首尾句与前后段（raw-md 及 dev 的 187/191 行）核实法中对应无误，行号符合 P028–P270 公式 2N+3=189。

1. **Mais si, c'est chic !** 对应「——当然有派头！」。"Mais si" 是对否定性反问（P092「这有什么派头？」）的反驳式肯定，「当然有」准确传达「才不是没有、确实有」的语气；chic 译「有派头」与 P092「有派头？为什么？」「这有什么派头」用词一致。保留。
2. **C'était bien les de Cambremer, n'est-ce pas ?** 对应「那确实是康布雷梅尔家的人吧？」。未完成过去时 c'était 指刚才见到的客人，「那」承接自然；bien 的确认语气译「确实」；les de Cambremer 为复数（康布雷梅尔夫妇/一家），「康布雷梅尔家的人」涵盖复数且沿用既有译名康布雷梅尔；n'est-ce pas 译「吧？」保留征询口吻，与「确实」连用恰再现原文「确认＋反问」的语气。保留。
3. **Je les ai bien reconnus.** 对应「我认出来了。」。les 指康布雷梅尔一家，中文承前省略宾语自然；bien 为强调副词（「认得清清楚楚」），此处未单独译出，但其确认语气已由上句「确实」及整段反驳口吻承接，「我认出来了」达意且不生硬，不必增字。保留。
4. **C'est une marquise.** 对应「那是一位侯爵夫人。」。marquise 为侯爵夫人（marquis 侯爵之阴性/配偶称谓），译名准确；c'est 译「那是」指代在座那位女宾，与上下文一致。保留。
5. **Et authentique.** 对应「而且货真价实。」。authentique 意为「真正的、货真价实的」，以「货真价实」这一略带市井调侃的成语形容贵族身份之「真」，贴合说话人炫耀、品评的口吻；独立成句对应原文省略句 Et authentique。保留。
6. **Pas par les femmes.** 对应「⊂不是从女系承袭的⊃≼🏛️原文 Pas par les femmes，指爵位与姓氏出自男系；这是当时贵族圈判定血统“正统”的偏见，而非制度规定。≽。」。par les femmes 在爵位/血统语境指「经女系（母系）传承」，「不是从女系承袭的」准确；原文为省略句，补「承袭」使中文完整自然，属合理显化。锚点 ⊂不是从女系承袭的⊃ 与注释 ≼…≽ 紧跟同行、结构完好；注释对男系传承及贵族圈偏见的解释与正文一致、未见错误。保留。

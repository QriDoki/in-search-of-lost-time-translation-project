| Mme Swann | 斯万夫人 | 即奥黛特；本章她在布洛涅树林散步，路人低语其旧名 Odette de Crécy。叙述者只称斯万夫人，不点破。 |
| salon | 沙龙；客厅 | 第003章；前者指社交圈，后者指房间，按语境判断。 |
| Odette | 奥黛特 | 与德·克雷西夫人、斯万夫人是同一人；黛奥特为转录中的疑误写法，不采纳。本章为背景人物。 禁用译法: 黛奥特 |
| chrysanthème | 菊花 | 奥黛特冬日沙龙里的主要花卉；本章末段叙述者追想斯万夫人客厅里「十一月暮色中菊花的橙红火光」，是旧日优雅的标记。首现第1章。 |
| Swann | 斯万 | 核心人物姓氏（Charles Swann，夏尔·斯万）。首次出现于第 0 章（书名及题献页）。贯穿全书的重要角色，巴黎上流社会艺术品鉴赏家。 需要称谓时用斯万先生；不擅加源文未出现的名字。 禁用译法: 史万 原文别名: M. Swann |
| cocotte | 交际花 | 贬义，家人对斯万妻子的评价（presque une cocotte）。首现第1章。 |
| jour de l'an | 元旦 | 第003章；新年第一天。 |
| samovar | 茶炊 | 俄式烧水器，当时刚传入巴黎，使沙龙带上琥珀色雾气。 |
| violettes de Parme | 帕尔马紫罗兰 | 奥黛特扶手椅旁水晶钵中常备之花；帕尔马为意大利产地名。 |
| Gilberte | 希尔贝特 | 斯万与奥黛特之女；本章香榭丽舍游戏的中心人物，叙述者少年之恋的对象。全名 Gilberte Swann→希尔贝特·斯万。禁用译法沿用全书。 |
| Henry Gréville | 亨利·格雷维尔 | 十九世纪末女小说家（本名 Alice Durand）；其小说中的女主角装束成为叙述者对旧式沙龙的联想。 |
| Lespinasse | 莱斯皮纳斯 | 莱斯皮纳斯小姐（Mlle de Lespinasse），十八世纪著名沙龙女主人；奥黛特自以为在办一个更自由的沙龙。 |

| Mme Verdurin | 维尔迪兰夫人 | 与其丈夫分开建角色；不把她的判断直接当作叙述事实。 禁用译法: 韦尔迪兰夫人、维乐迪兰夫人 原文别名: Madame Verdurin |

| du Deffant | 迪德方 | 迪德方侯爵夫人（Mme du Deffant），十八世纪著名沙龙女主人；原文「la du Deffant du petit groupe」指维尔迪兰夫人，带贵族姓氏的冠词用法。 |

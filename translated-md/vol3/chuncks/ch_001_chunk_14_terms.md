| Bergotte | 贝戈特 | 作家，叙述者的文学偶像；本章（vol3 第 1 章）首次实际登场，在斯万家谈论贝尔玛与《费德尔》，并评点叙述者的习作。其谈吐与文体不同，译时保留这一落差。 |
| Norpois | 诺尔普瓦 | 德·诺尔普瓦侯爵（marquis de Norpois），前驻外使节、驻埃及财政监督，法兰西道德与政治科学院院士；说话用旧式外交辞令。带爵位时作「诺尔普瓦侯爵」。禁用译法: 诺尔普瓦兹、诺普瓦。 |
| Swann | 斯万 | 核心人物姓氏（Charles Swann，夏尔·斯万）。首次出现于第 0 章（书名及题献页）。贯穿全书的重要角色，巴黎上流社会艺术品鉴赏家。 需要称谓时用斯万先生；不擅加源文未出现的名字。 禁用译法: 史万 原文别名: M. Swann |
| Art pour l'Art | 为艺术而艺术 | 十九世纪文学口号（l’Art pour l’Art）；诺尔普瓦反讽地称之为「神圣学派」。 |
| Cachet rouge | 《红色印章》 | 维尼的短篇小说（Le Cachet rouge）；诺尔普瓦称其中有可入选文选的篇章。 |
| Champs-Élysées | 香榭丽舍 | 本章主场景之一：叙述者与希尔贝特在此玩抢垒、打羽毛球；斯万夫妇住所亦在近旁街区。 |
| Cinq-Mars | 《森-马尔斯》 | 维尼的历史小说；诺尔普瓦贬贝戈特时举以为证。 |
| Combray | 贡布雷 | 叙述者童年度假小镇、全书核心场景（原型伊利耶 Illiers）。译林版（上游指示）。首现第1章。 |
| Loménie | 洛梅尼 | 路易·德·洛梅尼，十九世纪文人，著有《卢梭》等；与圣伯夫并称，此处记不清是谁写的掌故。 |
| Metternich | 梅特涅 | 梅特涅亲王妃（princesse de Metternich），奥地利驻法大使夫人；princesse 作「亲王妃」。 |
| Mlle Swann | 斯万小姐 | 即希尔贝特（Gilberte） |
| Mme Swann | 斯万夫人 | 即奥黛特；本章她在布洛涅树林散步，路人低语其旧名 Odette de Crécy。叙述者只称斯万夫人，不点破。 |
| Sainte-Beuve | 圣伯夫 | 圣伯夫，法国批评家；诺尔普瓦引其与洛梅尼的掌故，普鲁斯特全书对其方法持批判态度。 |
| Vigny | 维尼 | 阿尔弗雷德·德·维尼，《诗人日记》作者。首现第1章。 |
| chinoiseries | 东方小玩意儿 | 原义「中国玩意儿」，转指繁缛纤巧的雕琢；诺尔普瓦贬贝戈特的文体。 |
| diseur de phébus | 故作艰涩的饶舌者 | phébus 指繁复晦涩的文句；诺尔普瓦引父辈的说法讥贝戈特。 |
| double | 副本 | 叙述者想象中先于现实存在的「副本」（le «double»）：贝戈特笔下的香榭丽舍先在他心里放了副本，他才想去看真的。不作「替身」。 |
| ennuyeux | 讨厌家伙 | 第003章；圈内排斥标签，不是叙述者的客观判断。 |
| salon | 沙龙；客厅 | 第003章；前者指社交圈，后者指房间，按语境判断。 |

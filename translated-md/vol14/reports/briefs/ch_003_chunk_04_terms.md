| matinée | 午后聚会 | 第003章 4 处均指亲王妃家的白天招待会；章题与正文统一「午后聚会」。与 goûter（下午茶会，规模更小）区分。禁用「早晨」「日场」（日场义见 vol11 条）。 |
| \* \* \* | * * * | 本章有**一处**原书分节符（P17），译文作 `* * *`，单独成段、前后空行，不得删除或改成横线。 |
| M. de Charlus | 夏吕斯先生 | 源文 12 处。严格随源文形式：M. de Charlus→「夏吕斯先生」；le baron／du baron（17 处）→「夏吕斯男爵」；裸形 Charlus→「夏吕斯」。禁用「夏吕斯男爵先生」。本章他已中风初愈：白发白须、言语含混、动作失调，而智力完好。 |
| Mme de Guermantes | 盖尔芒特公爵夫人 | 本章仅 1 处（赴亲王妃家的语境中回想「公爵夫人家的午后聚会」）。照源文作「盖尔芒特公爵夫人」；不得改写成「亲王妃」，严禁回改为「盖尔芒特夫人」。 |
| duchesse de Guermantes | 盖尔芒特公爵夫人 | 本章 1 处：她属于会在夏吕斯失口说出亲德言论时打断他、替他圆场的人。禁令同上。 |
| princesse de Guermantes | 盖尔芒特亲王妃 | 本章午后聚会的女主人，与亲王同住 avenue du Bois 新宅。princesse de X 一律「X 亲王妃」；禁用「公主」「亲王夫人」。与公爵夫人严格区分。 |
| Jupien | 朱皮安 | 裁缝兼旅店经管人。本章他寸步不离照料病后的夏吕斯，扶他下车、替他通报来人，像看护孩子；并向叙述者讲述夏吕斯失明期间仍设法寻人、以及疗养院里的丑事。禁用「朱皮耶」「儒皮安」「朱比安」。 |
| Lord X | X 勋爵 | 匿名指某位英国勋爵。保留字母 X，不得代拟真名、不加译注、不作「某勋爵」「X 爵士」。 |
| prince de X | X 亲王 | 与 Lord X 并提的匿名亲王。保留字母 X。与「盖尔芒特亲王」无关。 |
| Guermantes | 盖尔芒特 | 家族名与地名。本章：请帖上这个名字重新唤起贡布雷的空气、鸟街与彩窗的旧魔力，随后又因亲王迁居而失效。le côté de Guermantes（散步路线）作「盖尔芒特家那边」；les Guermantes 作「盖尔芒特一家」。 |
| Venise | 威尼斯 | 本章：想从记忆里另取「在威尼斯拍的快照」，但一提这个词就觉得像看摄影展一样乏味。 |
| Bergotte | 贝戈特 | 作家，叙述者的文学偶像。本章：引其语「您有病，但不必为您难过，因为您有精神的快乐」——叙述者随即指出他看错了自己。 |
| instantané | 快照 | 记忆的「快照」（instantanés），源文加引号，译文保留引号。不作「瞬间」「剪影」。 |
| germanophilie | 亲德 | 夏吕斯病中精神抑郁，会把平日隐藏的政见大声说出，亲德即其一；战后他为德国战败哀叹，并说「我们」。必须保留「我们」（他把自己算在德国人里），不加解释。 |
| les joies de l'esprit | 「精神的快乐」 | 贝戈特语。esprit 此处指心智／精神，**不作「机智」**；保留引号。 |
| intelligence | 智力 | `son intelligence n'était pas atteinte` 作「他的智力并未受损」。 |
| esprit | 机智／心智 | 沙龙式的急智义作「机智」；本章 `netteté d'esprit` 作「头脑清楚」，`joies de l'esprit` 作「精神的快乐」。按语境，不一律「机智」。 |
| Destin | 命运 | 首字母大写，拟人化的「命运」（`le Destin, m'eût-il accordé cent ans de vie de plus`）。不加引号，不作「天命」「宿命之神」；不带神学色彩，与「天主」「天意」区分。 |

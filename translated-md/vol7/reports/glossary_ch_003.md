## 已有术语审查

- `Mémé`：**修订**。旧注称「斯万对夏吕斯男爵的亲昵绰号」，与本章原文不符——本章明写盖尔芒特公爵夫人称他 « ce Mémé »，且说男爵本人不喜欢这个家族小名。已改为「夏吕斯在家族内的亲昵小名，公爵夫人这样称呼他」，并保留「斯万」旧说的更正说明。译名仍作「梅梅」。
- `Moïse`：**修订**。旧注只记《圣经》先知（巴尔贝克门廊的金牛犊）。本章另指鲁弗斯·伊斯拉埃尔夫人的侄子，本名摩西、社交界称「莫莫」，与先知同名不同人。已补注，避免 L2/L3 把「莫莫」误作先知的绰号。
- `entremetteuse`：**补注**。旧译「淫媒」在斯万骂人的语境正确；本章 « les bons offices de l'entremetteuse » 是转义（女主人为宾客牵线），补注「该处译牵线／撮合，不照搬淫媒」。
- `Vénus`：**补注**。旧注只作「厨房＝维纳斯小庙」；本章作行星（金星，与仙后座并举），补「按语境择义」。
- `Matin à Doncières`：**补注**。原注标为第 002 章，本章再次出现（唐西埃尔的晨雾印象），补注同指关系。
- `grand'mère` → 「外祖母」、`petite bande` → 「小团体」、`petit noyau` → 「小核心」、`petit clan` → 「小宗派」、`petit groupe` → 「小集团」、`Stermaria` → 「斯泰尔马里亚」、`Simonet` → 「西蒙内」、`Bontemps` → 「博纳唐」、`Villeparisis` → 「维尔巴里西斯」、`Charlus` → 「夏吕斯」、`Palamède` → 「帕拉梅德」、`princesse de Parme` → 「帕尔马亲王妃」、`princesse de Ligne` → 「利涅亲王妃」：在本章语境中均准确，无需修改。
- `calorifère`／`chauffage central`、`verres de Venise`、`passementerie`：承接第 002 章的用法在本章开头复现（暖气、窗纱、白昼的饰带），沿用原译。

## 术语表之外的校对期定稿（已同步进 glossary.json，供后续卷沿用）

- `esprit des Guermantes`：章目提要原拟「盖尔芒特家的精神」，校对后改为**「盖尔芒特家的机智」**，与 vol3 已用的译法一致；已同步本章标题行。
- `entremetteuse` 在本章的转义落定为「经人撮合」；`figurante / doublure` 分作「哑角」「替身」。
- `bon pour un baiser` → **「吻券」**（票据隐喻，后文「您这些券」「再给您开几张」保持一致）；未单独立条，作为本章临时约定记此。
- `Justice éclairant le Crime` → **「照亮罪行的正义」**（寓意画，不加书名号、不加译注）。
- `quarantaine`（本章）→ **「隔离处境」**，与数字「四十」无关。
- 人名更正：`Norpois` 统一「诺尔普瓦」（初译一处误作「诺布瓦」，已改）；公爵夫人自称圣卢的 `tante` 作**「舅母」**，与第 002 章「他被舅父拉走了」（son oncle）的称谓体系一致；`belle-sœur / beau-frère` 作「嫂子／小叔子」。

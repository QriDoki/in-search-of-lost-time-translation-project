| M. de Charlus | 夏吕斯先生 | 源文 12 处。严格随源文形式：M. de Charlus→「夏吕斯先生」；le baron／du baron（17 处）→「夏吕斯男爵」；裸形 Charlus→「夏吕斯」。禁用「夏吕斯男爵先生」。本章他已中风初愈：白发白须、言语含混、动作失调，而智力完好。 |
| le baron | 夏吕斯男爵 | 本章 le baron／du baron 共 17 处，专指夏吕斯；首次提及后同段可简称「男爵」。不得与「M. de Charlus」互换。禁用「男爵先生」。 |
| prince de Guermantes | 盖尔芒特亲王 | 公爵的堂弟吉尔贝；已迁出旧府、在 avenue du Bois 新建府邸，聚会即在其家举行。禁用「亲王殿下」（源文无 Monseigneur）、「盖尔芒特亲王先生」。 |
| Mme de Sainte-Euverte | 圣厄韦尔特夫人 | 本章核心反讽所在：夏吕斯昔日嫌她「不够时髦」，不肯与她共餐；中风后却在马车里竭力脱帽、深深行礼，「像对待法兰西王后」。译文必须保留「昔日拒绝 ↔ 今日卑恭」的反差，行礼不得写得体面从容，也不得省略他从前看不起她的交代。禁用「圣埃弗尔特夫人」「圣欧韦尔特夫人」「圣厄韦尔特侯爵夫人」。 |
| Sainte-Euverte | 圣厄韦尔特 | 该家族／沙龙名。作「圣厄韦尔特沙龙」。禁用「圣埃弗尔特」「圣欧韦尔特」。 |
| Jupien | 朱皮安 | 裁缝兼旅店经管人。本章他寸步不离照料病后的夏吕斯，扶他下车、替他通报来人，像看护孩子；并向叙述者讲述夏吕斯失明期间仍设法寻人、以及疗养院里的丑事。禁用「朱皮耶」「儒皮安」「朱比安」。 |
| Swann / Charles Swann | 斯万 / 夏尔·斯万 | 本章仅见于夏吕斯所念亡友名单 `Charles Swann, mort !`，作「夏尔·斯万，死了！」。禁用「史万」「查理·斯万」。 |
| Hannibal de Bréauté | 阿尼巴尔·德·布雷奥泰 | 即布雷奥泰伯爵（全名 Hannibal de Bréauté-Consalvi）。亡友名单只作 Hannibal de Bréauté，照译，不补 Consalvi。禁用「汉尼拔」「布雷奥泰侯爵」。 |
| Antoine de Mouchy | 安托万·德·穆希 | 穆希公爵。亡友名单。禁用「安东尼」「穆希公爵先生」。 |
| Adalbert de Montmorency | 阿达尔贝·德·蒙莫朗西 | 亡友名单。禁用「阿达尔伯特」。 |
| Baron de Talleyrand | 塔列朗男爵 | 塔列朗家族后人，**不是**拿破仑的外交大臣塔列朗本人。源文大写 Baron，作「塔列朗男爵」，不作「塔列朗伯爵」。 |
| Sosthène de Doudeauville | 索斯泰纳·德·杜多维尔 | 杜多维尔公爵家。**不是**「索斯泰纳·德·盖尔芒特」（盖尔芒特家另一人），勿混。禁用「索斯坦」。 |
| mort ! | 死了！ | 亡友名单的固定结句，六次重复（Bréauté／Mouchy／Swann／Montmorency／Talleyrand／Doudeauville）。一律作「死了！」，短促、重复、不加修饰；禁用「去世」「逝世」「亡故」「与世长辞」（会毁掉「一铲土一铲土」的节奏）。 |
| Américaine | 美国女人 | 本章 2 处：亲王新宅里那些美国女人的晚会（与他无干的新富社交）；「最末等的美国女人」。非特指某位人物，不得代拟姓名。禁用「美国女子」「美洲女人」。 |
| Guermantes | 盖尔芒特 | 家族名与地名。本章：请帖上这个名字重新唤起贡布雷的空气、鸟街与彩窗的旧魔力，随后又因亲王迁居而失效。le côté de Guermantes（散步路线）作「盖尔芒特家那边」；les Guermantes 作「盖尔芒特一家」。 |
| Avranches | 阿夫朗什 | 诺曼底古城。本章夏吕斯先说「我第一次见您是在阿夫朗什」，**随即自我更正**为巴尔贝克；两处地名各自照译，改口过程不得省略或合并（这是他记忆仍完好的证据）。禁用「阿夫朗奇」。 |
| Balbec | 巴尔贝克 | 海滨胜地。紧接上条，作「不，我弄错了，是在巴尔贝克」。 |
| Sophocle | 索福克勒斯 | 本章 `tel chœur de Sophocle sur l'orgueil abaissé d'Œdipe` 指《俄狄浦斯王》歌队哀唱其失势。禁用「索福克里斯」。 |
| Œdipe | 俄狄浦斯 | 源文用连字 Œ。作品名作《俄狄浦斯王》。禁用「奥迪普斯」「伊底帕斯」。 |
| Bossuet | 博叙埃 | 17 世纪主教、悼词（oraison funèbre）大家。本章：夏吕斯脱帽行礼的雄辩被比作博叙埃，`avec l'éloquence d'un Bossuet` 作「带着博叙埃般的雄辩」。禁用「波舒哀」「博苏埃」。 |
| oraison funèbre | 悼词 | 天主教葬礼演说体裁。本章 `toute oraison funèbre sur la mort` 泛指一切悼亡演说。不作「祈祷」「祭文」。 |
| affiche | 海报 | 《费德尔》《黑多米诺》的街头海报。作「海报」，不作「告示」「招贴画」。 |
| réclame | 广告 | 夏吕斯说初见叙述者时他正站在一张同款商品的广告前。与 affiche（海报）区分：réclame 指商业广告内容。禁「广告牌」（源文未说牌）。 |
| victoria | 维多利亚式敞篷马车 | 源文 `passa en Victoria` 大写，仍作「乘着一辆维多利亚式敞篷马车经过」。指车，不是人名；禁作「维多利亚」。 |
| pianissimo | 极弱音 | 以音乐术语喻夏吕斯极轻的语声：« mes oreilles s'habituèrent bientôt à ce pianissimo » 作「我的耳朵很快习惯了这种极弱音」。保留音乐语汇，不作「低声细语」（否则失掉后文「乐队指挥」「小波浪」的比喻链）。 |
| snobisme | 附庸风雅 | 本章 3 处，两处对举：夏吕斯向圣厄韦尔特夫人行礼是「全部的附庸风雅」，她受此礼也是「全部的附庸风雅」——两处必须同词。不作「势利」。 |
| intelligence | 智力 | `son intelligence n'était pas atteinte` 作「他的智力并未受损」。 |
| esprit | 机智／心智 | 沙龙式的急智义作「机智」；本章 `netteté d'esprit` 作「头脑清楚」，`joies de l'esprit` 作「精神的快乐」。按语境，不一律「机智」。 |
| attaque | 中风发作 | 本章指夏吕斯那次中风。 |
| paralysie | 瘫痪 | 本章：中风后的瘫痪「转移到了眼睛」，一度全盲，后又复明。 |
| aphasie | 失语症 | 夏吕斯担心自己「要得失语症」，其实只是发音含混。不作「失言症」「无语症」。他说错字后潜意识立即把句子接顺的细节须保留。 |
| incoordination | 动作失调 | 中风后脊髓与脑损伤造成的动作失调，用以解释他行礼幅度过大、动作超出本意。不作「不协调」。 |

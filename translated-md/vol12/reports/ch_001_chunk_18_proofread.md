# Chunk 18 校对报告 (第 001 章)

## 术语审查
- `Charlus` → 夏吕斯（保留，括号外第一次出现处未加「男爵」，与资料袋 note「裸形与各种称谓统一」一致）。
- `Vinteuil` → 凡德伊、`Elstir` → 埃尔斯蒂尔、`sonate` → 奏鸣曲、`septuor` → 七重奏、`andante` → 行板、`Mme de Villeparisis` → 维尔巴里西斯侯爵夫人、`Albertine` → 阿尔贝蒂娜：均与术语表一致，无需改动。
- `dryades` → 树精、`fées` → 仙女、`divinités familières` → 家宅的守护神：三词同属一个神话语域，L2 处理得当，保留。建议上游在 glossary 中补录 `dryades`／`divinités familières`，以便后文（尤其七重奏相关段落）统一。
- `pneumatique` → 快信：保留（二十世纪初巴黎的气压传送信件，中文读者可从句境理解，不必加注）。建议 glossary 补录，注为「巴黎市内气压传送快信」。
- `bain de Jouvence` → 青春泉意象：初译「返老还童的沐浴」在中文里略显直白，改为「唯一能让人返老还童的沐浴」，保留「沐浴」这一原文的身体意象，不音译。

## 初译稿典型错误
- **疑问长句的主干被前置、落点被削弱**：初译作「可是，难道不正是如此吗——在这些元素当中……正是艺术……使它显现出来……？」把 `n'est-ce pas que` 拆成一个独立的设问小句，后面的长串同位语与「正是艺术」被读成答句，疑问语气在句中即已消耗，句末落点变成陈述。已改为：整句一气贯下，「难道不正是艺术，凡德伊的艺术如同埃尔斯蒂尔的艺术，使那难以言传之物显现出来……？」落在原文的 `le fait apparaître` 上，思辨的绵延与句末的问号同时保住。
- **指代重复导致「它」悬空**：初译「那难以言传之物……正是艺术……使它显现出来」，中间隔了七十余字，「它」的所指需回读。已把宾语显化（「使那难以言传之物显现出来」），并把 `extériorisant ... la composition intime de ces mondes que nous appelons les individus` 重排为「把那些我们称之为个体的世界的内部构成，外化为光谱上的种种颜色」，避免初译「让那些我们称为个体的世界，其内部构成外化为……」的欧化倒装。
- **`rafraîchissements` 误作「茶点」**：原文只是「清凉饮料／点心」，且此场合为音乐会幕间；「茶点」在中文里坐实了英式下午茶。改为「冷饮」。
- **`d'une insignifiance extraordinaire` 程度词弱化**：初译「无比微不足道」尚可，但与前文「最微不足道的现实」重复用「微不足道」；后一处改为「格外无足轻重」，保留 `extraordinaire` 的反讽强度而不复词。
- **`quel honneur c'était pour elle` 的插入语层次**：初译「能融入某种如此宏大、将我们联结在一起、而她仿佛曾向它借来那哀婉之声的东西，对她是怎样的一种荣耀」——三重「的」叠加且「某种……的东西」稀释了 `si grand`。改为以破折号插入「它把我们联结在一起，而她仿佛曾向它借来那哀婉的声音」，再以「这对她该是何等的荣耀」收束，句子主干（honneur）回到原位。
- **`la rouerie du coupable` 的反讽**：初译「罪人的狡黠」偏宗教化、偏重；此处指夏吕斯自知有罪的心态，改「带着有罪者的狡黠」，并补「可同时也」以承接上句「无疑……」的双重判断，防止读者把叙述者的两层判断读成递进褒贬。全段未添加原文没有的解释性词语。

## 对后续章节的建议
- 本段（源文单片段）译为一个自然段，段首无破折号，结尾停在 `dont ils pensaient mourir.`，与 chunk 19 衔接处应在「厌倦」之后直接续写，勿重复末句。
- 「内在祖国／失去的祖国」（`cette patrie perdue`）与本章他处的「未知者」是同一思想脉络的两个说法，建议后续 chunk 遇到 `la patrie inconnue` 一类表述时沿用「祖国」而非「故乡」，以保持一致。
- `les fées, les dryades, les divinités familières` 这组三名词的译法（仙女／树精／家宅的守护神）建议固定，后文若再现凡德伊乐句的人格化比喻，直接沿用。
- 「断句」一词在本段末兼取 `ponctuer` 的「加标点」与「打断」二义，是有意的双关，若后续 chunk 复用该比喻，请保留同一处理。

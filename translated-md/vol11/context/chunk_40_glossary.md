# 第001章 chunk 40 术语表（仅列本 chunk 出现的术语）

| EN | ZH | note |
|---|---|---|
| Albertine | 阿尔贝蒂娜 | 人名，统一作「阿尔贝蒂娜」。vol3 仅被提及为博纳唐夫人的侄女；vol4 仍只被提及；vol5 第 001 章正式登场——埃尔斯蒂尔画室介绍相识，与安德蕾、吉赛尔、罗丝蒙德等结成少女小团体，叙述者的爱情由此开始。vol10 第003章：她透露自己与凡德伊小姐及其女友相熟，叙述者据此确认其「恶习」，决定娶她。禁用译法: 艾伯丁、阿尔贝汀 vol11 第001章：巴尔贝克之行后住进叙述者巴黎的公寓（走廊尽头父亲的挂毯小屋），被置于近乎囚禁… |
| Andrée | 安德蕾 | 少女小团体的核心成员之一，阿尔贝蒂娜最亲密的女伴；棕色皮肤、眼睛极亮，第一天跳过老银行家，性格沉稳、乐善好施（富家女），叙述者一度假装追求她以接近阿尔贝蒂娜。首现 vol5 第 001 章。禁用译法: 安德雷、安德里 |
| Balbec | 巴尔贝克 | 诺曼底海滨胜地（原型卡堡）。前三卷只在想象与谈论中出现；vol4 第 1 章叙述者与外祖母真正抵达，住海滨大酒店，教堂在内陆的巴尔贝克镇。首现第1章。[place] |
| Bontemps | 博纳唐 | 博纳唐夫人（Mme Bontemps）为公共工程部部长办公厅主任之妻、阿尔贝蒂娜的姑母，斯万家的常客；译名用「博纳唐」，禁用「邦唐」「邦当」。[person] |
| chauffeur | 司机 | 叙述者雇用的私人司机，原文亦以 mécanicien 称之；第001章频繁出现（接送阿尔贝蒂娜、凡尔赛之行）。不作「车夫」。禁用译法: 车夫 |

| Morel | 莫雷尔 | 阿道夫叔公旧日贴身男仆之子夏尔·莫雷尔；巴黎音乐学院一等奖，后成小提琴手，野心勃勃。禁用译法: 莫雷耳 |
| mécanicien | 司机 | 原文对 chauffeur 的另一称呼，同指一人；不译「机械师」「修理工」。首次出现处可作「司机（原文称 mécanicien）」，其后一律「司机」。 |

| Vatel | 瓦泰尔 | 大孔代亲王的膳食总管，以精益求精、因鱼不至而自尽著称；诺尔普瓦借以称许弗朗索瓦丝。[person] vol11 第001章：凡尔赛有同名餐馆（瓦泰尔餐厅），与 Réservoirs 餐厅并提，用于核对阿尔贝蒂娜行踪；人名条与餐馆条分开处理。 |

| Rachel quand du Seigneur | 「拉谢尔，当主……」 | 叙述者给拉谢尔起的绰号，截自《犹太女》咏叹调首句 Rachel, quand du Seigneur…；老板娘不解其意，只觉好听，译文保留省略号以见其半截。 |
| Bloch | 布洛克 | 我年长的同学，引介贝戈特；爱用矫揉语体（mon très cher maître） |
| Gilberte | 希尔贝特 | 斯万与奥黛特之女；本章香榭丽舍游戏的中心人物，叙述者少年之恋的对象。全名 Gilberte Swann→希尔贝特·斯万。禁用译法沿用全书。 |
| Rachel | 拉谢尔 | 布洛克带叙述者去的妓院里的犹太姑娘；叙述者给她起绰号「拉谢尔，当主……」，出自阿莱维歌剧《犹太女》咏叹调首句。与圣经中雅各之妻拉结无关，不作「拉结」。 |
| tante Léonie | 莱奥妮姑妈 | 莱奥妮姑妈；贡布雷宅邸主人、久病闭居；其母即 grand'tante 姑外祖母（两人，勿混）。本章仅以「莱奥妮姑妈去世后」一句提及，弗朗索瓦丝因此进入叙述者家。禁用: 莱奥妮姨妈 |
| Juive | 《犹太女》 | la Juive，阿莱维的五幕歌剧；拉谢尔绰号出自其中咏叹调。与「犹太人」无关。 |
| Combray | 贡布雷 | 叙述者童年度假小镇、全书核心场景（原型伊利耶 Illiers）。译林版（上游指示）。首现第1章。 |
| Halévy | 阿莱维 | 雅克·弗罗芒塔尔·阿莱维，《犹太女》（La Juive）作曲者；拉谢尔的绰号出自其中咏叹调「Rachel, quand du Seigneur」。 |
| Mantegna | 曼特尼亚 | 意大利文艺复兴画家，以古典战士与透视著称。首现第1章。 |
| Mme Swann | 斯万夫人 | 即奥黛特；本章她在布洛涅树林散步，路人低语其旧名 Odette de Crécy。叙述者只称斯万夫人，不点破。 |
| Méséglise | 梅塞格利丝 | 预收：le côté de Méséglise→梅塞格利丝那边（斯万家那边的散步路线，贡布雷II）。 |
| Sienne | 锡耶纳 | marbre de Sienne→锡耶纳大理石（壁炉）。首现第1章。 |
| Wagner | 瓦格纳 | 作曲家。 |
| entremetteuse | 淫媒 | 撮合卖淫的女人；斯万以此骂音乐、也骂维尔迪兰夫人，保留粗俗分量，不弱化为「中介」。maquerelle→老鸨。首现第1章。 |
| ma tante | 姑妈 | 本章通指莱奥妮姑妈 |
| maison de passe | 妓院 | 布洛克带叙述者初访之处；与 maison de rendez-vous 同译「妓院」。 |
| orchidée | 兰花 | 斯万家候客厅与花篮中的兰花；与卡特兰同为奥黛特所爱。 |
| tisane | 草药汤饮 | 弗朗索瓦丝提出为叙述者煮的安神汤饮。首现第1章。 |

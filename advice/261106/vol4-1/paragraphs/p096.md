# vol4-1 P096 逐句审校

- 法语原文行号 `raw-md/vol4/chapters/001.md:195`
- dev 底稿行号 `polish/dev/chapters/polished-vol4-1.md:195`

本段是律师公会会长对首席院长夫人一行（上段 P095「nous restons cachés, comme l'humble violette」）的答话，承接康布雷梅尔夫妇午餐（P090）及其后的打趣（P091–P094）。法中对应核实无误：法语 195 行 ↔ dev 195 行，首句「Mais vous avez eu tort」对「可您错了」、末句「Allons-nous faire notre petit bésigue ?」对「来玩咱们那局贝齐克牌吧？」，与前后段 P095（193 行）、P097（197 行）衔接吻合。

1. **Mais vous avez eu tort … le danger était passé.** 对应「可您错了，我再说一遍，律师公会会长答道，此刻危险已经过去，他胆子也壮了。」
   - 「Mais vous avez eu tort」→「可您错了」：准确。须注意此处法语 vous 为复数——指首席院长夫人及其同伴（上段以 nous 自称「我们还是躲着吧」，下句 mangés 为阳性复数过去分词亦可证）。dev 用单数敬称「您」，是以刚发言的夫人这一「代言人」为直接对象，与 P094（191 行「我本以为您会过来」，同一复数 vous 亦译「您」）及整段对话的处理一致；中文以「您」指代夫人一行、由代言人承当，读者不会误解，若此处独改「你们」反与 P094 不一致。故保留「您」，不作指代错误处理。
   - 「je vous le répète」→「我再说一遍」：le 即「您错了」这事，vous（对您）在中文里隐含，译法自然。
   - 「répondit le bâtonnier」→「律师公会会长答道」：bâtonnier 译「律师公会会长」，与 P090/P092 等前后段一致；答话标签位置与法语同。
   - 「enhardi maintenant que le danger était passé」→「此刻危险已经过去，他胆子也壮了」：enhardi（壮起胆）译「胆子也壮了」地道；「危险」指午餐时须把平日朋友引见给侯爵夫人的那份社交风险（P090 他躲开平日朋友、P094 以「一丝讥讽」冲淡引见提议的荒唐），如今午餐已过，他才敢说「他们又不会吃了你们」。分词短语化为后置小句，因果（危险过去→胆壮）保留；「也」为语气衬字，非实义增译。保留。

2. **Ils ne vous auraient pas mangés.** 对应「他们又不会把您吃了。」
   - Ils 指康布雷梅尔夫妇（P090/P093 的贵族客人），译「他们」准确。
   - 「ne vous auraient pas mangés」为条件式过去（本不会把你们吃了），dev 以「又不会……吃了」这一中文反诘式宽慰口吻传达（「又不是真会把您吃了」），轻描淡写的语气贴合；中文不显标条件过去，其假设意味由语境（回应「我们躲着」）自明。mangés 阳性复数印证 vous 为复数，dev「您」承上以夫人为代言人，处理同第 1 项。保留。

3. **Allons-nous faire notre petit bésigue ?** 对应「来玩咱们那局⊂贝齐克牌⊃≼🏛️纸牌戏，法文 bezigue。≽吧？」
   - 「Allons-nous faire」→「来玩……吧？」：邀约语气准确。
   - 「notre」→「咱们」：包括式「咱们的」，指会长与朋友们常玩的那局牌，贴合。
   - 「petit」为亲昵/随便的小称（犹言「咱们那小局牌」），非实指规模；dev 未直译「小」，而以「咱们那局……来玩……吧」的口语亲昵语气传达，若硬译「小贝齐克牌」反生硬。此为修辞语气、非信息漏译，保留。
   - 「bésigue」→「贝齐克牌」，注释 ⊂贝齐克牌⊃≼🏛️纸牌戏，法文 bezigue。≽ 锚点完整、注释紧跟锚点且同一行，内容（纸牌戏、法文 bezigue）无误。保留。

# vol4-1 P145 逐句审校

- 法语原文行号 `raw-md/vol4/chapters/001.md:293`
- dev 底稿行号 `polish/dev/chapters/polished-vol4-1.md:293`

本段仅一句台词，承 P144 末尾「而律师公会会长故作大度地说道：」（Et le bâtonnier disait charitablement :），为会长就周日出游话题所说的一句羡慕之辞，与 P146 转回叙述者在门廊前等候的描写衔接吻合；法中行号均为 293（=2×145+3），已核对两文件实际行，以本段首尾句与前后段核实，对应无误。

1. **-- Je vous envie, j'aurais bien changé avec vous, c'est autrement intéressant.**。对应「——我羡慕您，我要是能跟您换换就好了，那可有意思多了。」。全段为一句，按三个逗号意群逐层核对：
   - **Je vous envie → 我羡慕您**：envier 即羡慕，词义准确；vous 译「您」，与会长身份及 dev 前后段对话中的敬称口吻一致。原文未明说「您」的所指（承上文当指周日去了费泰尔讷城堡的客人），译文同样以「您」留白，由语境自明，未擅自补出对象，处理得当。
   - **j'aurais bien changé avec vous → 我要是能跟您换换就好了**：changer avec qqn 为「与某人交换处境/位置」，此处指互换周日的去处，「跟您换换」是地道的口语说法，叠词「换换」带出随口艳羡的语气，词义无误。j'aurais changé 为条件式过去时，表虚拟的愿望（此处带回首过去出游的意味），中文以「要是……就好了」这一惯用句式对应，虚拟语气传达到位，过去参照由上文周日出游的叙述供给，无需另加时态标记，无语气偏差。bien 是意愿强化词（「很乐意/真愿意」），未单独译出，但「要是……就好了」的艳羡句式本身已含情愿之意，又与首句「我羡慕您」呼应，语义已被吸收而非漏译；若硬补「很乐意」反显冗赘。交换的宾语（去处）法中两文均隐含，中文读者据上下文不会误解，不构成歧义。
   - **c'est autrement intéressant → 那可有意思多了**：autrement 置于形容词前为程度副词，义为「远远更加」（=bien plus），并非「别样地」；dev 以「……多了」这一口语比较补语对应，程度与比较关系准确，未误读为方式副词。c' 指对方的去处/活动，「那」自然承指，属惯用的明示化，未增添信息。intéressant 译「有意思」而非更书面的「有趣」，与整句口语台词的语域一致。
   - **对话格式与中文表达**：法语对话破折号「--」对应 dev 通例「——」，与 P144 末尾「说道：」及全篇对话格式一致。三个短句节奏轻快，「您……您」的重复与原文 vous…vous 对应，句式通顺，无欧化硬译、生造搭配或语序纠缠；全段无任何注释，不涉及锚点问题。

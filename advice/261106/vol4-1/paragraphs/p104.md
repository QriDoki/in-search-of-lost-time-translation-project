# vol4-1 P104 逐句审校

- 法语原文行号 `raw-md/vol4/chapters/001.md:211`
- dev 底稿行号 `polish/dev/chapters/polished-vol4-1.md:211`

本段是律师公会会长（bâtonnier）对领班艾梅说的一番得意而又故作随意的话：他要艾梅向斯泰尔马里亚先生透露，今早与自己共进午餐的那位先生是康布雷梅尔侯爵，好杀杀这位贵族的傲气。已核对本段首尾句与前后段（P103 为艾梅应答「啊，真的吗？我倒不吃惊！」，P105 为次日斯泰尔马里亚先生登门拜访），法中对应无误；并参照上文 207 行与下文 215 行核实了末句代词的指代。本段无行内注释。

1. **Ça lui montrera qu'il n'est pas le seul homme titré.**。对应「这好让他明白，有爵位的人不止他一个。」。"Ça lui montrera" 为将来时（这会让他明白），dev 作「这好让他明白」略偏目的语气；但此处传话本就是为了让斯泰尔马里亚明白，目的与预期效果合一，口语中如此处理可接受，不算语气偏差。"qu'il n'est pas le seul homme titré"（他并非唯一有爵位的人）译为「有爵位的人不止他一个」，"homme titré" 作「有爵位的人」准确。保留。
2. **Et attrape donc !**。对应「这下可逮住他了！」。"attrape" 在此为感叹词（逮住你了／看你往哪儿跑），"donc" 加强语气，是会长想到能挫一挫斯泰尔马里亚的贵族傲气时的得意之语。「这下可逮住他了」传达出这种「将你一军」的口吻，「可」与 "donc" 的强调相应，属地道处理。保留。
3. **Il n'est pas mal de leur rabattre leur caquet à ces nobles.**。对应「杀杀这些贵族的傲气，倒也不坏。」。习语 "rabattre le caquet de qqn" 意为打掉某人的傲气／使其收敛，「杀杀……傲气」是贴切的汉语对应；"ces nobles" 作「这些贵族」，"Il n'est pas mal de" 作「倒也不坏」均准确。法语口语的赘述结构 "leur ... à ces nobles" 在汉语中自然化解。保留。
4. **Vous savez, Aimé, ne lui dites rien si vous voulez,**。对应「您知道，艾梅，当然，您若不说也无妨；」。"Vous savez, Aimé" 作「您知道，艾梅」无误。"ne lui dites rien si vous voulez" 是带 "si vous voulez" 缓和语气的吩咐（您不想说就别跟他说），与会长故作不在乎的姿态相合，「您若不说也无妨」准确传达这种听便的口吻。但「当然」在原文中无对应（并无 bien sûr／évidemment 之类），属轻微增译；去掉后句子同样自然、随意。修订：删去「当然，」。
5. **moi, ce que j'en dis, ce n'est pas pour moi ;**。对应「我呢，我说这话可不是为自己；」。口语化的自我指称 "moi, ce que j'en dis" 以「我呢，我说这话」自然承接；"ce n'est pas pour moi"（不是为我自己）作「可不是为自己」准确，表现会长撇清「我不是为自己打算」的姿态。保留。
6. **du reste, il le connaît bien.**。对应「再说，斯泰尔马里亚先生和康布雷梅尔侯爵本来就很熟。」。"du reste"（再说／况且）作「再说」无误。"il le connaît bien" 两个代词都必须是第三人称——说话者会长本人不可能作 il 或 le（否则须用 je/me），而此语境中相关的第三方男子只有斯泰尔马里亚与康布雷梅尔（上文 207 行点名康布雷梅尔侯爵，下文 215 行又称「我们共同的朋友康布雷梅尔一家」），故 dev 将指代显化为两人「本来就很熟」是正确的，也符合汉语需明确指代的习惯。「本来就」隐含于 "du reste" 及上下文（二人本就相识，故无需多此一举传话），非赘增。保留。

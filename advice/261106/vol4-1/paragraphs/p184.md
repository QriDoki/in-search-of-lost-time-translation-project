# vol4-1 P184 逐句审校

- 法语原文行号 `raw-md/vol4/chapters/001.md:371`
- dev 底稿行号 `polish/dev/chapters/polished-vol4-1.md:371`

本段为一句对话，上承维尔巴里西斯侯爵夫人与外祖母的寒暄、下启外祖母把外套递给经理一事；已核实第 371 行法中逐字对应，前后段（369/373 行）衔接无误，下段「les／外套」即指本段「manteaux」。

1. **Donnez donc vos manteaux … pour qu'on les remonte.** 对应「把你们的外套给我吧……好让人拿上楼去。」
   - 对话标记「--」→「——」，正确。
   - 主句「Donnez donc vos manteaux」：donner 命令式 vous 形，dev 用「把……给我吧」处置式，口吻自然。「vos manteaux」为复数（多件外套、多位受话人），译「你们的外套」正确，并与下段「les／外套」复数照应；此处 vous 为复数而非单数尊称，「你们」不误。「donc」为催促、劝诱语气词（非「因此」），dev 以「吧」传达商量兼催促的口吻，得当。
   - 「给我」：原文 donner 未明说接受者，属语境隐含（收外套的一方）。dev 补出「给我」是汉语自然的显化，并未增添与原文相悖的信息；结合下件外套经外祖母转交经理拿上楼，「给我」解作「交到我这边来」仍成立，不构成增译失误，予以保留。
   - 目的从句「pour qu'on les remonte」：pour que 目的关系译「好让」正确；不定代词 on 译「人」（让人＝叫人、由人）贴切；les 指外套，作「拿」的隐含宾语，无误；remonter（re-＋monter，拿回楼上）译「拿上楼去」，「回／再」一层在「把外套送回客房」语境中已隐含，未造成误解。
   - 中文表达：全句为地道口语对话，处置式＋目的分句顺畅，无欧化硬译、无生造搭配、无歧义指代，符合人物口吻。
   综上，本句语义、语气与口吻均准确，保留。

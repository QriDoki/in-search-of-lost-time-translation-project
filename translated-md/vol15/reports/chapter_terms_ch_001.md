## 一、本章核心哲学词（译名锁定，不得改译）

| 原文 | 译名 | note |
|---|---|---|
| temps | 时间 | 〔核心〕普通义「时间」；大写 `le Temps` 指拟人化的「时间」（提着灯笼、借人体显形的艺术家）。`le temps écoulé`／`le temps passé` 作「逝去的时间」。禁用「时光」通篇替代、「时机」「时候」。 |
| le Temps perdu | 失去的时间 | 〔核心〕正文概念作「失去的时间」，与书名《追忆似水年华》严格区分；书名不因本条改动。源文大写 `le Temps Perdu`。禁用「逝去的时光」「消逝的时间」。 |
| temps à l'état pur | 纯粹状态的时间 | 〔核心〕`un peu de temps à l'état pur`：感官偶合使人截住的一小段脱离时间秩序的时间。禁用「纯时间」「纯净的时间」。 |
| extra-temporel | 超时间的 | 〔核心〕`un être extra-temporel` 作「一个超时间的存在」；`joie extra-temporelle` 作「超时间的快乐」。禁用「超越时间的」（冗长）、「永恒的」（extra-temporel ≠ éternel，不可偷换）。 |
| temps incorporé | 体化的时间 | 〔核心〕结尾 `cette notion du temps incorporé`：过去并未与我们分离，而积存在身体里，人如巨人同时触及相隔遥远的年代。禁用「具体化的时间」「融入身体的时间」。 |
| réminiscence | 旧感复现 | 〔核心·锁定〕沿 vol14 第001章定名，本章不改。指「某一感官印象突然唤起过去」这一**事件**（石板、汤匙、餐巾、水管四处）。**与 mémoire involontaire 严格区分**：réminiscence 是复现事件，mémoire involontaire 是这种记忆能力；二者不得互换，不得把 réminiscence 改译「不由自主的记忆」。禁用「回忆」「追忆」「记忆再现」。 |
| mémoire involontaire | 不由自主的记忆 | 〔核心·锁定〕由感官偶合突然完整唤回、不经理智调动的记忆能力；与 mémoire volontaire 相对。沿用全书定名。禁用「无意识记忆」「非自愿记忆」「非自主记忆」。 |
| mémoire volontaire | 有意的记忆 | 〔核心〕即理智的记忆（la mémoire de l'intelligence），与「不由自主的记忆」构成对仗。本章 `on peut prolonger les spectacles de la mémoire volontaire, qui n'engage pas plus de forces de nous-même que feuilleter un livre d'images`。禁用「意愿记忆」「主动记忆」。 |
| impression | 印象 | 〔核心〕认识论关键词：`l'impression est pour l'écrivain ce que l'expérimentation est pour le savant`。禁用「感受」「感觉」（后者是 sensation）。 |
| impression vraie | 真实的印象 | 〔核心〕与「虚假的印象」对举；只能由感官被动接受。 |
| impression factice | 虚假的印象 | 〔核心〕`l'impression factice que nous nous en donnons quand volontairement nous essayons de nous la représenter`：刻意重构所得。 |
| sensation | 感觉 | 〔概念〕感官当下的材料（石板的高低、汤匙的声响）；与 impression（留在我们身上的印记）区分。`la sensation commune` 作「共同的感觉」。禁用「印象」。 |
| analogie | 类比 | 〔概念〕`le miracle d'une analogie`：此刻与过去两种感觉之间的相似。禁用「类似」「比喻」。 |
| métaphore | 隐喻 | 〔概念〕把两种感觉的共同品质联结、以抽离时间。禁用「暗喻」。 |
| idéalisme | 唯心论 | 〔哲学〕`la leçon d'idéalisme`：一切都在精神中，物质无关紧要。禁用「理想主义」（日常义）。 |
| essence / essence générale | 本质／一般本质 | 〔核心〕`l'essence des choses` 作「事物的本质」；`l'essence permanente et habituellement cachée` 作「恒常而通常隐蔽的本质」。禁用「精髓」「精华」（易与 gratin 混）。 |
| idée | 观念 | 〔核心〕与 impression 对举；`en tant qu'idée` 作「作为观念」，`les idées de l'intelligence` 作「智力的观念」。禁用「思想」（pensée）、「主意」。 |
| réalité | 现实 | 〔核心〕`la réalité à exprimer` 作「要表达的现实」；`la réalité intérieure` 作「内在的现实」。禁用「真实」（与 vérité 混）。 |
| vérité | 真理 | 〔核心〕`les vérités de l'intelligence` 作「智力的真理」，`une vérité nouvelle` 作「新的真理」。禁用「真实」。 |
| vocation | 天职 | 〔核心·锁定〕`Une vocation`（假设的章题）作「一种天职」，指作家的使命。**主译名一律「天职」**，禁用「使命」「职业」「志向」「天赋」。 |
| art / artiste / écrivain / œuvre | 艺术／艺术家／作家／作品 | 〔核心〕`l'art véritable` 作「真正的艺术」；`le devoir et la tâche d'un écrivain sont ceux d'un traducteur`；`mon œuvre` 作「我的作品」。禁用「美术」（仅指绘画时）、「作者」（auteur）、「著作」。 |
| style | 风格 | 〔概念〕`le style est une question non de technique, mais de vision`：强调是看法而非技巧。禁用「文体」「文笔」。 |
| livre intérieur | 内在之书 | 〔核心〕`le livre intérieur de ces signes inconnus`：每人身上那本由不认识的符号写成、无人能代读的书。禁用「内心的书」「内部的书」「心灵之书」。 |
| le seul livre vrai | 唯一真实的书 | 〔核心〕与「内在之书」同义群：不是作家「发明」的书，而是人人身上已存在、只待翻译的书。 |
| le livre aux caractères figurés | 带图形的书 | 〔核心〕`non tracés par nous`：符号由现实印在我们身上。禁用「象形文字书」。 |
| paperoles | 纸卷 | 〔核心〕弗朗索瓦丝对叙述者手稿纸片的叫法。正文保留法语原词并作斜体 *paperoles*，首次出现可夹注「纸卷」。禁用「纸片」「手稿」单独替代。 |
| traduire (écrivain) | 翻译 | 〔概念〕`Le devoir et la tâche d'un écrivain sont ceux d'un traducteur`：作家是「翻译者」。此处为比喻义的「翻译」，不改为「转译」「诠释」。 |
| équivalent spirituel | 精神的对等物 | 〔概念〕`convertir en un équivalent spirituel`。禁用「精神等价物」。 |
| signe / symbole | 符号／象征 | 〔核心〕感觉是「符号」，须解为法则与观念（`interpréter les sensations comme les signes`）；与「象征」区分：符号待解，象征已被赋予意义。禁用「标志」；二词不得互换。 |
| hiéroglyphe / grimoire | 象形文字／天书 | 〔概念〕现实给的符号像只表示实物的「象形文字」（禁用「图画文字」）；钟楼、野草在脑中组成一册繁复花哨的「天书」（禁用「魔法书」）。 |
| loi / les lois de l'Art | 法则／艺术的法则 | 〔概念〕禁用「规律」（偏科学描述）、「法律」；`la loi cruelle de l'art est que les êtres meurent` 作「艺术的残酷法则：人必须死去」。 |
| instinct / intelligence / intuition | 本能／智力／直觉 | 〔核心〕`l'instinct dicte le devoir et l'intelligence fournit les prétextes pour l'éluder`：本能指定义务，智力提供借口。intelligence 禁用「理智」「智慧」；intuition 禁用「本能」。 |
| volonté / paresse | 意志／懒惰 | 〔概念〕`le déclin de ma volonté` 作「意志的衰退」，禁用「毅力」；`dans la paresse, dans la dissipation des plaisirs` 作「在懒惰与寻欢作乐中」。 |
| moi / notre vrai moi | 自我／我们真正的自我 | 〔核心〕`les divers moi` 作「各个自我」；`notre vrai moi qui... semblait mort` 作「我们真正的自我，它有时看似早已死去」。禁用「本我」「真我」。 |
| psychologie dans l'espace | 空间中的心理学 | 〔概念〕与「平面心理学」相对，指把时间中的位移写成空间纵深。禁用「空间心理学」（易误为学科名）。 |
| la vraie vie | 真正的生活 | 〔核心〕`la vraie vie, la vie enfin découverte et éclaircie`；与 `la vie réelle`（实际生活）区分。 |
| éternité / néant / mort | 永恒／虚无／死亡 | 〔概念〕`un premier néant` 作「最初的虚无」；`l'idée de la mort` 作「死亡之念」。感叹条目 `mort !` 另作「死了！」（夏吕斯数死者），不得与名词「死亡」混。 |
| souffrance / bonheur / malheur | 痛苦／幸福／不幸 | 〔核心〕`la souffrance est la meilleure chose que l'on puisse rencontrer dans la vie`；bonheur 不作「快乐」（joie 另条）。 |
| amour / jalousie / habitude / souvenir / oubli | 爱情／嫉妒／习惯／回忆／遗忘 | 〔核心〕souvenir 与 mémoire（记忆能力）区分；habitude 本章多作比喻（`la vitesse acquise de l'habitude` 作「习惯所获得的速度」）。 |
| cathédrale | 大教堂 | 〔比喻〕`bâtir mon livre comme une cathédrale` 作「像建大教堂一样构筑我的书」；`des cathédrales restent inachevées`。禁用「教堂」（église 为普通教堂）。 |
| matinée | 午后聚会 | 〔场景·锁定〕本章及 vol14 第003章均指亲王妃家白天招待会，章题同；源文明确指剧院日场时作「日场」，字面 `cette heure matinale` 作「早晨」。禁用「日间聚会」「上午聚会」「晨间聚会」。 |
| soirée / goûter | 晚会／下午茶会 | 〔场景〕与「午后聚会」三分：soirée 晚间社交，goûter 小型茶点会（本章贝尔玛家那场）。 |
| salon / Salon | 沙龙；客厅／沙龙展 | 〔场景〕小写 salon 两义（房间／社交圈），按语境；大写 Salon 指官方美术年展，**不得用于本章任何客厅**。 |
| le monde / grand monde / gens du monde | 上流社会／大贵族社交界／上流社会的人 | 〔社会〕`aller dans le monde` 作「出入社交界」。禁用「世界」「世俗之人」。 |
| faubourg Saint-Germain | 圣日耳曼区 | 〔地名／社会〕巴黎贵族聚居区，转喻旧贵族社会。禁用「圣日耳曼郊区」「圣日耳曼城郊」。 |
| gratin / snobisme / mondanité / caste | 精华圈子／附庸风雅／上流社会习气／种姓 | 〔社会〕gratin 不作「锅巴」；`le pur gratin de l'aristocratie` 作「贵族中最纯粹的精华圈子」。 |
| cocotte / demi-mondaine / grue / gigolo | 交际花／半上流社会女子／烟花女子／小白脸 | 〔社会〕cocotte 禁用「妓女」（过重）；grue 按既有裁决两义（烟花女子／鹤）；gigolo 源文加引号时保留。 |

## 二、人物与称谓

> 硬规则：`princesse de X`→「X 亲王妃」（不是公主、不是亲王夫人）；`Mme de X`→「X 夫人」；`M. de X`→「X 先生」；`duc/duchesse`→公爵／公爵夫人；`marquis/marquis`→侯爵／侯爵夫人；`Mgr`→主教。称谓形式随源文，不合并同一人的不同称呼（note 说明同指）。

## 七、note 编写说明（供 L1 裁剪时保留）

1. **note 结构**：〔类别〕＋文化核查结论＋「禁用」项。类别取值：人物、称谓、家族、地名、机构、作品、概念、核心、母题、社会语汇、名物、建筑、历史事件。
2. **称谓随源文**：同一人的 `M. de X`／`le baron`／裸姓三种形式必须分别对应「X 先生」／「X 男爵」／「X」，不得自行统一。源文爵称前后不一致时（本章康布雷梅尔家 marquis／comte），译文随源文，但 note 已标明同族关系，禁止拆成两家。
3. **叙述边界**：凡「不得提前点破」者（圣卢小姐的婚事、亲王妃与维尔迪兰夫人的同一性在布洛克对话中的揭示节奏、公爵夫人与公爵的分居程度），L2 只照源文写，不补解释、不加译注、不算法文。
4. **重复出现的母题**：石板／汤匙／餐巾／水管四处，译文须保持同一措辞（「高低不平的石板」「汤匙碰盘子的声响」「浆硬的餐巾」「水管」），以便读者回认；不得逐处换词。
5. **书名**：真实作品用中文通行译名并加书名号；虚构作品（凡德伊奏鸣曲／七重奏、博塞让夫人回忆录）不加作者、不套现实原型。
6. **报纸与年鉴**：`Le Figaro`《费加罗报》、`Le Temps`《时报》（与概念「时间」同形，注意区分）、`Gotha`《哥达年鉴》、`Annuaire des Châteaux`《城堡年鉴》、`Tout-Paris`《全巴黎名人录》。
7. **数字与编号**：`Louis XIV`→路易十四、`Louis XVII`→路易十七、`XVIIIe siècle`→十八世纪（中文不用上标）；`Exposition de 1878`→1878 年世界博览会。
